Seek-and-Solve: Benchmarking MLLMs for Visual Clue-Driven Reasoning in Daily Scenarios

方向: MM | 标签: MM

简述: 评测MLLM日常视觉线索推理能力

筛选理由: Benchmark切中痛点，任务设计新，但偏评测非方法

Deep Review

创新: 论文提出了 DailyClue，一个专门评测 MLLM 在日常复杂场景中“主动寻找视觉线索并据此推理”能力的基准，而不是继续停留在目标识别、OCR 或知识记忆型问答上。其关键创新在于显式标注 visual clues，并通过“线索定位 + 推理求解”的任务设计，隔离并测量模型真正的 clue-driven reasoning 能力。作者还提出更严格的评测协议，不仅看答案是否正确，还检查模型推理中提取的线索是否与标注线索重合，从而识别“答对但理由错”的情况。

方法: DailyClue 围绕四大日常推理领域构建：位置识别、空间关系、日常常识推理和科学常识推理，共覆盖 16 个子任务、666 个高质量样本。数据构建流程包括：从公开数据集和互联网收集真实日常场景图片，利用 GPT-5 与 Gemini-2.5-Pro 生成 question-clue-answer triplet，再经人工修订与三类模型交叉过滤，只保留真正依赖视觉线索且具有挑战性的样本。评测时既采用常规 accuracy，也引入严格评测：模型不仅要答对，还必须在 CoT 中提取到与 ground-truth clue 相交的关键视觉证据。论文还进一步研究了 clue 注入、显式 clue-guided CoT 等机制对性能的影响。

实验: 作者系统评测了 25 个开源、闭源与 agentic 模型，发现当前最强模型 Gemini-2.5-Pro 也只有 56.9% 准确率，说明该 benchmark 具有很强区分度且远未饱和。实验进一步表明，模型性能的主要瓶颈不在纯推理器本身，而在于能否先找对视觉线索；注入 GT clue 后，多数模型都有显著提升。另一个很有价值的发现是，显式要求模型在 CoT 中先找 clue 再推理，能稳定提升表现，而严格评测下顶级模型的分数下降较小，说明强模型的正确答案通常确实建立在较合理的视觉依据上。

Deep理由: 这篇工作抓住了当前 MLLM 评测中的一个关键缺口：模型是否真的会在复杂图像里找线索并进行 grounded reasoning。若你关注多模态推理、视觉 CoT、agentic perception 或 benchmark 设计，这是非常值得读的一篇。

POINTS-Seeker: Towards Training a Multimodal Agentic Search Model from Scratch

方向: MM | 标签: MM

简述: 从零训练多模态搜索智能体

筛选理由: 问题新，含训练范式与长程压缩，实证较强

Deep Review

创新: 论文最大的创新是提出了从零开始构建多模态 agentic search 模型的训练范式，而不是像现有多数工作那样先有通用 LMM、再通过 SFT/RL 外挂搜索能力。作者进一步提出 Agentic Seeding，在模型形成期注入多模态推理、文本推理和 ReAct 式 agent 数据，把“规划-推理-工具使用”做成底层能力。另一个关键创新是 V-Fold：当长程交互历史过长时，将陈旧 observation 渲染成图像压缩进视觉 token，中间保留最新几轮文本，从而缓解 long-context 下的 attention dilution / lost-in-the-middle 问题。

方法: 整体方法分为三阶段：先做常规视觉语言预训练，再进行 Agentic Seeding，将 reasoning 与 planning 能力提前植入模型表征；随后基于自动构造的带轨迹 VQA 数据进行 SFT，并用带工具调用的 GRPO 式 RL 继续优化答案正确率、格式规范性和 tool-call 合法性。数据侧，作者构建了一个自动化 agent 轨迹生成流水线：从搜索型 VQA 或多跳 QA 改写为图文问答，再让强教师模型生成 think/tool_call/tool_response/answer 轨迹，并经过 judge 过滤。推理时若历史超过阈值，V-Fold 会把较早的 observation 渲染为图片送入视觉编码器，而保留最近交互为文本，以维持长程搜索中的证据可访问性和效率。

实验: POINTS-Seeker-8B 在 MMSearch、MMSearch-Plus、FVQA、SimpleVQA、LiveVQA、BrowseComp-VL 六个基准上整体达到 SOTA 或接近 SOTA，显著优于多种开源 agentic search MLLM，并超过部分基于更强底座后训练得到的方法。消融实验显示 Agentic Seeding、SFT、RL、V-Fold 都有稳定贡献，其中 V-Fold 在更难、交互更长的 MMSearch-Plus 和 BC-VL 上提升尤为明显。额外分析还表明，V-Fold 不仅提高准确率，还能把平均响应长度压缩约 23%~25%，并且不会伤害通用视觉问答能力，反而在通用 VQA 基准上平均提升 2.3 分。

Deep理由: 这篇工作同时回答了两个很关键的问题：多模态搜索 agent 是否应该从底座阶段就被塑造，以及长程交互历史该如何高效保留。对于做多模态智能体、搜索增强推理、长上下文记忆压缩的研究者来说，它的训练范式和 V-Fold 设计都很有启发性。

MAny: Merge Anything for Multimodal Continual Instruction Tuning

方向: MM | 标签: MM

简述: 训练免费多模态持续调参合并框架

筛选理由: 抓住双遗忘痛点，方法新颖且增益明显

Deep Review

创新: 论文最核心的贡献是提出了 MCIT 中一个此前被系统忽视的“双重遗忘”视角：不仅语言侧 LoRA/LLM 会发生 reasoning collapse，跨模态 projector 也会发生 perception drift，而且后者在某些视觉推理任务上甚至比语言侧遗忘更致命。基于这一诊断，作者提出训练后、免梯度的双轨合并框架 MAny：一条轨道用 CPM 通过视觉原型引导的 projector 自适应融合恢复感知对齐，另一条轨道用 LPM 通过递归最小二乘闭式解合并 LoRA 任务向量以抑制参数冲突。其价值在于把“持续学习”问题部分转化为“任务特定模块的解析式合并”问题，并且给出了较明确的数学动机与工程实现路径。

方法: MAny 将多模态持续指令微调显式拆成 perception 与 reasoning 两个相对独立的子问题来处理。对于感知侧，CPM 为每个任务保留一个轻量 projector，并用冻结视觉编码器提取的全局特征与各任务视觉 prototype 做相似度匹配，经 softmax 得到权重后，对多个 projector 的输出进行软融合，从而在推理时自动恢复更合适的视觉-语言对齐。对于推理侧，LPM 把每个任务的 LoRA 更新看作低秩任务向量，目标是最小化各层特征漂移；作者将其写成 least squares 目标，并进一步推导出无需历史样本回放的递归最小二乘更新公式，实现对历史 LoRA 的持续合并。整个框架除初始任务微调外不再依赖额外 GPU 训练，只需 CPU 上的代数运算完成知识整合。

实验: 在 UCIT 基准上，MAny 在 LLaVA-1.5-7B 与 InternVL-Chat-7B 上都取得了当前最优结果：相对先前强基线 HiDE，FAA 分别提升 8.57% 和 2.85%，同时遗忘指标 FFM 降到极低水平。消融实验表明，单独加入 CPM 或 LPM 都能显著缓解遗忘，但两者结合效果最好，验证了“双重遗忘”假设的必要性。更有意思的是，CPM 作为可插拔模块还能系统性提升其他 continual tuning 方法，说明 projector 漂移确实是现有方法普遍漏掉的重要瓶颈。

Deep理由: 这篇工作的问题诊断非常到位：它不仅提出新方法，更重要的是纠正了社区长期默认的“只需关注 LLM 遗忘”的偏见。若你关注多模态持续学习、参数高效微调或模型合并，这篇论文同时提供了新的分析框架、可落地的方法设计和具有说服力的实验结果。

Goal2Skill: Long-Horizon Manipulation with Adaptive Planning and Reflection

方向: VLA | 标签: VLA

简述: 分层规划反思提升长程操作

筛选理由: 长程操控痛点明确，闭环规划执行增益显著

Deep Review

创新: 论文提出了一个面向长时程操作的双系统框架 Goal2Skill，将高层语义规划/记忆/反思与低层视觉运动执行显式解耦，而不是继续采用单体式端到端 VLA。其关键创新在于把 memory 从“被动上下文缓存”提升为“主动决策变量”，用于子任务分解、后验验证、失败诊断与重规划，并通过几何保持的遮挡/干扰过滤来提升底层执行鲁棒性。

方法: 系统由高层 VLM planner 和低层 VLA executor 组成。高层模块接收全局目标与当前观测，维护结构化记忆（episodic history、working memory、error register），生成带有前后置条件、执行时长、干扰区域约束和技能索引的子任务序列；每个子任务执行后，高层通过 verifier 判断 success/fail/timeout，并在失败时调用 reflection engine 进行诊断、重试、参数调整或重规划。低层模块则基于 planner 给出的空间约束对图像做 geometry-preserving masked filtering，再调用 diffusion-based skill library 生成连续动作，实现闭环的局部控制。

实验: 在 5 个 RMBench 代表性任务上，Goal2Skill 的平均成功率达到 32.4%，显著高于最强基线的 9.8%；在更依赖长期记忆的 M(n) 任务上更达到 38.7%，而最佳基线仅为 9.0%。消融实验表明，结构化记忆显著提升需要中间状态跟踪和多阶段 bookkeeping 的任务表现，而 verifier + reflection 又进一步增强了 Battery Try、Press Button 这类失败恢复敏感任务的鲁棒性。

Deep理由: 这篇论文对长时程 manipulation 中 VLA 的核心瓶颈——记忆、阶段依赖和失败恢复——给出了较完整且工程上可落地的系统化方案，实验增益也比较明显。之所以不是“必读”，是因为当前结果主要仍集中在 5 个 RMBench 子任务上，整体成功率虽领先但绝对值仍不高，泛化性与真实机器人规模验证还有待进一步观察。

GeoAgentBench: A Dynamic Execution Benchmark for Tool-Augmented Agents in Spatial Analysis

方向: MM | 标签: MM

简述: 面向GIS智能体的动态评测基准

筛选理由: 基准新颖、评测务实，但偏垂直场景

Deep Review

创新: 论文的核心创新在于提出了 GeoAgentBench（GABench），这是一个面向 GIS 工具增强智能体的动态执行型 benchmark，不再停留于代码/文本匹配，而是在真实可执行沙箱中评测长链空间分析流程。其次，作者提出了专门衡量参数推理与执行有效性的 Parameter Execution Accuracy（PEA），并结合 VLM 对最终地图结果进行多模态验证，从而把“过程正确”与“结果正确”统一起来。最后，论文还提出 Plan-and-React 架构，将全局规划与局部反应式执行解耦，以提升复杂 GIS 任务中的鲁棒性和错误恢复能力。

方法: 方法上，作者首先构建了一个包含 117 个原子 GIS 工具、覆盖 6 大 GIS 核心领域和 53 个代表性任务的交互式执行沙箱，并将原始 GIS 任务重构为标准化、可执行的 tool-flow。评测层面，论文采用 TAO/TIO/TEM 衡量工具调用轨迹的集合、顺序和严格匹配程度，并进一步设计 PEA，通过“Last-Attempt Alignment”对 agent 最终成功尝试的参数配置进行对齐评估。与此同时，作者利用 VLM 比较生成地图与标准地图，在空间数据正确性和制图风格一致性两个层面进行端到端打分。最后，为适配该 benchmark，论文提出 Plan-and-React agent：先生成全局分析蓝图，再在每一步结合环境反馈进行 Thought-Action-Observation 式修正执行。

实验: 实验部分的亮点是，作者在 Base Agent、ReAct、Plan-and-Solve 和 Plan-and-React 四类框架下系统比较了 7 个代表性 LLM，较完整地揭示了当前模型在空间推理、长链工具编排和运行时纠错方面的能力边界。结果显示，Plan-and-React 相比传统 ReAct 和 Plan-and-Solve 在复杂多步 GIS 任务上取得了更优的平衡，尤其在参数失配、运行异常和错误恢复场景下更稳健。论文的实验设计也比已有工作更接近真实 GIS 实务，因为它关注的是执行闭环和最终地图产物，而不是静态文本相似度。

Deep理由: 这篇论文对“如何真正评估 GIS 智能体”给出了目前非常系统且务实的答案，特别适合做 GeoAI、工具增强 agent、空间分析自动化的人参考。它不仅提出了 benchmark，还在评测指标和 agent 架构上都给出了有启发性的设计，具有较强的方法论价值。

Robust parameter inference for Taiji via time-frequency contrastive learning and normalizing flows

方向: MM | 标签: MM

简述: 抗毛刺引力波快速参数推断

筛选理由: 方法扎实且实用，但偏领域应用创新

Deep Review

创新: 论文提出了一个面向太极（Taiji）空间引力波探测器的“glitch 鲁棒”参数推断框架，把条件正则化流（conditional normalizing flows）、时频双模态编码器和对比学习统一到同一个摊销贝叶斯推断流程中。其关键创新不只是“用深度学习替代 MCMC”，而是通过对比学习显式学习对瞬态噪声扰动不敏感的表征，从而在强 glitch 污染下仍保持后验的准确性与校准性。另一个很实用的贡献是提出神经 glitch 生成器，以极低成本合成高保真瞬态噪声，解决了大规模在线训练的数据生成瓶颈。

方法: 作者首先基于 Taiji 探测器配置模拟 MBHB（大质量黑洞双星）信号、平稳高斯噪声和 LPF 启发的瞬态 glitch，构造时域+频域双表示输入。随后用一个带门控融合的时频编码器提取上下文特征，并将其送入条件 normalizing flow 来直接学习源参数后验分布。为提升 glitch 鲁棒性，训练时对“同一物理源、不同噪声/glitch 污染”的样本对施加 InfoNCE 对比损失，鼓励网络保留源相关信息、抑制污染相关信息。与此同时，离线训练的神经 glitch 生成器在在线训练阶段快速生成多样化瞬态干扰，用于扩大污染分布覆盖范围。

实验: 实验显示，在无 glitch 条件下各方法都表现正常，但在强 glitch 污染（甚至测试到 glitch SNR=1000）下，传统基于平稳高斯似然的 MCMC 明显失准，而作者方法仍能保持更好的后验定位与校准。消融实验表明，“时频融合 + 对比学习”的完整模型优于去掉对比学习、仅时域或仅频域的版本，并且对 glitch 持续时间和相对并合时刻变化都更稳健。另一个亮点是他们指出 P-P plot 不能充分揭示后验失真，因此额外引入 CRPS 作为更严格的全局分布一致性指标，这一点方法论价值很高。

Deep理由: 这篇工作在空间引力波参数推断里把“鲁棒性、速度、后验校准”三件事结合得比较完整，尤其适合关注 simulation-based inference、normalizing flows 和非高斯噪声建模的研究者阅读。虽然目前仍建立在相对受控的 glitch 模型与模拟环境上，距离真实任务落地还有外推验证空间，但方法设计和评测思路都很值得借鉴。

Character Beyond Speech: Leveraging Role-Playing Evaluation in Audio Large Language Models via Reinforcement Learning

方向: MM | 标签: MM

简述: 音频角色扮演评测与强化学习优化

筛选理由: 聚焦语音角色一致性评测，数据集与评估框架较新

Deep Review

创新: 论文提出了首个面向语音角色扮演代理（voice RPAs）的多维评测框架 RoleJudge，不再只看文本语义，而是同时评估内容、上下文、情绪和语音风格与角色设定的一致性。与此同时，作者构建了首个带有推理链标注的语音角色扮演评测数据集 RoleChat，并在强化学习中引入 Standard Alignment 机制，用“标准样本”缓解 GRPO 相对奖励下容易出现的 reward misalignment 与局部最优问题。

方法: 整体方法分为两阶段：首先用 RoleChat 上带 CoT 和多维分数标注的数据，对 Qwen2-Audio 做 cold-start SFT，使模型学会评测任务理解与规范输出格式；随后进入基于 GRPO 的强化学习阶段。奖励由格式奖励和分数准确性奖励组成，其中准确性奖励采用高斯衰减形式衡量预测分数与人工标注分数的偏差。关键改进在于，训练时先让模型评估同一 query 对应的标准样本，得到一个反映其任务理解程度的绝对置信信号 ru，再用它去缩放候选样本 advantage，并动态调节格式奖励与准确性奖励的权重，从而降低“在一组都很差的答案里选相对最好”的风险。

实验: 在 RoleChat 的人工标注测试集上，RoleJudge 的 Overall Accuracy 达到 86.00%，显著超过 Gemini3 Pro 的 69.80% 和 GPT-4o-audio 的 53.06%，并且五个维度上都取得最优结果。进一步地，RoleJudge 的 Overall MSE 最低为 0.21，在情绪适配和风格一致性上的 Pearson 相关系数分别达到 0.81 和 0.62，说明它不仅更准，而且更贴近人类主观判断。消融实验还表明，RL 相比纯 SFT 带来大幅提升，而 Standard Alignment 又在 GRPO 基础上继续提升约 3.29 个点，验证了该机制的有效性。

Deep理由: 这篇工作在“语音角色扮演评测”这个新问题上给出了较完整的数据、方法和实验闭环，方向新且工程价值强。虽然数据构造与标注流程仍较依赖教师模型，且任务设定主要是评测器而非生成器本身，但作为 Audio LLM 评测与 RL 对齐的交叉研究，值得认真关注。

Failure Identification in Imitation Learning Via Statistical and Semantic Filtering

方向: MM | 标签: MM VLA

简述: 用统计加语义过滤识别机器人失败

筛选理由: 聚焦部署安全，方法实用，但偏检测模块

Deep Review

创新: 论文提出了 FIDeL，一个面向模仿学习机器人的独立失败监控模块，把“异常检测”进一步推进到“失败识别”：先检测偏离专家演示分布的异常，再通过视觉-语言模型区分无害异常与真正影响任务完成的失败。其关键创新在于将基于表示的视觉异常检测、最优传输时空对齐、空间感知的保形预测阈值以及语义级过滤整合到同一框架中，同时提供可解释的热力图与文本化失败判断。

实验: 在 TruckScenes 验证集上，RadarMOT 相比 MCTrack 将整体 AMOTA 从 26.6% 提升到 33.3%，绝对提升 6.7%，同时 IDS 相对下降约 30%。在长距离 100–150 m 区间，AMOTA 绝对提升 12.7%；在恶劣天气/光照下也表现突出，例如雾天提升 10.3%、夜间提升 10.8%。消融实验进一步表明：雷达 Kalman 更新主要降低 FP 和 IDS，而雷达关联负责补回 TP，cross-check 关联则显著稳定整体系统。

Deep理由: 这篇论文不是在网络结构上“堆更大模型”，而是抓住了雷达最有价值的物理属性，把它用在 3D MOT 最脆弱的状态估计与关联环节，工程启发性很强。若你关注多传感器融合、自动驾驶感知鲁棒性或低训练依赖的跟踪系统，这篇很值得读；但从方法复杂度和理论突破性来看，更偏实用改进而非范式级创新。

Deep理由: 这篇工作在“量子模型是否真的带来参数效率收益”这一点上给出了较清晰的理论和实验支撑，尤其适合关注 QML 与多任务学习结合的研究者阅读。不过其优势主要集中在 head 参数缩放与小规模近端量子可执行性，尚未充分证明在大规模实际任务上存在明确的性能或系统级优势。

创新: 这篇论文的核心创新是提出 Grounded World Model（GWM）：直接在预训练视觉-语言检索模型的对齐潜空间中学习状态转移，从而把传统依赖“目标图像”的 visuomotor MPC，变成可用自然语言目标进行打分和规划的 VLA。更关键的是，它不去微调基础多模态模型本体，而是冻结其语义空间，仅学习动力学预测器，因此显著缓解了 VLA 常见的知识遗忘和语义过拟合问题。另一个很有价值的创新是 Rendering-based Action Tokenization（RAT），把未来动作序列渲染成机器人图像 token，使动作与视觉观测共享同一编码空间，并支持跨机器人形态的零样本迁移。

方法: 方法上，作者先用 KNN 从示教库中基于当前关节状态检索出若干候选动作轨迹，而不是让策略网络直接生成动作；随后将当前观测与候选未来动作序列送入 GWM，在 Qwen3-VL-Embedding 的视觉潜空间中预测每条候选轨迹对应的未来结果表示。再把语言指令编码成目标语义向量，与各候选未来的表示计算余弦相似度，选择最匹配指令语义的轨迹执行，形成一个 language-conditioned MPC。训练时只需要未来视频监督做 latent MSE，不需要额外语言监督，因为语言只在推理阶段通过共享检索空间参与打分。

实验: 实验上，作者构建了专门评估“语义泛化”的 WISER 基准：训练和测试所需运动技能相同，但测试集中的视觉信号、颜色、指代表达和世界知识全部未见。结果显示，10 个主流 VLA 在训练集平均成功率约 90%，但测试集平均只有 22%，暴露出严重的语义过拟合；相比之下，GWM-MPC 在 288 个测试任务上达到 87% 成功率。进一步地，RAT 还让模型在不重新训练世界模型的情况下零样本迁移到 xArm6，上测试集仍有 83% 成功率，说明其动作表征具有较强的 embodiment-agnostic 特性。

Deep理由: 这篇论文非常值得读，因为它不仅指出了当前主流 VLA 在“真正语义泛化”上的核心缺陷，还给出了一条与端到端微调范式明显不同且实验上更有效的替代路线。无论你关注 world model、VLA、MPC，还是机器人中的 foundation model 保真迁移，这篇工作都提供了很强的问题定义、基准设计和方法启发。

LARY: A Latent Action Representation Yielding Benchmark for Generalizable Vision-to-Action Alignment

方向: VLA | 标签: VLA

简述: 潜在动作表征评测基准

筛选理由: 基准价值高，但偏评测非方法突破

Deep Review

创新: 论文提出了首个专门面向“潜在动作表示”质量评测的统一基准 LARYBench，把以往依赖下游任务成败的间接评估，拆解为可直接测量的两类能力：高层语义动作理解（what to do）和低层物理控制映射（how to do）。同时，作者构建了覆盖 1.2M 视频片段、620K 图像对、595K 轨迹、151 类动作、11 种 embodiment 的大规模数据体系。更重要的是，实验给出一个很强的结论：通用视觉基础模型在动作表征上系统性优于专门设计的 embodied LAM，而 latent-level 视觉空间又明显优于 pixel-level 空间。

方法: LARYBench 将潜在动作表示的评测分成两条主线：一是通过 attentive probe 做动作分类，检验表示是否能区分原子级运动原语与任务级复合动作；二是通过 MLP action expert 做轨迹回归，检验表示是否保留足够的物理控制信息。数据层面，作者设计了自动化数据引擎，对多个人类/机器人视频数据集进行重分段、重标注和统一 taxonomy 对齐。模型层面，论文不仅评测了 embodied LAM、通用语义编码器、像素生成编码器，还提出把 LAPA 训练范式嫁接到冻结的通用视觉 backbone 上形成 General LAM，用来系统比较不同动作表示路径。

实验: 实验最亮眼的结果是：V-JEPA2、DINOv3 这类未显式使用动作监督的通用视觉模型，在分类和回归两项任务上都显著超过 LAPA、UniVLA、villa-X 等专门的 latent action 模型。其次，latent-based 表征（如 V-JEPA2、DINOv3）在机器人控制回归上明显优于 pixel-based 表征（如 Wan2.2、FLUX.2-dev），说明语义抽象空间与物理动作空间更对齐。消融还表明，好的 latent action model 关键不只是数据量，更依赖强视觉先验和稳定的量化瓶颈设计。

Deep理由: 这篇论文对 VLA/LAM 方向非常重要，因为它把社区长期缺失的“潜在动作表示评测标准”补上了，而且实验结论具有方向性：未来未必应继续迷信专门的 embodied latent action 设计，反而更应重用通用视觉基础模型的表征能力。对于做 VLA、world model、robot learning 的研究者，这篇论文有很强的 benchmark 和 research agenda 价值。

DA-PTQ: Drift-Aware Post-Training Quantization for Efficient Vision-Language-Action Models

方向: VLA | 标签: VLA

简述: 面向VLA的漂移感知量化

筛选理由: 抓住时序漂移痛点，部署价值高，方法较实用

Deep Review

创新: 论文的核心创新在于把 VLA 的后训练量化问题从传统的“静态重建误差最小化”重新定义为“面向序列控制漂移的优化问题”，明确指出量化误差会在视觉-语言到动作接口处被注入，并在闭环执行中逐步累积成 kinematic drift。为此，作者提出了两个互补模块：Cross-Space Representation Compensation 用于修复跨模态表征到动作空间之间的结构性失真，Drift-Aware Mixed-Precision Allocation 用于按照轨迹级漂移敏感性进行混合精度分配。整体上，这篇工作最有价值的地方是把“控制稳定性”而非“局部数值保真”作为 PTQ 的核心目标。

方法: DA-PTQ 是一个无需再训练的校准式量化框架，首先在少量 calibration trajectory 上收集全精度激活统计、动作轨迹以及 Jacobian 相关的漂移敏感性信息。随后，方法在关键的 vision-language-to-action 接口处，对量化后激活做分层补偿：先用按通道仿射变换对齐均值和方差，再用低秩仿射矩阵补偿跨通道协方差失真，并将这些补偿折叠进量化权重中，因此不增加推理开销。最后，作者构建了一个基于虚拟平面串联链和结构 Jacobian 的漂移代理指标，用它衡量不同动作维度和网络层对长时序误差累积的贡献，从而把最敏感的层保留为 BF16，其余层压到 W4，实现 drift-aware 的 mixed precision。

实验: 实验基于 SimplerEnv，在 WidowX 和 Google Robot 两种 embodiment 上评估，既覆盖域内任务，也覆盖跨机器人、跨场景的 zero-shot 泛化。结果显示，DA-PTQ 在约 42.5% 内存下降和 54.8% 推理加速下，WidowX 上平均成功率达到 48.9%，明显优于 QuantVLA 的 43.5%，并更接近全精度模型 51.3%。消融实验进一步证明，表示补偿与漂移感知混合精度各自有效，二者结合后达到最佳 Pareto trade-off，说明论文提出的“接口对齐 + 长时漂移抑制”确实是互补机制。

Deep理由: 这篇论文的问题定义很到位，抓住了 VLA 量化不同于 LLM/VLM 量化的本质：误差会在闭环控制中累积成轨迹漂移，因而很有启发性。虽然当前实验规模和理论代理仍偏工程化、近似性较强，但作为“面向 embodied control 的 PTQ”方向工作，值得认真阅读。

ReXSonoVQA: A Video QA Benchmark for Procedure-Centric Ultrasound Understanding

方向: MM | 标签: VLA

简述: 超声流程视频问答基准

筛选理由: 面向机器人超声评测，揭示视频VLM程序理解短板

Deep Review

创新: 这篇论文的核心创新在于提出了首个面向“超声采集过程理解”的视频问答基准 ReXSonoVQA，而不是继续停留在静态超声图像上的解剖识别或诊断判断。它把超声智能体真正需要的三类能力——动作-目标映射、伪影/成像质量问题排查、以及流程上下文与下一步规划——显式建模为视频推理任务。更重要的是，作者通过 text-only blind baseline 和严格质控证明：这个 benchmark 确实在测“看视频后的程序理解”，而不只是语言模型利用题干模式猜答案。

方法: 方法上，作者从 YouTube 上公开的超声教学视频中筛选“带专家讲解、连续扫描、强调采集流程、且无屏幕标注”的素材，并裁剪出仅保留超声图像流的片段。随后利用 WhisperX 做词级时间对齐转录，再借助 GPT-5.2 将 narration 转成带时间戳的 procedural event log，每个事件包含 operator action 和 scanning intent。基于这些事件日志，作者再用 LLM 自动生成三类 QA：Type 1 是 Action-Goal Reasoning，Type 2 是 Artifact Resolution & Optimization，Type 3 是 Procedure Context & Planning；同时设置 MCQ 与 free-response 两种形式。为避免题目被文字线索“泄题”，作者设计了迭代式质控流程：对所有题目先做 blind evaluation，筛掉不看视频也能答对的题，并对 MCQ 干扰项做医学合理性与抽象层级一致性的再打磨，最终得到 514 个 clip-grounded QA 样本。

实验: 实验上，作者对 Gemini 3 Pro、Qwen3.5-397B、LLaVA-Video-72B 和 Seed 2.0 Pro 做了 zero-shot 视频问答评测，并与同题 text-only 条件配对比较。结果显示视频输入整体有显著帮助：MCQ 总准确率从 42.2% 提升到 66.3%，free-response 平均分从 0.31 提升到 0.95，说明数据集总体确实依赖视觉时序信息。最值得注意的是，Type 2（伪影排查与优化）始终是所有模型最难的部分，且相对 blind baseline 的增益最小，这揭示了当前前沿 VLM 在“因果故障诊断式程序推理”上的明显短板；另一方面，长视频片段通常更有利于推理，说明 temporal context 对 procedure understanding 很关键。

Deep理由: 如果你关注 VLA、医疗机器人、超声自动扫查或医疗视频理解，这篇论文非常值得读，因为它抓住了一个此前几乎空白但对真实部署极关键的评测维度：procedure-centric ultrasound understanding。它的价值不只在于提出了新 benchmark，更在于清楚证明了当前强模型在超声流程理解中最薄弱的瓶颈其实不是静态识别，而是 troubleshooting 与因果推理。
