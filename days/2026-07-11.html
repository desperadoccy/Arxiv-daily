Harness VLA: Steering Frozen VLAs into Reliable Manipulation Primitives via Memory-Guided Agents

作者: Yixian Zhang (Tsinghua University); Huanming Zhang (Tsinghua University); Feng Gao (Striding AI); Xiao Li (Purdue University); Zhihao Liu (Institute of Automation, Chinese Academy of Sciences); Chunyang Zhu (Infinigence AI); Jiaxing Qiu (Infinigence AI); Yuchen Yan (Infinigence AI); Jiyuan Liu (Zhongguancun Academy); Wenhao Tang (Tsinghua University); Zhengru Fang (Hong Kong University of Science and Technology); Yi Nie (Tsinghua University; Striding AI); Changxu Wei (Tsinghua University); Yu Wang (Tsinghua University); Wenbo Ding (Tsinghua University); Chao Yu (Tsinghua University)

方向: VLA | 标签: VLA

简述: 用记忆代理驯化冻结VLA做可靠操作

筛选理由: 聚焦VLA鲁棒部署，方法实用且增益显著

Deep Review

一句话判断

这篇论文最值得关注的是：在不微调 VLA、也不扩充技能库的前提下，把 frozen VLA“降格”为可重试的接触型 primitive，再由带记忆的 agent 负责重定向、重定位和长程组合，显著提升了扰动场景鲁棒性；如果你关心 VLA 在真实部署中的可靠性，这篇值得精读。

核心问题与动机

论文解决的是一个很实际的 VLA 部署问题：端到端 VLA 在标准分布内能做出不错的局部接触控制，但一旦遇到语义重定向、目标重绑定、物体布局变化、局部接触失败，就容易沿着训练轨迹“惯性执行”，既不擅长长时程组合，也不擅长显式纠错。相反，LLM/coding agent 擅长语义推理和任务分解，但纯解析 primitive 很难完成不规则抓取、受约束放置、关节/器具操作等接触密集动作。

因此作者的核心动机不是“训练更强的 VLA”，而是重新划分职责边界：把语言理解、目标重绑定、非接触阶段执行、失败后重布置交给 planner；把 VLA 限制在它最擅长的局部接触阶段。这个问题重要，因为它直接对应 VLA 从 benchmark 走向复杂、扰动环境时的失效模式，而不是单纯追求闭集成功率。

方法拆解

整体 pipeline 很清晰：输入为任务语言、RGB-D 观测、机器人状态；planner 在一个固定 primitive 库上做自回归决策，输出 JSON 形式的结构化 primitive 调用，而不是低层 action。primitive 库包含少量解析控制器（如 MOVE TO、ROTATE、SET GRIPPER、RELEASE，厨房场景再加移动底盘 primitive）以及唯一的学习型 primitive VLA ACT。VLA ACT 调用 frozen VLA，以短 burst 方式执行局部接触动作，并带有 early-return 条件，因此它是“局部尝试”而非整段 rollout 的唯一控制器。

关键机制有两个。第一是两阶段流程：先在单个 reference seed 上做 bootstrapping 探索，允许 RESET，在试错后把成功 primitive 序列抽象成可重 grounding 的 Task Specific Memory；同时把成功规则和失败模型写入 Global Memory。正式评测时禁用 RESET，并在新 seed/扰动下读取这些 memory 做动态重 grounding。第二是重试式 VLA 调用：planner 先用解析 primitive 做 pre-contact staging，再调用 VLA；若接触结果不理想，则调整视角、接近位姿或局部站位，再次调用 VLA。论文没有给出复杂训练公式，方法重点实际上是这个执行接口设计与记忆驱动的编排，而不是学习一个新 policy。

创新点含金量

第一，把 frozen VLA 作为单一“接触专家 primitive”暴露给 agent，而非端到端 rollout。这针对的是 VLA 在长时程、语义绑定和 OOD 扰动下脆弱的问题。这个点有实质创新，尤其是在“职责切分”上很明确，也容易迁移到别的 VLA backbone。

第二，固定且小的 primitive 库 + planner 学习其适用范围。作者刻意不靠扩技能库提性能，而是通过 memory 学会何时解析、何时 VLA。这个思路比“不断添加 skill”更可控，也更适合安全审计。创新性中等偏上，更偏系统设计，但有较强方法论价值，可迁移。

第三，Task Specific Memory 与 Global Memory 的分工。前者存任务成功轨迹并参数化为空间可重 grounding 的结构先验，后者存可复用的成功规则与失败模型。这个设计针对的是 agent 每次从零规划代价高、且容易重复历史错误的问题。更像高质量工程整合，但在机器人 manipulation + frozen VLA 这个组合上是有效的。

实验证据

实验覆盖四类 benchmark：LIBERO、LIBERO-Pro、RoboCasa365、RoboTwin C2R。最关键结果来自扰动和迁移场景。标准 LIBERO 上，Harness VLA(CC) 总体 96.0%，与直接 frozen RLinf 的 95.3% 接近，说明这种 harness 没有明显损伤分布内性能。LIBERO-Pro 上，Harness VLA(CC) 达到 82.4%，相比文中最强相关基线 RATS 的 43.8% 提升 38.6 个百分点；相对同 backbone 的直接 RLinf 50.0% 也有大幅优势。RoboCasa365 上，Harness VLA(Codex) 55.4%，较 RLDX-1 的 30.0% 提升 25.4 个百分点。RoboTwin C2R 上，从直接 LingBot-VLA 的 50.4% 提升到 58.4%。

证据最充分支持的结论是：将 planner 负责重 grounding / staging / retry，能显著扩大 frozen VLA 的有效工作区间，尤其在 instruction redirection 和 position swap 下。机制分析也较扎实：一是零样本 LIBERO-Pro GOAL 中，不用 task-specific memory 时仍优于 Cap-X，说明不是纯靠检索模板；二是限制每回合可调用 VLA 次数的曲线显示，少量但可重试的 VLA 调用就能超过直接 VLA baseline。相对不足的是：论文主要给出成功率，没有更细的代价指标，如平均 primitive 数、调用开销、失败类型分解；memory 构建的人力/时间成本也未系统量化，论文未明确说明。

局限与风险

第一，方法当前依赖bootstrapping reference seed + memory 写入，因此 few-shot 设定下的性能并非纯在线泛化；若任务族变化很大，memory 可复用性边界尚不清楚。第二，系统高度依赖 planner 对 RGB-D 的语义/几何 grounding 能力，若感知更嘈杂、遮挡更强、描述更模糊，planner 可能在错误绑定上反复重试。第三，作者自己承认高层 planner 与低层 VLA 之间仍是开放反馈环，缺少联合优化；这意味着 VLA 的内部不确定性无法被端到端校正。第四，评测以仿真 benchmark 为主，真实机器人上的延迟、感知误差、碰撞安全边界，论文未明确说明。

与我方向的关系

对 VLA / embodied AI 很相关。它提供了一个很强的启发：与其继续把所有能力都塞进单一 VLA，不如把 VLA当作局部接触 skill module，把语义重绑定、长程组合、失败恢复外置到 agentic layer。这对后续做可验证、可调试的 embodied system很有参考价值。

对 multimodal safety / robustness 也有直接价值。固定 primitive 库、结构化 JSON 调用、显式 memory 规则，使系统比端到端 action 更容易做行为审计、失败归因和安全约束注入。若你研究鲁棒性，本文可借鉴的是：把错误局部化到 primitive 调用级别，而不是让一次接触失败污染整段 rollout。推断：这类接口也更适合未来加入 uncertainty-aware stopping、shielding 或 human oversight。

TFP: Temporally Conditioned Memory-Fusion Policies for Visuomotor Learning

作者: Yushen Liang (NYU Shanghai, Shanghai, China); Yue Peng (NYU Shanghai, Shanghai, China); Baosheng Jin (NYU Shanghai, Shanghai, China); Tianluo Zhang (NYU Shanghai, Shanghai, China); Xinyu Zhang (University of Electronic Science and Technology of China, Chengdu, China); Shuyi Zhou (Beijing Institute of Technology, Beijing, China); Zhuoran Chen (NYU Shanghai, Shanghai, China); Xinqi Liu (NYU Shanghai, Shanghai, China); Shenji Wan (NYU Shanghai, Shanghai, China)

方向: VLA | 标签: VLA

简述: 为VLA引入时序记忆融合策略

筛选理由: 面向阶段依赖操控，方法轻量且有增益

Deep Review

一句话判断

这篇论文最值得关注的是：它不是简单给 VLA“加记忆”，而是把随物理时间变化、对事件敏感的潜在任务进度 belief直接注入动作生成头；若你关心 VLA 在长时程、遮挡、阶段依赖操作中的失效机理与改进，这篇值得精读。

核心问题与动机

论文针对的是一类典型但常被低估的问题：许多 VLA 策略本质上是 reactive 的，即基于当前视觉、语言和本体状态预测下一段动作。但在 stage-dependent manipulation 中，视觉上相似的状态可能对应完全不同的动作，区别来自“当前做到第几阶段”“之前接触/放置是否成功”“被遮挡期间目标状态如何演化”等隐变量。

作者认为，现有两类方法都不完全够用：一类是历史检索/历史 token 聚合，能提供上下文，但未必形成紧凑的任务进度状态；另一类是 RNN 式隐状态，虽然有紧凑状态，但更新通常按帧/步/chunk 进行，而不是按操作事件与真实流逝时间校准。论文的核心动机是：chunked control 下，策略重查询间隔本身就是可变的物理时间量，因此 memory 不应只依赖离散 step index。

方法拆解

TFP 是在 chunked VLA backbone（主要实验基于 π0.5）上加一个 episode-local latent belief。每次 policy query 时，输入当前视觉 observation、机器人状态、语言指令、上一步隐状态，以及距上次查询的实际时间间隔 $\Delta t$。视觉与状态先压缩成紧凑表示，再通过 LTC 风格更新得到新的 belief：先由当前输入和旧状态生成候选状态 $\hat h_t$，再预测输入相关的时间常数 $\tau_t$，最后用 $k_t=\exp(-\Delta t/\tau_t)$ 控制保留旧状态还是写入新证据。直观上，稳定/遮挡阶段应高保留，接触/释放/子目标切换附近应更快更新。

关键不在“有个 RNN”，而在这个 belief 直接作用于动作生成。作者将更新后的隐状态投影到 action decoder 条件空间，并与 flow-matching timestep embedding 相加，通过 AdaLN 调制 decoder 各层激活，从而让 temporally accumulated context 直接改变 action chunk 的生成分布，而不是仅作为被动历史。训练上，为兼顾 episode 内隐状态连续性与大模型显存成本，作者提出 EATB：跨多个 episode 并行采样连续 K 个 chunk，数值上持续传递每个 episode 的 hidden state，但在 segment 边界做梯度截断。推理时还使用 adaptive receding-horizon executor，在预测固定 horizon chunk 后，根据 gripper transition、jerk、动作连续性等风险信号决定实际执行前缀长度，因此后续 memory 更新接收到的 $\Delta t$ 是不规则的真实执行间隔。

创新点含金量

第一，把 memory 问题表述为“物理时间校准的任务 belief 更新”，而非普通 history aggregation。它针对的是 reactive VLA 在阶段依赖任务中的根本不足，我认为这是实质性问题定义创新，且可迁移到其他 chunked policy 或 diffusion/flow-based policy。

第二，LTC belief + AdaLN action-head conditioning 的组合是本文最核心的技术点。LTC 本身并非新网络，但用于 VLA 的 episode-local belief tracking，并直接调制 flow-matching action decoder，而非只影响感知或做检索，这一点更接近“实质创新上的新接口设计”，不是纯工程堆叠，迁移性也较强。

第三，EATB 训练机制主要解决 recurrent fine-tuning 的工程可行性问题。它有实际价值，但更偏工程组合创新；对大模型上的时序隐状态训练具有可借鉴性。

第四，事件敏感机制分析（write-gain near events）不是方法创新，但提升了说服力，说明作者确实在验证“belief 是否按事件更新”，而不只是在卷 benchmark。

实验证据

实验覆盖仿真、诊断任务和真实机器人。主 benchmark 上，TFP 在 LIBERO 将平均成功率从 π0.5 的 96.85% 提升到 98.75%，其中 Long split 从 92.4% 提升到 97.0%；在 LIBERO-plus 从 91.4% 提升到 93.77%，在 noise 与 lighting 扰动下提升更明显。这个证据比较充分地支持了“memory 对长时程与视觉扰动有帮助”的主张。与公开方法对比时，作者也强调部分数字来自文献，不是同 pipeline 复现，因此横向比较应谨慎；更可信的是同 backbone、同训练协议下的 controlled ablation。

消融方面最关键的是两组：一是与 GRU、S4D 对比，TFP 在 LIBERO Long 与 LIBERO-plus 平均表现更优，说明收益不只是“加了递归状态”；二是 TFP w/o $\Delta t$，即保留 LTC/AdaLN 架构但把真实时间间隔替换成常数，性能明显下降，支持“elapsed-time conditioning 有效”。机制分析也较强：在 LIBERO mug-in-microwave 中，事件附近的 write-gain 变化约为远离事件阶段的 6 倍；固定 observation/state/instruction 只替换 hidden state 时，生成动作 chunk 会显著变化，支持 belief 对动作有因果影响。真实机方面，Galaxea A1 上 object swap 从 3/20 到 15/20，counting pick-and-place 从 8/20 到 18/20，且失败类型从“阶段错误/重复子任务”转向“目标 grounding/低层执行误差”，这一点相当契合论文主张。不过真实任务数量仍偏少，统计充分性有限。

局限与风险

第一，方法的主要收益集中在阶段依赖、部分可观测、遮挡/扰动场景；对纯短程、强视觉可判别任务的必要性没那么强，甚至从消融看，某些简单 memory variant 还会拖累平均表现，说明记忆模块并非总是稳赚。
第二，训练成本不低。作者明确给出其最大 LIBERO 训练需要超过 100GB GPU 显存、4 张 H200、约 80 小时；这会限制该方法在更大 backbone 或更复杂 embodied setting 的普适采用。
第三，真实机验证范围较窄，仅限桌面单臂 A1 两个任务；对移动操作、双臂、灵巧手、开放环境泛化，论文未明确说明。
第四，MIKASA ShellGameTouch 上 TFP 虽显著优于部分基线，但仍低于 MemoryVLA 的 88%，作者也承认这暴露出其在object-centric hidden-location binding 上仍有缺口，说明紧凑 belief 未必足以解决所有隐藏状态推理问题。

与我方向的关系

和 VLA / embodied AI 很相关。它最大的启发是：对于 chunked generative policy，memory 最有效的接入点不一定是“加更多历史 token”，而可能是构造一个小而稳定、能按事件改写的 belief state，再直接调制动作头。对后续 VLA 研究，可借鉴两点：其一，把策略失效分解为“belief 保持失败”与“belief 改写失败”；其二，在不规则控制周期、接触事件密集的机器人场景中，显式使用 elapsed time 可能比普通 RNN 更自然。

对多模态 safety/robustness 也有启发：论文显示记忆可在噪声、光照扰动、遮挡下稳定动作生成。进一步研究可考虑把 risk-aware re-query、belief uncertainty、异常接触检测结合起来，形成更安全的执行闭环。若你的方向偏 object-centric/world model，这篇也提示：仅有 task-progress belief 还不够，下一步可把对象级隐变量绑定进连续时间记忆中。若做纯语言规划，这篇相关性相对次要。

LEEVLA: Seeing What Matters in Latent Environment Evolution for Vision-Language-Action

作者: Qi Lyu (State Key Laboratory of Robotics and Intelligent Systems; Shenyang Institute of Automation, Chinese Academy of Sciences; University of Chinese Academy of Sciences); Baicheng Liu (State Key Laboratory of Robotics and Intelligent Systems; Shenyang Institute of Automation, Chinese Academy of Sciences); Xudong Wang (State Key Laboratory of Robotics and Intelligent Systems; Shenyang Institute of Automation, Chinese Academy of Sciences; University of Chinese Academy of Sciences); Jiahua Dong (Mohamed bin Zayed University of Artificial Intelligence); Lianqing Liu (State Key Laboratory of Robotics and Intelligent Systems; Shenyang Institute of Automation, Chinese Academy of Sciences); Zhi Han (State Key Laboratory of Robotics and Intelligent Systems; Shenyang Institute of Automation, Chinese Academy of Sciences)

方向: VLA | 标签: VLA

简述: 突出关键视觉证据并建模潜在演化

筛选理由: 聚焦注意与潜在动力学，思路新，需看实验增益与泛化

Deep Review

一句话判断

这篇论文最值得关注的是：它把 VLA 的“看哪里”与“潜空间里怎么演化” 作为训练期显式监督来做，并且不增加推理开销；如果你关心 VLA 中间表征、world-model 式辅助训练或长时程泛化，值得精读。

核心问题与动机

论文要解决的是：现有 VLA 往往把所有视觉 token 一视同仁，或者依赖人工选定的中间线索（如子目标图、分割、深度）做显式推理，导致在复杂动态场景下，模型既难以聚焦真正与任务因果相关的区域，也难以发现“未知但有用”的潜在因素。

作者的核心动机有两层。第一，训练信号被静态背景和无关物体稀释，所以需要一个机制告诉模型“哪里值得学”；第二，若只做普通的未来特征预测，高维潜空间容易失去局部语义结构，因此还需要约束“这些关键特征应如何演化”。论文因此提出一个训练框架：用 DGDP 解决 where to attend，用 SFFG 解决 how to evolve。

方法拆解

整体上，LEEVLA 仍沿用标准 VLA 设定：输入第三视角图像、腕部相机图像、本体状态和语言指令，经视觉编码器（DINOv2 + SigLIP）、projector、语言 tokenizer 和状态编码后送入 LLM，最后由并行连续动作预测头输出 action chunk。与 OpenVLA 类似，动作监督仍是 L1 回归；新增部分主要发生在训练期辅助损失中。

DGDP 的关键是给未来特征预测加 patch 级权重。DPP 用相邻时刻同一 patch 的余弦变化量衡量“动态性”；SDG 再看该 patch 与语言 token 的相关度在 \(t\) 到 \(t+T\) 之间是朝任务相关方向漂移还是背离。两者合成权重 \(\beta_i\)，用于强调“变化大且越来越和指令相关”的区域，而压低静态背景或语义上偏离任务的区域。

SFFG 则约束未来特征预测的结构。作者先对 \(t+T\) 的多视角 patch 特征联合聚类，再按“离簇中心从近到远”构造 prototype-to-periphery (P2P) 顺序，并在这个顺序上计算未来特征预测损失，避免扁平 token 顺序破坏局部语义连续性。进一步地，作者构造一阶/二阶 kNN 图，只保留互为邻居的高置信正样本，用 MC contrastive loss 保持局部拓扑一致。总损失为动作 L1、P2P 和 MC 三项加权和。论文明确说明 DGDP 和 SFFG 只在训练时使用，测试时无额外内存和延迟负担。

创新点含金量

第一，DGDP：动态性 + 语义漂移联合加权。它针对的是“视觉 token 均匀训练导致监督被稀释”的不足。这个点比单纯 attention 可视化或 instruction-aligned token selection 更进一步，因为它显式利用了时间变化和语言相关性变化方向。我判断这是有一定实质性的训练机制创新，且可迁移到视频决策、多模态预测控制中。

第二，P2P 结构化未来特征预测。它针对普通扁平 token 预测破坏局部语义结构的问题。思想上接近“让潜空间预测遵循簇内结构”，属于中等强度创新：核心不在新 backbone，而在重新定义 latent forecasting 的组织方式。可迁移性较强，尤其适用于 token 化视觉状态预测。

第三，互邻域对比损失 MC。它针对聚类噪声和非对称邻接关系，保留 reciprocal neighbors 做对比学习。这个点更像稳健化工程组合，但和本文的 latent topology 目标是匹配的，实用价值高，理论新颖性相对有限。

实验证据

实验覆盖两类基准：LIBERO 和 CALVIN，并给出小模型（LEEVLA-mini, 0.5B）和大模型（LEEVLA-large, 7B）结果。LIBERO 上，LEEVLA-mini 平均 97.5%，高于 FLOWER 的 95.7% 与 DreamVLA 的 92.6%；LEEVLA-large 平均 98.2%，高于 OpenVLA-OFT 的 97.1%、π0.5 的 97.5%。CALVIN 上，LEEVLA-large 平均 length 4.34，也高于 OpenVLA-OFT 的 4.10。就“是否比当前强 baseline 更好”而言，证据是充分的。

消融也比较关键。以 LIBERO-Goal 为例，base 为 94.8%，加 P2P 到 95.2%，再加 MC 到 95.6%，再加 DPP 到 96.3%，最后加 SDG 到 97.0%。这说明两条主线都有贡献，其中 DPP 提升最大。另外，作者还验证了 feature reorder（95.2 vs 94.7）和全局因子 \(\alpha\)（97.0 vs 95.8）的作用，支持其设计并非纯拍脑袋。

但也有证据不足之处。真实机器人实验只和 OpenVLA 比较，任务数也较少，虽然表中给出 Place/Press/Drawer/Long 的提升，但“Average=78.5”与分项数值之间看起来存在不一致，原文未解释。复杂度分析显示MC 训练延迟很高（1200.91ms），说明训练收益并非免费；作者强调推理无开销，这一点被表格支持。

局限与风险

第一，方法依赖未来特征可预测且对动作有辨识度这一前提；若任务关键因子在视觉 backbone 特征中本就弱、或语言相关性难以由点积捕捉，DGDP/SDG 可能失效。这是基于方法机制的推断。

第二，真实世界证据偏弱。论文只报告 3 个实体任务、每个 20 次连续试验，且 baseline 很有限，尚不足以证明在开放场景、遮挡、光照变化或跨机器人平台上的稳健性。

第三，训练过程较复杂：聚类、未来特征解码、互邻域图、对比损失都引入额外实现成本。尤其 MC 延迟高，说明如果要在更大分辨率或更长时域上扩展，训练效率可能成为瓶颈。

第四，论文把“未知任务相关因素”的发现作为动机之一，但实验主要验证的是成功率提升，并未直接证明模型确实捕捉到了哪些“未知因素”；这一点论文未明确说明。

与我方向的关系

对 VLA / embodied AI 很相关。它的启发不是换更大 backbone，而是：在不改推理图的前提下，用训练期辅助目标把策略学习拉向更好的中间表征。这对做高效 VLA 很有价值，尤其适合“推理预算固定、训练可更重”的设定。

对 world model + policy 联合训练 也有借鉴意义。本文没有做视频生成控制，而是把未来预测降到 latent auxiliary supervision，这是一条比端到端生成更轻的路线。对 多模态 safety/robustness，DGDP 的“任务相关证据加权”思路可扩展到异常干扰抑制、指令冲突检测或 OOD 关注区域约束，但论文本身没有安全性实验，相关结论只能算推断。

FabriVLA: A Lightweight Vision-Language-Action Model for Precise Multi-Task Manipulation

作者: Shiyuan Yang (University of Macau); Borong Zhang (University of Macau); Jizheng Zhang (University of Macau); Zhijia Tao (University of Macau); Junfei Guo (Mese Technology Limited Co., Ltd.); Donglai Ran (FabriX team at Youibot Robotics Co., Ltd.); Xu Bian (FabriX team at Youibot Robotics Co., Ltd.); Qingbiao Li (University of Macau)

方向: VLA | 标签: VLA

简述: 轻量VLA实现高精度多任务操控

筛选理由: 1B级轻量方案效果强，但仅Meta-World验证

Deep Review

一句话判断

这篇论文最值得关注的是：在 不到 1B 参数的轻量 VLA 上，通过 gated self-attention + 浅层/深层 VLM 特征融合 + 单阶段联合训练，在 Meta-World MT50 上做到 90.0% tier-average；如果你关心 小模型 VLA 的结构设计与训练配方，值得精读。

核心问题与动机

论文要解决的是：现有 VLA 虽然能做多任务操作，但常依赖数十亿参数骨干，推理代价高、实时控制不友好；而轻量模型往往又难兼顾语言语义、精确空间定位和长时序动作建模。作者希望证明，一个 1B 级别以内的 VLM 骨干，经过合适的动作头设计，也能在精细多任务操作中取得强结果。

现有方法的关键不足，文中主要指向两点。其一，轻量 VLA 的动作建模能力不够，尤其对 50-step 动作 chunk 内的时序依赖捕获不足。其二，仅用 VLM 最深层特征可能有语义但缺少精细空间细节，不利于精确定位、接触式操作和插入类任务。

方法拆解

整体 pipeline 很清晰：输入是 单张 corner-view RGB 图像、语言指令、24 维机器人状态；输出是 50×24 的动作 chunk 速度场预测，再通过 flow matching 的 Euler 积分从噪声逐步生成动作序列，最终只执行 Meta-World 有效的 4 维动作，并以 receding horizon 闭环方式控制。

结构上分三块。第一块是 InternVL3.5-1B 骨干，保留 14 层，将视觉 token 与文本 token 融合。第二块是状态与动作编码：状态经两层 MLP 变成一个 state token 并拼到上下文中；噪声动作序列逐步编码成 50 个 action tokens。第三块是关键的 flow-matching action head：8 层 Transformer block，每层先做一个带门控的 action-token self-attention，再 cross-attend 到 VLM 上下文，最后加上 flow timestep 的时间条件做 FFN。门控参数 初始化为 0，意味着模型起步时退化成“仅 cross-attention”的更易优化形式，训练中再逐渐学会动作步之间依赖。

另一个关键机制是 浅层特征融合：除了第 14 层深层语义特征，额外取第 6 层特征，经 concat+linear 投回 1024 维，且投影初始化为 `[I|0]`，保证一开始与 deep-only 完全等价。这个设计本质上是在不破坏预训练语义对齐的前提下，给动作头补充更细的空间信息。训练采用 单阶段联合优化：VLM 与动作头从一开始一起训，VLM 不冻结。flow matching 部分使用均匀噪声到专家动作的线性插值，训练目标就是预测速度场 `a-ε`。

创新点含金量

第一，gated self-attention in action head。它针对的是长 horizon 动作 token 之间难建模、直接加自注意力又可能训练不稳的问题。这个点属于 小而实的结构创新，不是纯工程拼装；其“零初始化门控残差”思路也较易迁移到 diffusion/flow-based policy 头中。

第二，浅层-深层 VLM 特征融合。针对的是深层语义强但空间细节弱的问题。创新性中等，更像 高质量工程设计，但初始化为 deep-only 等价、训练后再决定是否利用浅层，这个做法很干净，具有不错可迁移性，尤其适合精细 manipulation。

第三，从预训练 VLM 出发的单阶段全量联合训练。这不是架构创新，但属于值得注意的训练结论：作者明确指出若仅 BF16 而无 FP32 master weights，VLM 参数几乎不更新。这个经验对小学习率微调 VLA 很实用，但更偏 训练工程贡献。

实验证据

实验全部围绕 Meta-World MT50。训练数据使用公开的 Evo-1 demonstration dataset，共 2500 条轨迹，每任务 50 条。评测协议是 50 个任务、每任务 10 个 episode、总 500 个 episode。主要对比包括 TinyVLA、π0、SmolVLA、RoboTron-Mani、Evo-1、Evo-Depth、LA4VLA。FabriVLA 以 0.89B 参数 达到 90.0% tier-average、92.0% overall episode-level，在表中 tier-average 最优，说明“轻量模型也能很强”的核心结论是被支持的。

消融里最有说服力的是两项。其一，浅层融合相对 deep-only，将 tier-average 从 82.9 提升到 90.0，overall 从 86.8 提升到 92.0，且各难度层都提升，这对“浅层空间信息有用”支持较充分。其二，动作头模块累积消融显示 gated self-attention 是决定性组件：tier-average 从 48.5 提到 57.7，而再叠加 token-residual head 或 temporal conv 都变差。这个因果链条比较清楚。

但也有证据不足之处。首先，模块消融是在 冻结 VLM、只训 50k steps、且训练设置弱于正式模型 的条件下做的，因此能支持“相对比较”，但不能完全外推到最终 full fine-tuning 场景。其次，对比表中的 baseline 数字来自各自论文，训练数据、预训练 recipe、输入模态未必完全一致；论文承认部分方法有 robotic pretraining 或 MixPT，因此“绝对公平性”有限。

局限与风险

第一，论文验证几乎全部来自 Meta-World 仿真，没有真实机器人结果，也没有跨 embodiment 或跨环境泛化实验，因此对真实部署价值仍需保留判断。

第二，输入最终只用 corner 单视角 RGB，虽然结果强，但这也可能限制遮挡、视角变化和复杂 3D 几何场景下的鲁棒性。论文未明确说明多视角/深度失效情形。

第三，训练数据规模其实不大，仅 2500 条轨迹，这说明方法数据效率可能不错，但也意味着结果可能较依赖 Meta-World 的任务分布与状态可观测性；对开放场景长尾操作的结论不能直接外推。

第四，动作生成虽然是 50-step flow matching，但最终执行的是 Meta-World 有效 4 维动作。对更高维真实机械臂控制、双臂、灵巧手场景是否仍成立，论文未明确说明。

与我方向的关系

对 VLA/embodied AI 很相关。最直接的启发是：小模型不一定输，关键在于 动作头是否能补足 VLM 不擅长的时序与精定位能力。如果你做轻量 VLA，这篇文章提供了一个很可复用的设计范式：冻结语义对齐、逐步打开动作 token 交互、补浅层视觉细节。

对 multimodal safety/robustness 的直接贡献不多，论文没有安全约束、OOD 鲁棒性、对抗扰动或不确定性评估。但从研究延伸看，浅层融合可能带来对视觉噪声更敏感的风险，而 gated self-attention 可能影响长时序误差累积；这些都值得后续做鲁棒性分析。这个判断属于推断。

FabriVLA 表明，在 Meta-World 多任务操作上，基于约 1B 级 VLM 的轻量 VLA 只要配合门控时序动作头与浅层空间特征融合，也能达到接近或超过更大模型的性能。

WCog-VLA: A Dual-Level World-Cognitive Vision-Language-Action Model for End-to-End Autonomous Driving

作者: Xuerun Yan (Tongji University, China; Nanyang Technological University, Singapore); Zhexi Lian (Tongji University, China); Nuoheng Zhang (Tongji University, China); Shiyu Fang (Tongji University, China); Haoran Wang (Tongji University, China); Chen Lv (Nanyang Technological University, Singapore); Jia Hu (Tongji University, China); Binyang Song (Nanyang Technological University, Singapore)

方向: VLA | 标签: VLA

简述: 双层世界认知VLA实现主动驾驶

筛选理由: 思路新且NAVSIM达SOTA，但需验证泛化与复杂度

Deep Review

一句话判断

这篇论文最值得关注的是把语义层世界认知/推理与生成层联合多车轨迹世界演化明确耦合进 VLA，并在 NAVSIM 上给出较强 SOTA 证据；如果你关心 VLA 从“反应式驾驶”走向“主动式驾驶”，值得精读。

核心问题与动机

论文聚焦于端到端自动驾驶里的一个关键缺口：现有 VLA 虽然能把视觉、语言和动作统一起来，但多数仍停留在“看到什么就做什么”的反应式规划，缺少对当前世界状态、他车未来意图、以及 ego-他车交互后果的系统建模。作者认为，问题不只是缺 3D 空间感知，还在于“世界认知”被割裂：有些方法只做语义预测，有些只把 world model 当辅助任务，却没有在动作生成阶段真正利用可交互的未来世界演化。

因此，论文试图回答：如何让 VLA 同时具备语义层 forecasting 与生成层 evolution，从而支持主动驾驶。这个动机是成立的，因为自动驾驶中的长尾场景、本质上常常要求模型提前推断周车反应，而不仅是拟合单车轨迹。

方法拆解

整体框架 WCog-VLA 分成两部分。第一部分是 VLM backbone：输入包括 6 路环视图像、导航指令、ego 状态（速度、加速度、2 秒历史轨迹）。在视觉编码之外，作者额外用 BEVFormer + TrackFormer 从多视角特征中提取 agent tokens，把 2D VLM 扩展到带显式 3D 空间结构的表示。视觉 token、文本 token、agent token 一起送入 InternVL3-2B/Qwen2.5 组成的主干 LLM。随后，输出 hidden states 被“功能解耦”：`O_agent` 送到 world head，监督当前 3D 感知和周车未来轨迹；`O_vision/O_text` 用于语言生成，并在 Game-CoT 数据上学习四步式博弈推理。

第二部分是生成世界模型 ADDT。它不是直接让 VLM 输出动作，而是把 VLM hidden states 作为条件，生成ego + surrounding agents 的联合轨迹。核心设计是 decoupled diffusion transformer：condition encoder 专注抽取语义交互信息，generation decoder 专注恢复高频轨迹细节。为减少扩散推理步数、稳定不同 denoising step 的语义一致性，作者加入表示对齐：把 condition encoder 中间层特征与一个预训练轨迹 VAE 的 latent scene representation 做 cosine alignment。训练上分四阶段：先训 3D 感知模块，再联合微调 VLM 与 world head，再冻结 VLM 训练 ADDT，最后用 DiffGRPO 做强化微调，奖励由 ego 的 PDMS 与周车预测误差共同构成。

创新点含金量

第一个创新是双层世界认知框架：把 semantic forecasting 和 generative evolution 放在同一 VLA 中闭环起来。它针对的是过去“只理解、不演化”或“只生成 ego、不建模交互”的不足。我认为这是本文最有价值的实质创新，且可迁移到 embodied planning、机器人交互预测等任务。

第二个创新是 ADDT 的解耦式扩散生成器 + latent alignment。它针对单一 diffusion transformer 同时承担抽象语义编码和精细轨迹解码时的优化冲突。这里既有方法论成分，也有一定工程组合色彩：decoupled encoder-decoder 与表示对齐的想法本身不完全新，但在“VLM cognition → joint multi-agent motion generation”的接口设计上比较完整，可迁移性较强。

第三个创新是 Game-CoT 数据集（85k）。它补足了自动驾驶 VLA 中较少涉及的 game-theoretic reasoning 监督，尤其是“if-what imagination + payoff evaluation”。但这里更偏数据工程与监督设计创新，价值取决于标注质量和泛化性，而论文对人工校验或噪声分析展示有限。

实验证据

实验主要在 NAVSIM v1/v2。NAVSIM v1 上，WCog-VLA 达到 92.9 PDMS，优于 ReCogDrive-2B（90.8）、AutoVLA-3B（92.1）、LatentVLA-3B（92.4），也超过若干相机+激光雷达方法。安全相关指标上 NC=99.4、TTC=98.5，支持“主动预判提升安全性”的主张。NAVSIM v2 上，三阶段 SFT 版本取得 85.9 EPDMS，也优于表中基线。就 benchmark 结果看，论文的主结论——双层 world cognition 能提升规划表现——是被较充分支持的。

消融也比较到位。四阶段训练从 84.4 提升到 92.9，说明 3D 感知、ADDT、RFT 都有贡献；双层世界认知消融显示，单独加 semantic 或 generative 都涨分，二者结合最好（86.5→89.3）；ADDT 对比标准 SDT 和去掉 alignment/decoupling 的变体也有稳定收益，并展示 5-step 推理即可接近甚至优于 20-step baseline。不过仍有证据不足之处：Game-CoT 的真实性、推理文本与最终动作间因果关系、以及 RL 阶段是否带来更强 out-of-distribution 鲁棒性，论文没有更深入分析。开放道路或跨数据集泛化也未展示，论文未明确说明。

局限与风险

第一，作者自己承认当前 semantic cognition 主要聚焦agents，没有显式建模未来道路几何与地图拓扑演化。这意味着在施工改道、临时障碍、复杂路权变化场景中，能力边界可能明显。

第二，Game-CoT 是由 Qwen3-VL-Plus 自动生成，并且引入 GT action 作为提示来重建因果链。这有助于减少幻觉，但也可能带来“事后解释式推理”的风险；即推理文本更像对 GT 的对齐，而不一定代表真实决策过程。论文没有提供人审一致性或推理正确率评估。

第三，生成层虽然强调联合多车轨迹，但训练和奖励仍主要围绕 NAVSIM 指标展开。对真实闭环部署中的时延、失效恢复、极端交互鲁棒性，论文证据有限。尤其 5-step diffusion 虽快，但系统级实时性是否足以车端部署，论文未明确说明。

第四，方法依赖较复杂的多阶段训练与外部模块堆叠（BEVFormer、TrackFormer、VAE、DiffGRPO），研究价值高于部署简洁性；复现和工程稳定性成本可能不低。

与我方向的关系

与 VLA/embodied AI 非常相关。它提供了一个很清晰的范式：把“语言/语义推理产生的世界认知”显式桥接到“可交互未来的生成模型”，而不是让 VLM 直接吐动作。这对通用机器人同样有启发，比如人机协作、导航操作中，可先做语义层 agent-state reasoning，再做生成层 interaction rollout。

对多模态 safety/robustness 也有启发：其安全提升并非来自显式规则，而是来自更好的“周围体意图预测 + 联合未来采样”。后续可借鉴其 dual-level design，但应进一步研究：如何验证 reasoning 的可信度、如何把不确定性显式暴露给 policy、以及如何把 map/topology 演化也纳入 world cognition。

Post-Training in End-to-End Autonomous Driving

作者: Ruining Yang (Northeastern University, Boston, USA); Muxing Wang (Northeastern University, Boston, USA); Yixiao Chen (Northeastern University, Boston, USA); Tongfei Guo (Northeastern University, Boston, USA); Yi Xu (Northeastern University, Boston, USA); Can Cui (Purdue University, West Lafayette, USA); Zichong Yang (Purdue University, West Lafayette, USA); Yitian Zhang (Northeastern University, Boston, USA); Ziran Wang (Purdue University, West Lafayette, USA); Yun Fu (Northeastern University, Boston, USA); Lili Su (Northeastern University, Boston, USA)

方向: 其他 | 标签: VLA

简述: 综述自动驾驶后训练方法谱系

筛选理由: 系统梳理后训练范式，适合快速建图

Deep Review

一句话判断

这是一篇把端到端自动驾驶“后训练”系统化定义并统一归类的综述，最大价值在于给出 distillation / preference alignment / RL / test-time refinement 的统一视角；如果你做 VLA/闭环训练/对齐，值得精读，否则可作为快速查阅型综述。

核心问题与动机

论文关注的不是新的驾驶模型，而是一个被以往文献割裂讨论的问题：端到端自动驾驶在 imitation learning 之后，如何继续提升闭环行为质量。作者强调，自动驾驶不同于普通监督学习，开环模仿即使拟合专家轨迹很好，到了闭环执行时仍会出现误差累积、恢复行为稀缺，以及安全/舒适/交互等长时域目标无法由逐点标签刻画的问题。

现有方法的关键不足在于：一类工作仍停留在离线 imitation；另一类虽已引入奖励、偏好或 verifier，但缺少统一定义，导致“后训练”常被混在 RL、对齐或 test-time scaling 中分别讨论。本文的动机就是把这些方法放到同一框架下，明确它们本质上都在利用超出初始专家演示的数据与监督去修正预训练好的驾驶策略。

方法拆解

这篇论文是综述，不提出新的算法 pipeline，而是提出一个两阶段统一范式：第一阶段用 imitation learning 获得初始驾驶能力；第二阶段进行 post-training，在预训练策略邻域内，用新的监督信号优化闭环表现。作者给出统一目标：在 imitation policy 周围的小邻域中，使用 post-training 数据与信号最小化相应损失，并可加参考策略正则；test-time refinement 则不更新参数，而是在候选输出中用 verifier 选最优。

四大类方法的拆解比较清晰。Distillation 用强教师策略提供稠密指导，核心价值在于给学生 rollout 访问到的状态重新打标签，缓解 distribution shift。Preference-based alignment 用优劣轨迹对直接更新策略，重点不在显式 reward model，而在如何构造有信息量的偏好对。RL post-training 把规则分数、学习到的 critic、世界模型、反事实优势、推理一致性等都视作 reward supervision，再讨论 rollout 构造和策略优化（如 GRPO、PPO、actor-critic）。Test-time refinement 则通过 Best-of-N、rerank、自反思修正等方式，在不改参数的前提下提升输出质量。本文最有用之处是把“监督形式”而不是“模型架构”作为主轴。

创新点含金量

第一，把 post-training 定义为独立阶段并形式化统一目标。这是在回应“闭环优化被零散命名”的不足，属于概念层面的实质整理，对后续研究和写综述都很可迁移。

第二，按监督信号而非模型类型划分四大家族。这比按 VLA、planner、world model 分类更抓住本质，因为很多方法跨架构共享同一优化范式。这个贡献更偏高质量方法学归纳，不是算法创新，但很适合迁移到 embodied policy post-training 的讨论。

第三，把 RL 设计空间进一步拆成 reward design、rollout collection、policy optimization。这针对以往 RL-for-driving 讨论过于扁平的问题，属于有分析深度的结构化综述，尤其适合研究者定位瓶颈：奖励本身、采样分布，还是优化器。

第四，单列 evaluation challenges，强调 open-loop 与 closed-loop 的错配、benchmark saturation、真实车评测不可比、推理成本缺报。这不是新方法，但对审稿和做实验设计很有现实价值，可迁移性强。

实验证据

作为综述，本文的“实验证据”主要来自对已有论文结果的汇总，而非作者自己统一复现。文中整理了 open-loop（nuScenes、WOD-E2E）与 pseudo/closed-loop（NAVSIM v1/v2、Bench2Drive）结果表，并区分是否使用 foundation-model backbone。它支持的最强结论不是“某类方法一定最好”，而是：后训练已成为端到端驾驶的重要趋势，且闭环评测应比开环指标更受重视。

被较充分支持的判断包括：开环指标不能可靠反映闭环行为；NAVSIM 分数已有一定饱和倾向；许多最新方法在 NAVSIM/Bench2Drive 上报告改进，但横向比较受 backbone、协议和算力差异影响。证据不足之处也很明显：论文没有做统一重跑或元分析，因此无法严格比较四类方法谁更优，也无法得出某种监督信号在何种场景下一定胜出的因果结论。真实车辆效果方面，作者只指出少量工作已有报告，但论文未明确说明可比的统一结论。

局限与风险

首先，这是一篇框架性综述，不是经验性 benchmark paper。因此它能帮助你建模问题空间，但不能替代“该用哪条技术路线”的定量决策。若你想知道 preference vs RL 的真实收益差，本文证据不够。

其次，文中大量讨论集中于近年的 VLA/GRPO/世界模型脉络，虽然覆盖面广，但也可能带来一种印象：RL-style post-training 是主流答案。这个结论更像推断，因为作者自己也承认评测仍受采样、奖励、基座模型影响。

第三，很多开放问题被提出得很准确，例如 reward-exploration coupling、behavior-relevant world models、data-feedback loop，但这些更多是研究议程，论文未明确说明可操作的标准解法。

第四，从审稿视角看，文中汇总表的比较维度并不完全统一，尤其 backbone 大小、是否使用 foundation model、是否含 test-time scaling 均不同，因此读者若直接拿表中分数做方法优劣排序，风险较大。

与我方向的关系

与 VLA/embodied AI 高度相关。本文最大的启发是：自动驾驶后训练并不是孤立问题，而是具身策略在安全关键闭环环境中的通用对齐问题。把监督分成 teacher / preference / reward / verifier 四类，对 VLA 机器人、导航 agent、操作策略都可直接借鉴。

对 multimodal safety/robustness 也有价值。文中反复强调 recovery data、takeover logs、counterfactual feedback、world-model outcome supervision，这些都对应“模型不仅要会做对，还要会从错中恢复”。如果你做 embodied safety，可直接借用其观点：比起单纯 SFT，更关键的是构建失败—反馈—再训练闭环。若做多模态推理，文中关于 reasoning-consistency reward 与 test-time self-reflection 的梳理也值得参考。
