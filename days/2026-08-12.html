Lost in Reconstruction: Aligning Action Representations with Language in Vision-Language-Action Models

作者: Li Wenjie (Carnegie Mellon University); Yash Jangir (Carnegie Mellon University); Ignacy Stepka (Carnegie Mellon University); Yash Agarwal (Carnegie Mellon University); Marion Kipsang (Carnegie Mellon University); Yonatan Bisk (Carnegie Mellon University)

方向: VLA | 标签: VLA

简述: 让动作表征对齐语言

筛选理由: 方法新颖，且显著提升语言条件控制性能

Deep Review

一句话判断

这篇论文最值得关注的是它把 VLA 的瓶颈明确定位在“动作离散化接口的语义丢失”，并用一个仅改 tokenizer 训练阶段的 SALT 显著提升下游控制成功率；如果你做 VLA/embodied AI，这篇值得精读。

核心问题与动机

论文讨论的问题很具体：现有 VLA 往往把动作表示优化成“便于重建”的数值编码，但语言中的动词不仅描述结果，还描述动作是如何执行的；而 L1/L2 或纯重建目标并不保证这些语言上重要的差异会被保留下来。作者认为，这会在 VLM 到机器人控制的接口处形成一个系统性瓶颈。

动机部分做得比较扎实。作者先在 BridgeV2 上证明：动词语义既来自视觉终态变化，也来自 7-DoF 轨迹本身的运动动态，且两者互补。也就是说，仅靠 vision-language alignment 不够，动作表示本身也必须对语言友好。这个论点对 VLA 很关键，因为很多工作默认“只要动作可执行、重建误差小，语义自然能被下游 policy 学回来”，本文正面质疑了这个假设。

方法拆解

整体 pipeline 分两段。第一段训练动作 tokenizer：基线是 residual VQ-VAE，把 8-step、7-DoF action chunk 编成 7 个离散 code；SALT 在此基础上额外加入语言对齐损失。具体做法是，把每个 chunk 的量化 latent 相加得到 `q_i`，再映射成 soft prefix embedding，加位置编码后喂给一个冻结的预训练语言模型，并要求它生成该 episode 的自然语言 instruction。

训练目标为 `L = L_recon + L_VQ + λL_align`。关键不在公式本身，而在监督信号的方向：SALT 不是直接让 token 预测 verb label，也不是做对比学习，而是让“量化后的动作潜变量”足以支持 instruction generation。这样梯度会通过 straight-through quantizer 回传到 encoder 和 codebook，改变动作空间如何被切分。推理和下游 VLA 训练阶段则不变：训完 tokenizer 后冻结，policy 仍像普通离散动作 VLA 一样预测 token ID，再解码成连续动作。

创新点含金量

第一，作者把“动作表示是否保留语言语义”提出为 VLA 的独立研究问题，并用 mutual information/verb decodability 做诊断。这个点针对的是以往只盯视觉-语言对齐、忽略 action-language alignment 的不足，属于实质性问题定义创新，可迁移到其他动作表示研究。

第二，SALT 用冻结 VLM/LM 的 instruction generation 作为 tokenizer 的辅助目标。它针对的是纯重建 tokenizer 的语义塌缩问题；方法上属于在 VQ-VAE 上加一个设计得比较干净的辅助监督，创新强度中等，更像“有洞察的机制改造”而非全新范式，但很可迁移。

第三，论文展示了语义对齐会重组 codebook，使其出现 verb-specialized codes。这个发现本身不是新架构，但它把“可解释的离散动作词表”与性能提升联系起来，对后续做可控、可诊断 VLA 很有价值。

实验证据

证据链是完整的。诊断实验在 BridgeV2 上先证明 motion dynamics 对 verb grounding 有独特贡献：联合表示比单独 goal 或 motion 信息更强，motion 相比 goal 还能额外贡献 0.059 bits。随后作者比较 Bin、FAST、VQ-VAE 三类 tokenizer，发现随着压缩增强，tokenized actions 与 verb 的 mutual information 普遍下降，说明“重建好”不等于“语义保真”。

下游实验用 miniVLA + BridgeV2 训练，在 SimplerEnv WidowX 四个任务上评估。SALT 平均成功率 71.9%，显著高于 reconstruction-only VQ-VAE 的 42.7% 和 FAST 的 31.2%；而且 SALT 与 VQ-VAE 架构、容量、数据、VLA 训练流程一致，因此 29.2 个点的提升基本支持“对齐损失改变了动作词表质量”这一主结论。另一个重要证据是，SALT 的重建误差 0.088 与 VQ-VAE 的 0.080 接近，说明收益不是靠牺牲执行精度换来的。相对不足的是，评测仍限于单数据集、单小模型、仿真环境，真实机器人泛化与大规模预训练场景尚未验证。

局限与风险

第一，语言覆盖面偏窄。BridgeV2 过滤后只有 17 个 verb class，且类别极不均衡，因此论文证明的是“有限动词集合上的对齐收益”，对更开放语言空间的外推仍不足。

第二，方法目前只适用于可学习 tokenizer。对 Bin、FAST 这类固定或信号处理式离散化，论文未给出如何施加类似语义监督。

第三，性能提升的因果机制仍未被真正拆开。论文观察到 verb-specialized code 与成功率同时提升，但没有证明究竟是哪些结构变化直接改善了 policy learning。

第四，闭环部署证据有限。评测使用 SimplerEnv visual-matching 套件和 open-loop 8-step chunks；在分布外物体、扰动、传感噪声或真实接触误差下是否同样稳健，论文未明确说明。

与我方向的关系

对 VLA 很相关。它的直接启发是：动作 tokenizer 不应只追求压缩率和重建误差，还应作为“语言语义的承载层”来设计；这对离散动作 VLA、latent action pretraining、甚至连续动作上的 representation shaping 都有参考价值。

对 embodied AI 而言，本文把“verb grounding partly lives in action trajectories”说清楚了，这对技能抽象、层级控制、以及从 demonstration 中学习可组合动作词汇都很有启发。对 multimodal safety/robustness，推断：语义更清晰的动作码本可能有助于做指令一致性检测、异常动作解释和安全约束挂钩，但本文没有直接做 safety 实验，因此这里只能作为研究方向参考。

World Tokens: Enhancing Embodied Policies with Training-Time World Modeling

作者: Qu Tang (JIUTIAN Research; Zhongguancun Academy); Benhui Zhuang (JIUTIAN Research; Zhongguancun Academy); Bo Yuan (JIUTIAN Research; Zhongguancun Academy); Xue Yu (JIUTIAN Research; Zhongguancun Academy); Longteng Guo (JIUTIAN Research; Zhongguancun Academy); Junlan Feng (JIUTIAN Research; Zhongguancun Academy)

方向: VLA | 标签: VLA

简述: 训练期世界建模增强VLA策略

筛选理由: 兼顾性能与部署成本，训练范式有参考价值

Deep Review

一句话判断

这篇论文最值得关注的是：它把 world model 的收益限制在训练期，通过 `World Adapter + world tokens + exclusive routing` 让未来视频监督直接塑造控制表征，并在部署时基本保持 VLA 级延迟；如果你关心 VLA 如何低成本吸收时序动力学信息，这篇值得精读。

核心问题与动机

论文要解决的是 VLA 在闭环控制里虽然快，但缺少对“场景将如何演化”的显式建模，尤其是接触、遮挡、物体位移这类对动作选择很关键的时序变化。作者认为，纯图文预训练给不到这类监督，VLA 只能从有限机器人示教中硬学，导致长时程任务和跨分布泛化受限。

现有 WAM 虽然能用视频世界模型补上动力学建模，但代价通常是推理时仍要保留视频生成或大型视频骨干，控制延迟高。作者抓住的核心矛盾很清楚：能不能只在训练时利用 world model 塑造表征，而部署时完全去掉视频分支，同时又避免辅助预测分支被动作头“绕过”。

方法拆解

整体 pipeline 很直接。输入是多视角 RGB 观测和语言指令，先经预训练 VLM 得到可变长视觉-语言 token 序列；随后 `World Adapter` 用类似 Perceiver resampler 的 learned queries，把该序列压成固定 `256` 个 world tokens。动作头是 flow-matching DiT，只允许读取这组 world tokens 作为唯一视觉-语言上下文，不能直接访问原始 VLM hidden states。

训练时额外接一个视频 world model 分支：把 world tokens 线性投影后，送入联合微调的 future-video denoiser，监督目标是未来 8 帧视频 latent。关键设计有两个。第一，`exclusive routing`：动作专家只能看 world tokens，因此视频去噪梯度会直接塑造动作真正使用的表征。第二，首帧条件不用 RGB，而用主视角 Canny edge 经 VAE 编码后的 structural anchor，迫使视频分支更多依赖 world tokens 提供语义与演化信息，而不是靠外观延续“偷懒”。总损失是动作去噪损失与视频去噪损失加权和，文中设 `lambda_w=0.5`。部署时完全删除视频分支，只保留 VLM、World Adapter 和动作头，4 步 flow integration 生成动作 chunk。

创新点含金量

第一，训练期 world modeling、测试期剥离视频分支。针对的是 WAM 推理慢的问题，这属于比较扎实的体系设计创新，不只是口号，因为论文明确把性能-延迟一起做了对照；可迁移性较强，适合其他 VLA 或 policy backbone。

第二，world tokens 作为共享且唯一的控制接口。针对的是预测监督与动作表征脱耦的问题。这一点比“多加一个辅助预测头”更实质，因为作者用 exclusive routing 明确阻止 bypass，消融也支撑这一机制有效；这一设计很可能可迁移到其他多任务/辅助监督式 embodied policy。

第三，query-based adapter 取代简单 FFN 压缩。这更像是与前述接口设计配套的关键工程选择，而非全新范式，但消融显示它不是可有可无的细节。第四，edge anchor 作为抑制外观泄漏的结构条件，想法巧妙、效果明显，但更偏工程启发，且手工设计成分较重。

实验证据

证据总体是够用的。LIBERO 上，2B、无 embodied action pretraining 的 World Tokens 平均 `98.2%`，高于 matched baseline Qwen-GR00T 的 `96.9%`，提升主要集中在 Long suite：`97.0%` 对 `92.8%`。这很重要，因为它更直接对应作者宣称的“动力学感知”收益。延迟上，World Tokens 为 `61.85 ms/chunk`，接近 `pi0.5` 的 `56.32 ms`，显著低于文中列举的大多数在线 WAM。

消融是本文最有说服力的部分。去掉 world-model supervision，Long 从 `97.0` 降到 `95.0`；保留视频监督但允许 VLM bypass，则降到 `94.1`；把 query adapter 换成参数量匹配 FFN，降到 `93.4`；把 edge anchor 换回 RGB，Long 进一步掉到 `91.5`。这说明作者的主张不仅是“加视频监督有用”，而是“只有当监督真正约束到动作所用表征时才有用”。此外，注意力分析显示带 world modeling 的 world tokens 在任务阶段上更聚焦，熵从 `5.22` bits 降到 `3.29` bits。SIMPLER 上报告 WidowX `71.5%`、Google Robot `82.1%`，R1 Pro 实机从 `59.4%` 提升到 `76.0%`。不过实机只和 matched baseline 比，任务也主要是 pick-and-place，证据支持“有实际收益”，但还不足以证明广泛真实场景鲁棒性。

局限与风险

第一，训练成本不低。论文明确需要联合微调 2B VLM、2B 视频 denoiser，并在 H100 上训练；它节省的是部署成本，不是研发成本。第二，真实世界实验覆盖面偏窄，只有 R1 Pro 单臂、四种水果入篮，任务复杂度有限。

第三，方法对 future clip 监督和视频世界模型质量有依赖，跨 embodiment、视角或接触分布变化时是否仍稳定，论文未明确说明。第四，Canny edge anchor 是手工设计，虽有效但可能带来数据域敏感性；作者自己也在结论中承认这是局限。另一个风险是，world tokens 被强压为固定 256 个，复杂场景下是否形成信息瓶颈，论文未明确说明。

与我方向的关系

对 VLA/embodied AI 很相关。它提供了一个很值得借鉴的范式：不是把世界模型塞进测试时控制环，而是把它当作训练期表征塑形器。这对追求低延迟部署的 VLA 很有参考价值，尤其适合资源受限或实时性要求高的机器人系统。

对多模态 safety/robustness 的启发主要在方法层而不是直接结论层。可借鉴的是：把安全相关预测目标，如未来碰撞、遮挡恢复、抓取稳定性、失败轨迹，压到一个“动作必经”的共享 token 接口上，而不是作为旁路辅助头。这样更可能真正改变策略决策。至于安全鲁棒性本身，论文没有专门评测，相关结论不能外推。

JEPA-WAM: Learning Vision-Language-Action Policies with Joint-Embedding World Modeling

作者: Yihan Lin (School of Information, Renmin University of China, Beijing, China; Key Laboratory of Data Engineering and Knowledge Engineering, Beijing, China); Jiawei He (XYZ Embodied AI, Beijing, China); Shifeng Bao (School of Information, Renmin University of China, Beijing, China; Key Laboratory of Data Engineering and Knowledge Engineering, Beijing, China); Chen Zhao (School of Information, Renmin University of China, Beijing, China; Key Laboratory of Data Engineering and Knowledge Engineering, Beijing, China); Yang Li (School of Information, Renmin University of China, Beijing, China; Key Laboratory of Data Engineering and Knowledge Engineering, Beijing, China); Xiaobo Wang (Shenzhen University of Advanced Technology, Shenzhen, China); Yan Wang (Institute for AI Industry Research (AIR), Tsinghua University, Beijing, China); Cheng Chi (School of Information, Renmin University of China, Beijing, China; Engineering Research Center of Database and Business Intelligence, Beijing, China); Jing Zhang (School of Information, Renmin University of China, Beijing, China; Engineering Research Center of Database and Business Intelligence, Beijing, China)

方向: VLA | 标签: VLA

简述: 共享潜空间VLA控制

筛选理由: 结构新颖，性能强，适合VLA控制

Deep Review

一句话判断

这篇论文的核心价值在于：用“联合当前-未来表征 + 共享预测器”把显式转移建模直接压到 V-JEPA 空间里，目标明确地服务于 VLA 的鲁棒泛化；如果你关心 OOD 泛化和 VLA/world model 的结合，值得精读。

核心问题与动机

论文要解决的是：VLA 策略只做动作预测时，对状态转移的建模是隐式的，遇到视觉、空间分布偏移时容易不稳；而传统视频生成式 WAM 虽然显式建模未来，但推理成本高。作者认为，现有 latent WAM 主要有两类不足：要么用更像“生成器特征”的表征，不一定真正强调状态变化；要么把预测模块和动作模块拆开，转移监督难以有效塑造动作生成所依赖的 backbone。

因此，论文的动机很集中：既保留显式转移监督，又不做未来帧生成；既保留 dense spatial correspondence，又让转移监督真正影响动作生成路径。这个问题设定对机器人控制很合理，尤其是需要抗视角、背景、布局变化的 manipulation。

方法拆解

整体 pipeline 是：冻结 V-JEPA 2.1 作为视觉表征空间，把当前观测编码成 dense patch tokens；训练时再取当前帧和 `δ` 步后的未来帧一起编码，构造“联合当前-未来”目标 `Y_t,t+δ`，而不是只预测未来帧表征。然后用共享预测器 `Fθ` 同时做两件事：一方面从当前视觉+语言上下文中输出视觉位置上的隐藏状态，回归这个 joint target；另一方面输出专门的动作条件表示 `C_t`，送入 DiT 动作专家做 flow matching 动作生成。

关键点不在复杂公式，而在设计选择：预测监督落在共享 predictor 的最终层，并且目标保留 patch-level 和 camera order，不做全局池化；部署时丢掉转移分支，只保留动作生成。论文还把同一套“联合当前-未来监督”迁移到预训练 π0.5：加未来 token，预测未来 token 的隐藏状态，再上采样对齐 V-JEPA joint target，且不改原始动作路径。

创新点含金量

1. 联合当前-未来目标：针对 future-only 目标丢失“转移关系”的问题，属于有明确动机的结构性改造，不是简单拼接；可迁移性较强，因为它依赖的是表征对齐而非特定动作头。
2. 共享 predictor 而非独立动态模块：针对“转移监督弱影响动作 backbone”的问题，把监督直接压到动作条件生成的同一骨干上，这比外接一个 latent dynamics head 更实质。
3. 保留 patch 级空间结构：针对压缩表征容易丢细粒度空间关系的问题，论文用 dense token 对齐而不是低维瓶颈；这对空间敏感操作很有价值。
4. 可插入预训练 VLA：这点很实用，说明方法不只是一套新 policy，而是可作为辅助目标接到已有 VLA 上；但它更像训练范式迁移，创新强度略低于前两点。

实验证据

实验覆盖 LIBERO、LIBERO-Plus、RoboTwin 2.0 和真实双臂平台。主证据是：在 LIBERO-Plus 上，JEPA-WAM 在不使用大规模 robot-policy 预训练时达到 79.2%，是该组最好；把同样监督加到 π0.5 上到 86.3%，为全表最好。RoboTwin 2.0 上，JEPA-WAM 的 Random 成绩明显优于无预训练方法，并且对 π0.5 也有增益；真实系统上，ID/OOD 都优于 π0，且对 π0.5 的辅助监督在两种设置下都显著提升。

消融比较完整，至少支持三点：V-JEPA 表征本身优于 DINO+SigLIP；joint current-future 比 future-only 更好；保留空间结构、把监督放在最终 shared predictor、用 action placeholder 而不是全 hidden state 都更有效。证据整体是闭环的，但论文未明确说明统计显著性、多随机种子方差，真实实验的任务数也不多。

局限与风险

第一，论文自己也承认，方法更擅长学习“通用视觉转移结构”，如果同一观察在不同指令下会导向不同转移，表达力可能不足。第二，转移目标依赖 V-JEPA 预训练空间，方法效果强烈绑定于该表征质量，跨 backbone 的稳健性论文未充分证明。第三，主要优势集中在视觉/空间 OOD，对语言歧义、长时序多步规划、复杂接触动力学是否同样有效，证据不足。第四，真实世界只做了五个双臂任务，外推边界还不够宽。

与我方向的关系

对 VLA 和 embodied AI 相关性很高，尤其适合作为“显式 world modeling 如何改善 policy robustness”的参考。对多模态 safety/robustness 的启发是：不要只把未来当上下文，而要把“状态变化关系”当监督目标，并尽量让这种监督直接作用于动作生成骨干。它不直接讨论 safety 约束、失败检测或不确定性估计，所以和 safety 的直接关联有限，但对鲁棒表征学习很有借鉴价值。

XCoT-VLA: Executable Chain-of-Thought for Vision-Language-Action Driving

作者: Foundation Model Team (XPeng Inc); XPeng Inc

方向: VLA | 标签: VLA

简述: 用可执行CoT做实时自动驾驶VLA

筛选理由: 思路新且贴近部署，但增益与泛化仍待细看

Deep Review

一句话判断

这篇论文最值得关注的是把驾驶 VLA 中“冗长自然语言推理”改成可执行、短序列的离散 reasoning token，并直接接到连续轨迹生成上；如果你关心 VLA 在自动驾驶里的实时规划接口设计，值得精读，但若关注闭环安全结论，目前证据还不够。

核心问题与动机

论文要解决的是：VLA 在自动驾驶中是否需要显式推理，以及这种推理该以什么形式服务控制。作者认为，现有 CoT 式方法多用自然语言中间过程，但对实时驾驶控制并不合适，因为它开放、冗长、解码慢，而且与可执行轨迹之间只有间接关联。

因此本文的核心动机不是“让模型多说理由”，而是把推理压缩成对决策真正有用的中间表示。作者提出 reasoning 应同时满足三点：决策关键、足够紧凑、且能直接作用于轨迹生成。这个问题对于 driving VLA 重要，因为自动驾驶规划有严格时延预算，而语言推理若不能转化为动作收益，只会带来额外计算负担。

方法拆解

整体 pipeline 是：从离线日志轨迹和场景上下文中，先构造 Reason-Action supervision，再压缩成 XCoT token 序列，最后训练模型根据观测先预测 XCoT，再据此生成未来轨迹。输入包括相机观测、文本任务/提示、ego 状态、历史轨迹和高层导航指令；输出先是 2-6 个 XCoT token，再是 24 步未来运动序列与积分后的轨迹。

方法上最关键有两层。第一层是离线标签构造：作者先从未来轨迹里抽取纵向/横向 action evidence，再结合场景语义生成候选原因，并用多个 vision-language experts 的一致性选择最匹配原因，最后用 taxonomy-based semantic compression 映射到固定 XCoT 词表。第二层是模型结构：共享 self-attention 先让所有 token 交互，再用确定性的 token-function routing，把非轨迹 token 都送入 Reason FFN，把 24 个 trajectory queries 送入 Control FFN；轨迹头采用 conditional flow matching。Stage I 用 token CE + flow matching 联合训练；Stage II 提出 XCPO，仅更新 reasoning 侧参数，用轨迹级奖励优化 XCoT policy，但执行栈冻结。

创新点含金量

第一，提出 executable CoT 作为驾驶中的中间接口，针对的是自然语言 CoT 冗长、不可直接执行的问题。这算有实质创新，尤其体现在把“推理接口”而不是“最终动作 token 化”作为设计对象；对其他低时延 embodied/VLA 任务也有可迁移性。

第二，Reason-Action supervision 的构造链条比较关键：用日志轨迹提供 action evidence，用场景提供 causal semantics，再压缩到固定词表。这个点更像“任务定义 + 标注机制”的创新，工程成分较强，但很贴近驾驶场景，也解释了为什么它优于无因果对齐的 latent tokens。

第三，decoupled Reason/Control FFN 配合共享 attention，是一个有针对性的结构设计，解决 joint fine-tuning 可能破坏控制稳定性的问题。这更偏架构工程优化，但实验里确实支撑了它的必要性，迁移到其他“语义推理 + 连续控制”系统是有潜力的。

第四，XCPO 把 policy optimization 放在 XCoT 离散空间中，思路有意思，但当前版本没有量化评测，创新性更多停留在扩展设想，证据不足。

实验证据

实验基于约 362 万样本的混合数据，包含自动标注、人标复杂场景和定向 lane-change 数据。对比对象包括 trajectory-only、Verbose CoT、Latent tokens 和 XCoT-VLA。主结果上，XCoT-VLA 在 general set 和 lane-change set 的所有报告指标上最好：general set 上 longitudinal ADE 从 1.6452 降到 1.3233；lane-change 上 lateral FDE 从 1.6160 降到 0.6484，说明它对路线条件下的横向决策帮助尤其明显。

消融实验基本支持两件事：其一，单独加 XCoT supervision 已能改善横向指标；其二，再加入 targeted navigation data 还有进一步提升。训练稳定性实验也支持 decoupled FT 优于 joint FT，后者会明显伤害纵向误差。时延分析则表明，按作者设定的 H100 条件与 12Hz 预算，6 个 token 的 XCoT 能满足预算，而 40-80 token 的 verbose CoT 不行。证据不足的地方也很明确：XCPO 没有定量结果；全部主结果是 open-loop ADE/FDE，尚不足以证明闭环安全、交互质量和真实部署收益。

局限与风险

第一，整套方法高度依赖离线构造的 Reason-Action 标签质量，而候选原因来自 vision-language experts、模板和关键词对齐；这一步若有系统偏差，可能把错误因果语义固化进 token 空间。

第二，实验主要证明了 open-loop 轨迹拟合和推理接口时延，没有闭环 route completion、collision、rule violation、intervention 等关键指标，因此“更适合真实驾驶决策”这一点目前支持有限。第三，论文自己也承认对 surrounding agents 的 interactive negotiation 能力有限，并对 traffic-rule perception error 敏感。第四，longitudinal comfort/long-horizon longitudinal accuracy 改善较弱，甚至某些设置下仍逊于纯 SFT 基线，说明该方法当前更擅长横向意图表达，而非全面提升控制质量。

与我方向的关系

和 VLA、embodied AI 很相关。它提供了一个很值得借鉴的观点：在动作生成前插入的中间表示，不一定要是自然语言，也不一定是不可解释 latent；可以是小而离散、任务语义明确、直接面向执行的 token 空间。这对机器人操作、导航、车端 planning 都有启发。

对多模态 safety/robustness，这篇论文的直接贡献有限，但有一个可延展方向：把安全规则、交互约束、风险状态编码成可执行 token，再研究其对闭环鲁棒性和可验证性的帮助。推断：若后续能把 XCoT token 与风险评估、规则监控、反事实诊断结合，可能比自由文本 CoT 更适合 safety-critical VLA。

Neural Introspection Gating for Adaptive KV-Cache Reuse in Vision-Language-Action Models

作者: Zhijie Wu (Graduate School of Information Science and Technology, The University of Tokyo, 7-3-1 Hongo, Bunkyo-ku, Tokyo, 113-8656, Japan); Kento Kawaharazuka (Graduate School of Information Science and Technology, The University of Tokyo, 7-3-1 Hongo, Bunkyo-ku, Tokyo, 113-8656, Japan); Kei Okada (Graduate School of Information Science and Technology, The University of Tokyo, 7-3-1 Hongo, Bunkyo-ku, Tokyo, 113-8656, Japan)

方向: VLA | 标签: VLA

简述: 用置信门控改进VLA缓存复用

筛选理由: 思路务实，提速有效，但方法增量偏小

Deep Review

一句话判断

这篇论文最值得关注的是：它用几乎零额外成本的“logit margin 自省信号”给 VLA-Cache 加了一个训练外的安全阀，在不重训模型的前提下显著缓解了缓存复用导致的控制失真；如果你关心 VLA 推理加速与可靠性的平衡，值得精读。

核心问题与动机

论文关注 VLA 在实时控制中的一个实际瓶颈：相邻帧高度冗余，但 7B 级自回归模型仍要重复计算大量视觉 token 的 KV 表征，推理成本很高。已有 VLA-Cache 通过检测静态图像 patch 来复用缓存，确实省算力，但它的决策依据完全来自观测空间启发式，无法判断“视觉上变化很小但行为上很关键”的时刻。

作者的核心动机很明确：缓存复用真正危险的，不是图像有没有变，而是模型此刻是否对动作足够确定。尤其在抓取对齐、子任务切换、长时序误差累积时，陈旧 KV 可能把动作解码持续带偏。因此他们引入“神经自省”信号，用模型自己的动作置信度来决定何时放弃缓存、回到全量重算。

方法拆解

整体方法是在 VLA-Cache 前面再加一个 gate。原有 VLA-Cache 仍保留三步：先用相邻帧 patch cosine similarity 找静态 patch；再用 text-to-vision attention 去掉任务相关的重要 patch；最后按层的 attention entropy 做分层复用比例调度。新方法不改这些机制，只是在每个时刻决定“继续走缓存复用流程”还是“整帧全量重算”。

关键 gating 信号来自上一步动作解码的 top-1 / top-2 概率差。作者把每个动作 token 的 top-1 与 top-2 softmax 概率之差取平均，得到 margin。margin 大表示模型对当前动作选择更笃定，允许继续复用缓存；margin 小于阈值时，直接使整个 KV cache 失效，并在下一步做 full forward pass。这个设计是训练 free、实现轻量、额外开销近乎为零，但它有一个明确代价：决策基于 `t-1` 的输出，因此存在一步反应滞后。

创新点含金量

第一，把输出侧不确定性引入视觉缓存策略。它针对的是 VLA-Cache 只看输入变化、不看模型状态的缺陷。这是本文最实质的创新，虽然形式很简单，但问题抓得准，也符合机器人推理系统里“何时不能省”的工程逻辑，可迁移到其他自回归 VLA。

第二，选用 logit margin 而不是熵类信号作为 gating 指标。作者给了较完整的经验解释：动作熵会被大词表长尾噪声淹没，attention entropy 又受 attention sink 影响，难以反映关键时刻的不确定性。这一部分更像“扎实的指标选择”而不是全新理论创新，但说服力比单纯拍脑袋换指标强，可迁移性也较好。

第三，自调节计算预算的推理机制。简单任务上 gate 很少触发，困难任务上自动增加重算频率，本质上是 test-time adaptive computation。这个思想本身不新，但嵌入 KV-cache reuse 场景后，形成了一个很实用的系统级改进，更偏高质量工程组合。

实验证据

实验基于 LIBERO 四个 suite：Spatial、Object、Goal、Long；模型用 OpenVLA 和 OpenVLA-OFT；指标是成功率与每步 TFLOPs。对 OpenVLA，证据是成立的：相较 VLA-Cache，本文方法在 Goal 上把 74.0% 拉回到 77.4%，在 Long 上把 50.2% 拉回到 54.8%，不仅恢复了 blind caching 带来的退化，还略超 full inference；同时计算量从 full inference 的 1.87 TFLOPs 降到 1.53，仍保留大部分加速收益。这个结果直接支持了作者最核心的 claim。

但证据也有边界。首先，收益主要集中在 VLA-Cache 本来会伤精度的任务；在 Object 上反而掉到 67.8%，说明 gate 会有误触发。其次，OpenVLA-OFT 上三者几乎持平，表明该方法不是普适提升器，而是“缓存有害时的补救机制”。论文还提供了 threshold sensitivity、gate firing trace，并报告 Long 上约 24% step 触发重算，这些都增强了机制解释性。缺失之处在于：没有真实机器人实验，没有跨 benchmark 验证，也没有更细粒度的失败案例统计。

局限与风险

第一，logit margin 不能区分“缓存导致的不确定”与“模型本身就难”。因此它更像保守防护，而不是因果定位工具；算力会浪费在一些本来重算也无济于事的时刻。

第二，gating 有一步时延。若关键视觉变化在当前步才首次出现，系统只能在下一步才回退到全量重算，这对强瞬时反应任务可能不够。

第三，阈值仍需按模型族校准。作者证明了在同一架构内跨任务较稳，但并未证明跨模型、跨数据分布能直接复用。

第四，实验只在仿真 LIBERO 上完成。对真实机器人中的传感器噪声、相机抖动、控制延迟是否同样有效，论文未明确说明。

与我方向的关系

对 VLA / embodied AI，这篇工作最大的启发不是提出了新模型，而是展示了一种很务实的 test-time control 原语：把“模型自信度”接入推理系统调度，用于控制何时省算、何时保守。这个思路可外推到 token pruning、帧跳过、分辨率切换、分层规划-控制切换等问题。

对多模态 safety / robustness，它提供的是一种弱安全机制：当模型内部冲突上升时，减少使用近似推理结果。它还不是严格意义上的安全保证，但适合作为 runtime monitor 的组成部分。进一步的研究可考虑把 margin 与 OOD 检测、action consistency、risk-sensitive control 联合起来，而不是单独依赖一个标量阈值。

简述: 引入阶段语义未来提升操作策略

筛选理由: 问题定义清晰，思路新，但增益与泛化仍需细看

Deep Review

一句话判断

这篇论文最值得关注的是把机器人操作中的“下一阶段任务进展”显式建模为潜变量目标，并用它去条件化短时 world-action prediction；如果你关注 VLA/WAM 的长程任务推进而不只是局部动作拟合，这篇值得精读。

核心问题与动机

论文要解决的是：现有 VLA 直接从观测到动作，缺少显式未来建模；现有 WAM 虽然预测短时视频和动作，但它建模的是固定时间窗内的局部物理演化，仍然没有明确表示“当前任务下一步应达到什么阶段状态”。对于交接、对位、装箱、堆叠这类多阶段操作，仅靠短时 rollout 容易会做出局部合理但阶段推进不明确的动作。

作者因此区分了两种未来：短时 physical future 和阶段级 semantic future。核心动机很清楚：机器人不仅要知道“接下来几帧会怎么动”，还要知道“下一阶段应到达什么任务相关状态”。这一定义比单纯加长预测 horizon 更有针对性，因为作者认为远距图像预测会过度关注像素外观，而不是任务完成所需的对象关系变化。

方法拆解

整体是两阶段训练。Stage I 先训练一个 Stage-JEPA：输入当前观测片段和语言指令，用冻结的 V-JEPA2 编码当前 64 帧片段，再预测“下一阶段边界”对应目标片段的 latent，而不是预测目标图像。阶段监督并非人工标注，而是通过 V-JEPA2 特征变化自动找 transition keyframes：每 8 帧采样候选中心，比较局部窗口前后表征差异，做时序 NMS，最多保留 5 个关键转折点，再把每个当前帧 t 配到其下一个边界 bi+1。

Stage II 冻结 Stage-JEPA，把它接到 Motus-based WAM 上。WAM 继续负责短时视频未来和动作 chunk 预测；Stage-JEPA 输出的下一阶段 latent 经过 mean-pool 和 MLP 映射后，以一个全局标量门控残差注入到视频 token：`Xv + alpha h`。训练目标仍以原生 `Lvideo + Laction` 为主，外加约束门控幅度的正则。推理时用 causal 64-frame buffer 反复预测阶段 latent，再闭环生成动作。关键机制不复杂，但思路明确：JEPA 负责“该到哪一步”，WAM 负责“怎么到那一步”。

创新点含金量

第一，提出“阶段级语义未来 + 短时物理未来”的双时间尺度建模框架。它针对的是 WAM 只擅长局部动力学、缺少显式任务推进表示的不足。这是有实质性的任务表述创新，而且可迁移到其他 latent world model 或 hierarchical policy。

第二，用 JEPA latent 而不是视觉子目标作为阶段监督。它针对显式图像子目标易受外观干扰的问题，属于比较扎实的表示层设计，不只是工程替换。其可迁移性较高，尤其适合多模态和语义关系主导的操作任务。

第三，自动阶段对构造机制。利用冻结 V-JEPA2 特征变化做 keyframe/边界挖掘，避免人工 stage label。这更偏工程方法整合，但很关键，因为它决定该框架能否规模化训练。

第四，把阶段 latent 通过简单门控注入 WAM 视频流，而不是单独加一个高层规划器。这是务实设计，创新幅度中等，但兼容现有 WAM 架构，迁移成本低。

实验证据

实验主集是 RoboTwin 2.0 的 50 个双臂操作任务，clean 和 randomized 两种环境，各跑 100 个闭环 episode。总体成功率上，JEPA-WAM 达到 clean 91.42%、randomized 89.08%、overall 90.25%，相对最强 baseline Motus 的 88.66%/87.02% 有稳定提升。提升最明显的任务类别是 handover、targeted placement、container packing、arrangement/stacking、tool use，这和作者的阶段推进假设是吻合的；而 acquisition & lifting 上反而略低于 Motus，也说明该方法并非普适增益。

消融基本支持主要论点：去掉 JEPA 降幅最大；保留 JEPA 但不把 future latent 注入 WAM 时也会下降，说明关键不只是多一个分支，而是要把阶段表示真正用于条件化生成。值得注意的是，去掉 Stage-I 专门训练后性能只小幅下降，表明预训练 V-JEPA2 predictor 本身已贡献大量收益，因此“任务特化阶段学习”本身的增益并不算特别大。效率上，成功轨迹平均步数从 79.57 降到 74.82，下降 5.97%，这个证据支持“减少无效局部修正”的说法。真实机器人只给了 LIFT2 上 2 个任务的 task-progress score，JEPA-WAM 平均 48.0 对 π0.5 的 41.5，但证据规模偏小。

局限与风险

第一，阶段边界监督来自启发式特征变化检测，并不等价于真实语义阶段。论文给出了边界距离和 slice overlap 诊断，但没有证明这些自动边界与任务语义严格对齐，存在监督噪声风险。

第二，方法收益明显依赖任务类型。对以抓取几何、接触稳定性为主的任务帮助有限，说明该框架更像是“长程语义推进增强器”，不是底层操作能力的通用替代。

第三，真实世界验证较弱。文中只报告两个 LIFT2 任务的进度分，缺少更系统的 sim2real 成功率、鲁棒性、时延和失败模式分析。

第四，推理成本可能不低。系统需要维护 64 帧缓冲并运行 V-JEPA2 + WAM，论文承认未来工作要解决 inference latency，但未明确给出时延数据。

与我方向的关系

和 VLA/embodied AI 关系很直接。它提供了一个值得借鉴的思路：不要把 future modeling 只理解为更长的视频预测，而应显式拆分“阶段语义目标”和“局部执行动态”。这对长程操作、双臂协作、任务分解式控制都很有参考价值。

对多模态 safety/robustness 的启发在于：阶段 latent 可以被视为一种更稳定的中间语义约束，理论上有助于减少局部贪心动作和无效修正。但论文没有直接评估安全性、OOD 鲁棒性或对抗干扰，因此这部分价值目前更多是推断。若往后做 safety-aware VLA/WAM，可以考虑把安全约束也编码进 stage-level latent 或边界预测里。

简述: 3D语义场增强开放词汇移动操作

筛选理由: 3D语义地面提升鲁棒性，实机结果较强。

Deep Review

一句话判断

这篇论文最值得关注的是把局部 Semantic-3DGS 作为从主动感知到 VLA 执行的统一中间表示，并在真实移动操作上证明它确实提升了遮挡、杂乱、视角变化和机体约束下的鲁棒性；如果你关心 VLA 与显式 3D grounding 的结合，值得精读。

核心问题与动机

论文处理的是开放词汇移动操作中的目标指代与执行脱节问题：机器人不仅要从语言里找对物体，还要在三维空间里稳定定位、选择可达站位，并最终完成操作。作者强调两个常见失败源：一是很多 VLA 仍偏依赖 2D 外观，遇到遮挡、杂乱或“照片冒充实物”时容易误抓；二是即便目标找对了，如果底盘站位和机体高度不合适，机械臂依然会失败，尤其在长时序任务和高度变化场景中更明显。

因此，论文的核心动机不是单纯提高识别精度，而是把语言、局部多视角图像、3D 几何、障碍信息和动作可行性对齐到一个可复用表示里。作者将问题限定为few-shot embodiment-specific manipulation + open-vocabulary target grounding，而不是宣称零样本学会任意技能，这个问题定义相对克制，也让实验结论更可信。

方法拆解

整体 pipeline 分四步：收到语言指令后，先用腕部相机主动采四个视角；再基于 VGGT 初始化局部几何，并蒸馏 CLIP/DINO 特征构建 Semantic-3DGS；随后用语言相关性在 Gaussian 层面做开放词汇 3D 定位，得到目标位姿；最后依据目标相对底盘的位置估计可达站位和站立/下蹲高度，再把语义 3D 线索注入扩散式 VLA 执行抓取与放置。

关键机制有三处。第一，主动视角选择不是端到端学出来的，而是用“语义覆盖 + 视角互补 + 移动代价”打分，先把局部场景看清。第二，3D 定位不是只给一个点，而是利用 language relevance 选出一组 Gaussian support，再加权求目标位置，并通过 PCA 估计稳定 6D pose。第三，语义信息只注入动作专家最后五个 diffusion block，前面预训练 backbone 冻结，避免早期融合破坏已有动作先验；这比把 3D 特征从头灌进 VLA 更像一种保守且工程上稳妥的适配策略。

创新点含金量

1. 用 task-driven local Semantic-3DGS 作为 perception-to-action 共享接口。 针对的不足是 3D 表示常只停留在感知端，没有真正进入执行闭环。这个点有实质创新，尤其在“同一表示同时服务主动观测、语言定位、障碍推理、站位准备、VLA 条件注入”这一系统整合上比较完整，可迁移到其他 embodied grounding 场景。

2. 主动多视角 + Gaussian 级开放词汇定位。 针对单视角和 2D grounding 在遮挡杂乱下不稳定的问题。这里更像“已有组件的有机组合”，但组合方式是围绕机器人任务设计的，不是简单堆料；对移动操作、导航后局部操作等任务有较强可迁移性。

3. late-block semantic injection。 针对的不足是强行早融合同质化 3D 语义会破坏预训练 VLA 的动作先验。这个点偏实用型创新，但证据比较扎实：既提高成功率，也降低推理延迟，说明不是纯工程小技巧。

4. 将 grounding 与 reachability-aware base posture 显式耦合。 这是论文区别于只比 VLA 感知模块的关键。创新性中等，更偏系统设计，但对移动操作非常重要，且高度可迁移。

实验证据

实验主要是实机 few-shot manipulation，平台为四足底盘加 6DoF 机械臂。任务包括多任务放置、长时序 drawer-to-chair、高度变化、照片欺骗、重遮挡杂乱操作。baseline 选了 DexVLA、PointVLA，以及自己的 single-view 和去掉 Base-RL 版本；在公平性上，作者说明各方法使用相同 embodiment、相同 10 条示教/任务、相同相机与评测预算，这一点是加分项。

结果层面，证据最强的是三组：长时序任务 50 次实机中，full system 60%，高于 PointVLA 的 40% 和 DexVLA 的 28%；杂乱遮挡任务 74%，显著高于 single-view 的 52% 和 PointVLA 的 46%；高度变化到 75 cm 时仍有 75%，而去掉 Base-RL 后为 0%。此外，照片欺骗中 full system 与 PointVLA 都将 false grasp 降到 0%，但 full system 的真实目标成功率更高（88%）。这些结果充分支持“显式 3D grounding + 站位准备”确实提升鲁棒性。相对不足的是：泛化范围仍集中在局部 household manipulation；论文未明确说明任务间统计显著性检验，也未展示更多失败案例分解。

局限与风险

第一，系统明显依赖操作前的显式建图阶段，四视角采集本身就要 16 秒，整套方法面向 quasi-static 场景，不适合快速动态交互。第二，Semantic-3DGS 与 VLA 推理目前依赖场外 RTX 4090，部署形态离真正 onboard autonomy 还有距离。

第三，few-shot 设定下每个任务仍需 10 条真实示教，因此它提升的是 grounding 和 embodiment adaptation，而不是通用技能泛化。第四，开放词汇能力的边界没有被充分展开，例如更细粒度属性指代、关系性指令、强 domain shift 下是否仍稳健，论文未明确说明。

与我方向的关系

对 VLA/embodied AI 很相关。它给出的最有价值启发是：不要把 3D 表示只当感知前端，而要把它设计成动作前的共享工作空间表示，让 view planning、target grounding、collision reasoning、base preparation、policy conditioning 共用同一对象中心场。这对今后做 embodied foundation model 很有参考价值。

对多模态 safety/robustness 也有直接启发。照片欺骗实验表明，显式 3D 几何能抑制纯外观诱骗；而 late-block 注入则说明，把安全/语义约束放在动作生成后段，可能比全模型强融合更稳。若做后续研究，可考虑把这种局部 3D 语义场扩展到 uncertainty-aware grounding、OOD 检测或 closed-loop refresh。

RynnValue: Scaling Robotic Value Foundation Models with Temporal Distance

作者: Dongchi Huang; Hongyin Zhang; Bohan Hou; Siteng Huang; Zhian Su; Hang Guo; Tong Lu; Zhaofeng Xu; Jiahao Tang; Jianfei Yang; Donglin Wang; Peixi Peng; Mingxiu Chen; Deli Zhao; Xin Li

方向: VLA | 标签: VLA

简述: 用时间距离扩展机器人价值基础模型

筛选理由: 监督信号可规模化且跨任务泛化，实机增益显著

Deep Review

一句话判断

这篇论文最值得关注的点，是把机器人通用 reward/value 学习的监督目标从偏好或归一化进度，改成可由时间戳直接构造的 temporal distance，并在大规模异构数据上证明这一路线能超过偏好监督 SOTA；对做 VLA/机器人奖励建模的人，值得精读。

核心问题与动机

论文关注的是：如何为通用机器人策略提供可扩展、跨任务跨 embodiment 可复用的 value/reward 接口。作者认为当前瓶颈不在 policy 容量，而在 reward supervision：手工 reward 泛化差，稀疏成功信号对长时程任务引导弱，而偏好、参考轨迹、局部状态比较这类监督都绑定在任务内部锚点上，难以迁移到异构数据源。

作者对现有 progress-based 方法的批评比较关键：归一化 progress 本质是轨迹内坐标，不是真正 goal-conditioned cost-to-go，因此在任务时长、机器人形态、执行速度变化时不稳定。RynnValue 的核心主张是直接学“距语言目标完成还剩多少时间”，即 directed temporal distance，把它作为统一 value 接口，再通过 potential-based shaping 转成 dense reward。

方法拆解

整体 pipeline 是：从大规模异构机器人/仿真/第一视角数据中，先做子任务切分和 completion cutoff 重标注，再用时间戳为每个 observation 自动生成 absolute temporal distance 标签；同时对相邻采样帧生成 relative temporal displacement。模型输入是指令、embodiment metadata 和一串观测帧；输出包括每帧到完成的绝对剩余时间、相邻观测的相对时间位移，以及视频描述/任务匹配/成功判断。

模型上最关键的有三点。第一，用 repeated query group 而不是单 token query 表示每个 value 查询，再拼接 hidden states 送入 absolute / relative 两个 distributional heads。第二，用 symlog 分桶加 two-hot 目标，把连续时间回归转成稳定分类。第三，也是论文最重要的机制，是 shortcut suppression：随机时间采样打破固定间隔，temporal-order shuffling 打破“序号=进度”，value-isolation attention 则阻止某一帧的 value query 直接偷看其他帧的 value query，迫使预测回到视觉证据和语言目标上。训练时还加入 instruction mismatch augmentation，并联合学习视频描述、match、success。

创新点含金量

1. 用 temporal distance 替代 progress/preference 作为统一监督目标：直接针对异构数据难统一标注的问题，属于比较实质的 framing 创新，不只是工程替换；可迁移性强，尤其适合大规模离线机器人数据。

2. 基于时间戳的低标注成本数据配方：把 supervision 建立在 timestamps + cutoff relabeling 上，显著降低偏好构造成本。这更偏“可扩展训练 recipe”创新，方法本身不复杂，但工程价值很高。

3. temporal-order shuffling + value-isolation attention 的防捷径设计：针对多帧 value 学习中常见的顺序泄漏和 query 间外推问题，属于很有针对性的机制创新。单看模块未必非常重，但和任务定义高度耦合，证据也比较充分。

4. absolute + relative temporal modeling 联合建模：相对位移为局部时序变化提供监督，更多像有效的结构性增强，而非全新范式；可迁移到其他视频 value/进度建模任务。

实验证据

证据最强的是 RBM-EVAL-OOD 轨迹排序。RynnValue-8B 的 Kendall’s τa 为 0.675，高于全监督偏好方法 Robometer(RBM-1M) 的 0.655，也远高于 progress-only 的 0.292；4B 版本也有 0.670，说明收益主要不来自单纯增大模型。instruction-trajectory alignment 中，RynnValue 的 diagonal margin 为 0.79，也高于对比方法，支持其确实更依赖语言目标而不是泛化的“视觉进展”。

消融也比较扎实：去掉 shuffle 降到 0.189，uniform sampling 降到 0.379，去掉 isolation 降到 0.482，去掉 language supervision 降到 0.537，去掉 relative 分支降到 0.627，说明作者强调的几个组件都不是装饰。真实机器人 RL 上，online 成功率从最强基线 52.5% 提升到 72.5%，offline 从 63.8% 提升到 82.5%。不过需要注意，reward shaping 系数对不同方法并不相同（RynnValue 0.1, Robometer 1.0），这说明公平性虽有考虑，但仍可能影响最终幅度解读。

局限与风险

第一，temporal distance 依赖 completion cutoff 重标注质量，而 cutoff 的设定带有数据集特定启发式；若 cutoff 偏差大，监督会系统性失真。第二，方法默认“最短时间到目标”是合理 value 代理，但对需要等待、试探、绕行或安全约束优先的任务，这个假设未必成立。

第三，真实世界实验任务数仍有限，虽然覆盖双臂、抽屉、工具使用，但离开放世界长时程 manipulation 还有距离。第四，论文强调 zero-shot 到 unseen tasks/embodiments/viewpoints，但对失败模式、极端语言歧义、严重视觉遮挡下的鲁棒性展示仍不充分。多模态 safety 方面也几乎没有系统讨论。

与我方向的关系

和 VLA/embodied AI 的关系很直接：这篇工作提供了一个比 progress 更像“控制意义上的 value”监督接口，适合作为通用机器人基础模型中的 reward/value 侧组件。对后续研究，一个重要启发是：在异构 embodied 数据中，真正可扩展的往往不是更复杂的偏好标注，而是寻找能由原生元数据自动导出的目标。

对多模态 safety/robustness 的启发主要在训练机制层面。其防 shortcut 设计说明，时序多模态模型很容易学到“顺序即答案”“query 间泄漏”这类伪规律；这种问题在 VLA 和安全判别里同样存在。推断：value-isolation 这类 attention 约束，未来可借鉴到 failure prediction、safety critic、语言条件一致性检测中。但论文本身没有直接研究安全目标。

这篇论文最值得关注的是把“动作能解释状态变化、状态变化也能约束动作”显式写进紧凑 VLA 表征学习里，并在 0.47B 规模下同时拿到较强性能与明显效率优势；如果你关注 VLA 的轻量化、latent dynamics、real-world robustness，值得精读。

核心问题与动机

论文要解决的是：机器人操作策略是否必须依赖大 VLM 式 backbone，或在测试时做昂贵的像素/视频未来预测，才能获得强泛化与稳健控制。作者认为，现有 VLA 往往把动作与观测变化的关系“隐式”埋在动作监督里；而 world model / WAM 路线虽然强调 action-conditioned future，但像素级预测会浪费容量在纹理、光照、背景等与控制弱相关的细节上，还可能引入测试时延迟。

因此，SLIM 的核心动机是学习一种 action-grounded predictive latent：既能从当前/未来观测反推动作，也能从当前观测与动作预测未来 latent。这样未来预测只作为训练信号塑造控制表征，而不是推理时必须执行的生成过程。这一点对 VLA 很关键，因为它实际上在回答“控制所需的最小表征是什么”。

方法拆解

整体上，SLIM 分两阶段。第一阶段先做 self-supervised masked trajectory prediction，学习动作扎根的预测 latent；第二阶段再在同一个 backbone 上训练 language-conditioned flow-matching policy。输入包括语言指令、当前多视角图像和本体状态，视觉编码器把图像编码为 observation latents，语言由 T5-small 编码，动作以连续 token 形式建模，不做离散化。

核心 backbone 是一个双流 MoT：observation stream 处理当前观测 latent 与 proprio token，action stream 处理动作 chunk token；两流通过 joint attention 交互，而语言只作为 per-stream cross-attention 条件，而非主干计算中心。第一阶段有两个互补目标：一是 inverse-dynamics 风格的动作重建，把动作加噪后，利用当前和未来观测 latent 预测 flow velocity；二是 forward-dynamics 风格的未来 latent 预测，把未来 latent token mask 掉，用当前观测和干净动作去预测未来 latent，并对齐 stop-grad 的 EMA target。第二阶段则不再输入未来观测，仅保留由第一阶段塑造出的 predictive slots，用 flow matching 直接生成动作。关键机制不在单个公式，而在这两个方向的约束共同把 latent 空间压成“对控制有用”的状态表征。

创新点含金量

第一，把前向/逆向动力学约束统一到同一紧凑策略 backbone 内。它针对的是 VLA 中动作-状态转移关系建模不足的问题，属于有实质性的训练目标设计创新，不只是工程拼装；这个思路可迁移到其他 latent-policy 或 diffusion/flow policy。

第二，未来预测发生在观测 latent 空间而非像素空间。这针对 WAM 的高计算与表观细节冗余，更多是方法路线上的明确取舍，创新性中等，但实用价值很高，尤其适合实时控制。

第三，语言从“控制主干”降为条件信号，主计算聚焦 observation-action interaction。这不是全新结构发明，但对 VLA 范式有明确立场：把开放域语义与低层控制解耦。可迁移性较强，特别适合参数受限或低时延部署场景。

第四，两阶段训练后推理时不显式生成未来。这是系统层面的有效设计，更多偏工程与架构整合，但实验上确实带来了时延和显存收益。

实验证据

实验覆盖 LIBERO、zero-shot LIBERO-Plus、CALVIN ABC→D，以及 5 个真实机器人任务。结果上，SLIM 在原始 LIBERO 达到 97.5%，与强基线基本持平；在 zero-shot LIBERO-Plus 上总体 77.45%，高于 OpenVLA-OFT、π0、Fast-WAM，但低于 VLA-JEPA 的 79.5%。因此“显著优于所有方法”并不成立，更准确的说法是：在无额外 embodied pretraining、参数仅 0.47B 的条件下，鲁棒性结果非常有竞争力。CALVIN 上 4.556 的 avg length，高于 UnifiedVLA 4.41、FLOWER 4.53、DreamVLA 4.44，证据较强。真实世界里，SLIM 在 nominal、distractor、lighting 三种设置下平均 progress 最好，background shift 略低于 π0.5 但远强于 Fast-WAM。

消融是这篇论文较有说服力的部分：加入 Stage 1 比只做 Stage 2 更好；IDM:FDM 比例存在最优点，0.125:1 最佳；EMA target 明显提升 LIBERO-Plus 与 CALVIN，并通过 effective rank、cosine similarity、energy concentration 说明无 EMA 会出现 latent collapse。这部分较充分支持“动作扎根的 masked trajectory learning 确实在塑造有效表征”。不过注意，attention 可视化只是定性诊断，不能单独证明因果。

局限与风险

第一，论文强调效率与小模型优势，但没有展示更大规模下该范式是否还能保持相对收益；作者也在结论中承认 scaling law 尚未建立。对想把它作为通用 VLA 主路线的人来说，这是明显缺口。

第二，真实世界实验规模有限，只有 5 个任务、750 条 demonstrations，且每个 task-condition 10 次试验，足以说明可行性，但不足以证明跨场景泛化的稳定结论。第三，SLIM 在 LIBERO-Plus 的 robot perturbation 上只有 36.90%，显著低于 VLA-JEPA 的 67.7%，说明该表征对机器人初始状态/运动学扰动的鲁棒性并不全面。第四，论文未明确说明 Stage-1/Stage-2 的训练成本、数据吞吐或总训练时长，因此“整体更便宜”目前主要体现在推理，而非全生命周期成本。

与我方向的关系

对 VLA 而言，这篇工作的启发很直接：不要默认语言-视觉大模型必须承担每一步控制主干，控制表征可以更小、更偏 dynamics-aware。对 embodied AI，它提供了一个很值得跟进的方向：把 future prediction 从 test-time planner 退回成 train-time representation shaping signal，同时保持可部署性。

对多模态 safety/robustness，这篇论文的相关性是间接但有价值的。它没有直接研究安全对齐或 failure detection，但其 action-grounded latent 可能成为鲁棒性研究的更好接口，例如分析哪些 latent 因子对应可执行性、接触状态、扰动恢复。一个自然后续是把 uncertainty / OOD detection / safety critic 直接接在这种 predictive latent 上，而不是接像素或大语言特征上。这部分属于推断。

VANE: Reliable Test-Time Training for Vision-Language-Action Models via Future Visual Representation Prediction

作者: Hongjin Ji (The Chinese University of Hong Kong, Shenzhen; Li Auto Inc.); Guoyang Xia (Beijing University of Posts and Telecommunications; Li Auto Inc.); Luoyang Sun (Institute of Automation, Chinese Academy of Sciences; University of Chinese Academy of Sciences; Li Auto Inc.); Fangxiang Feng (Beijing University of Posts and Telecommunications); Lei Ren (Li Auto Inc.)

方向: VLA | 标签: VLA

简述: 基于未来反馈的可靠VLA测试时训练

筛选理由: 方法明确，闭环改进有价值

Deep Review

一句话判断

这篇论文最值得关注的是把 VLA 的 test-time training 从“直接在线更新”改成“基于未来观测证据的候选更新-验证-提交”机制；如果你关注 VLA 部署期自适应、尤其是 closed-loop 下的可靠性问题，值得精读，但其收益明显依赖任务与平台。

核心问题与动机

论文关注的是：VLA 在部署时能否利用无标注交互流进行轻量自适应，同时避免把错误更新直接写进闭环控制器。作者认为现有 TTT-VLA 式方法虽然证明了 latent prompt 级别的在线适配可行，但在真实闭环 manipulation 中不够“可靠”，主要体现在两点：一是不同任务共享同一适配空间时会发生干扰，某个任务受益的 prompt 更新可能损害另一个任务；二是在线更新会立刻改变后续动作，而这些动作的后果尚未显现，导致“未验证更新”直接影响未来轨迹。

这两个问题的重要性是成立的。VLA 部署天然会遇到任务异质性、视觉分布偏移与闭环耦合，而如果 test-time adaptation 不能控制回退与验证，其工程风险很高。论文的动机因此相当清晰：不是单纯追求更强 TTT，而是追求更可控、更可验证的 TTT。

方法拆解

VANE 由三个串联部分组成。第一部分是 MoLP：维护一个共享 latent-prompt bank，用当前视觉-语言上下文通过 router 做 top-k 稀疏路由，组合出当前有效 prompt，而不是对所有任务使用单一 prompt，也不要求外部任务 ID。第二部分是 WPI：不用当前时刻的 state grounding 做代理目标，而是用延迟到来的未来图像，经冻结的 V-JEPA 2 编码成未来视觉表征，让模型根据当前观测、prompt 和动作上下文去预测未来视觉 latent。第三部分是 AGV-TTT：先由注意力跨层重分布检测“交互转折时刻”，只在这些时刻提出 shadow update；候选更新不会立即接管控制，而是等后续若干 future pairs 到来后，与旧 prompt 在配对输入上比较，只有在 focused loss 改善、global loss 不退化、且多数验证帧受益时才原子提交，否则回滚。

方法上的关键不在公式本身，而在机制组合：MoLP 解决“适配什么空间”，WPI 提供“什么自监督信号”，AGV-TTT 解决“何时更新、何时相信更新”。其中最核心的是把 test-time update 从即时生效改成“提案-未来验证-提交”的延迟决策，这直接针对闭环自适应的因果污染问题。

创新点含金量

第一，上下文路由的 latent prompt mixture。针对单一 prompt 跨任务干扰的问题，这是实质性设计改进，不只是简单多 prompt 堆叠，因为它强调共享与特化并存、且不依赖任务标签。可迁移性较强，适合别的 prompt-based VLA/VLM 适配框架。

第二，未来视觉表征预测作为部署期代理目标。针对 state grounding 过于同刻、低维且 embodiment-specific 的不足，这是比较有含金量的 proxy 重构。它不是训练一个完整 world model，而是把 future latent prediction 当作 test-time self-supervision interface，这一点界定较清楚，也较易迁移到其他冻结 backbone 的 setting。

第三，shadow update + future validation 的可靠 TTT 协议。这是本文最强的创新点，明显不是纯工程拼装。它把 closed-loop TTT 里“更新影响验证数据”的问题单独拿出来处理，具有方法论价值，对 embodied online adaptation 和 safety/robustness 都有借鉴意义。

实验证据

证据最扎实的是 WidowX。完整配置 `QwenWPI + MoLP + AGV-TTT` 在 SimplerEnv WidowX 上达到 71.2%，相比对应的 `QwenWPI + FP-LP + TTT` 为 68.0%，也高于文中引用的 `TTT-VLA` 67.4%。更重要的是受控实验：在 WidowX 上，WPI 在 8 个 matched prompt-protocol 对比里都优于 state grounding；AGV-TTT 在 4 个 proxy-prompt 组合上都是最佳协议；future validation 消融中，`Event + Accept-All` 67.3%，`AGV-TTT` 69.0%，说明收益不只是稀疏更新，而是验证机制本身。

但 Google Robot 证据明显更复杂，也更能说明边界。三任务汇总下，`QwenWPI + MoLP + AGV-TTT` 反而低于 `QwenWPI + FP-LP + TTT`；四任务完整统计时又从 64.6% 提升到 70.4%，说明收益对任务组成敏感。论文对此处理得相对诚实，没有把 WPI 或 AGV 包装成普适优势。因此，被充分支持的结论是：VANE 在 WidowX 上有效，future validation 有独立贡献；证据不足的结论是：该框架能稳定泛化到不同 embodiment 与任务族。

局限与风险

第一，方法增益的外部有效性有限。Google Robot 上组件排序变化较大，说明其“可靠性”更多是在特定任务分布上成立，而不是一般性结论。

第二，WPI 的收益与 backbone/训练分布可能强耦合。论文展示了替换 proxy 后整体更强，但不少绝对优势在 No-TTT 时就已经出现，说明它部分是在改变训练后策略接口，而不纯粹是提升 test-time adaptation 增量。

第三，attention event detection 的可靠性并未被系统量化。论文明确说该分析是 illustrative，不提供 precision/recall，因此 AGV 的触发质量仍有实验缺口。

第四，计算代价虽减少 backward 次数，但仍引入额外 validation forward。论文只报告优化次数，没有 wall-clock 或真实部署时延，这对机器人在线应用仍是关键缺口。

与我方向的关系

对 VLA 和 embodied AI，这篇论文的启发很直接：部署期适配不该只研究“能不能更新”，而应研究“如何把更新限制在可验证、可回滚的机制里”。这对真实机器人尤其重要，因为 online adaptation 的错误会立刻进入控制闭环。

对多模态 safety/robustness，这篇论文最值得借鉴的是“future evidence before commit”的思想。它本质上是一种轻量级部署时防护：先提案，再用后验观测验证，再决定是否写入策略。该思想可推广到 test-time calibration、OOD 触发更新、甚至安全约束下的 policy patching。若你的方向更偏 world model 或 safety-aware adaptation，这篇比单纯提性能的 VLA 论文更有参考价值。

Skills in Weights, Memory in Code: Hybrid Learning for Memory-Dependent Robot Manipulation

作者: Yunhao Zhao (Northwestern University); Zhenyang Ni (Northwestern University); Haoyang Chen (University of Minnesota); Ruohan Zhang (Northwestern University; Stanford University); Qi Zhu (Northwestern University)

方向: VLA | 标签: VLA

简述: 用代码式记忆增强机器人操作

筛选理由: 方法新颖，任务提升明显，适合关注长程记忆

Deep Review

一句话判断

这篇论文最值得关注的是把“低层运动技能”留在权重里学、把“长时记忆/策略”放到可执行代码里学，并用记忆驱动的 steering 让同一套 Markovian VLA 处理非 Markov 任务；如果你关心长时序 VLA、可解释记忆和数据效率，值得精读。

核心问题与动机

论文针对的是记忆依赖型机器人操作：当前观测不足以决定下一步动作，必须回忆此前出现过的线索、计数或阶段状态。作者认为现有 memory-augmented VLA 往往把记忆和动作模型端到端耦合训练，导致需要覆盖组合爆炸的历史配置，且记忆逻辑难以检查和修改。这个问题在 RoboMemArena 的转移、计数、序列、遮挡任务中都很典型。

其动机很明确：既然现代 VLA 已经能学到较强的低层操控技能，就不应再把所有历史依赖都塞回权重里学；更合理的是把“会做动作”和“记得当前处于哪一阶段”拆开。论文把前者交给 imitation learning，把后者交给 coding agent 在代码空间里迭代修订规则。

方法拆解

HyMeS 是一个双组件框架：一侧是固定的 flow-matching VLA，先用示范数据学 motor skill；另一侧是显式符号记忆程序 `P=(C,V,U)`，分别负责阶段约束选择、完成判定、记忆更新。执行时，当前记忆状态 `s_t` 选择一个阶段约束 `R_t`，再通过梯度引导 VLA 的去噪过程生成动作 chunk；一旦多模态验证认为阶段完成，记忆就被更新并切到下一阶段。

训练上，VLA 只用专家示范做流匹配式 imitation learning，得到冻结的 `θ*`。记忆策略不靠梯度，而是 coding agent 根据 rollout 轨迹和 benchmark 的阶段级反馈迭代改写程序。推理时不再改权重，只用冻结程序与冻结 policy 交互。完成检测用 PACE：结合本体感觉信号和最多五帧的多帧 VLM 判断，通过滑动窗口投票决定是否真的进入下一阶段。

创新点含金量

  • 把“技能”与“记忆”分到权重空间和代码空间：针对端到端记忆学习需要覆盖组合历史的问题，属于结构性拆分，不只是工程拼接，迁移到其他长时序操作有潜力。
  • 用可执行符号记忆去 steer Markovian VLA：不是只在输入端加历史，而是把记忆转成可微约束注入生成过程，这一思路对历史歧义任务更直接，属于实质方法设计。
  • 采用 rollout 驱动的 heuristic learning：记忆规则可通过执行反馈修订，不需要新的专家动作标注。这个机制对数据稀缺场景有可迁移性，但其稳定性强依赖反馈质量。
  • PACE 的多模态阶段验证：把 proprioception 和多帧 VLM 结合做阶段切换，解决“该不该记为完成”的问题。它是重要配套模块，但更像方法闭环中的关键工程，而非独立理论创新。

实验证据

实验主要在纠正后的 RoboMemArena 12 个任务上，覆盖 transferring、counting、sequential execution、occlusion，共 160 个 episode；并在 SO-101 真机上测了 3 个记忆依赖任务。对比对象是 reactive π0.5 和 PrediMem。结果显示，HyMeS 在仿真中把总体 CSR 从 52.5% 提升到 66.2%，TSR 从 41.3% 提升到 60.1%；相对 PrediMem，TSR 还高 14.5 点。真机上总体 TSR 从 25.7% 提升到 57.1%。

证据比较充分的结论是：显式记忆 + steering 确实能把同一套 motor skill 用到更复杂的历史依赖任务上；rollout 经验和双模态验证都有效。证据不足之处在于：论文未明确说明方法在更长时程、更多阶段、或更噪声视觉条件下的上限，也未系统比较不同记忆表示的优劣。

局限与风险

第一，方法依赖“可压缩成符号状态”的任务前提，论文自己也承认这一点；如果任务需要连续、模糊或高维情境记忆，适用性会下降。第二，性能仍受底层 VLA 和阶段验证限制，论文的失败分析表明：记忆正确并不保证接触式执行成功，尤其在抓取偏差、按压深度不足、遮挡下识别不稳时。

第三，推理开销和延迟会上升，因为要周期性调用 VLM 和 coding agent。第四，实验虽然有真机，但任务数不大，且具体场景较集中；对更开放的长程操作、跨平台泛化和安全失败模式，论文未做系统评估。

与我方向的关系

和 VLA、embodied AI 的关系很直接：它提供了一种把长时记忆从 policy 权重中剥离出来的路线，适合那些“动作技能已学会，但历史状态难保留”的任务。对多模态 safety/robustness 的启发主要在两点：一是用显式、可审计的记忆状态降低黑箱记忆错误；二是用本体感觉 + 多帧视觉做阶段验证，减少错误状态推进。

对后续研究可借鉴的是“代码化记忆 + 可微 steering + 闭环验证”的组合。但它不是通用安全方案，更多是记忆一致性和阶段切换鲁棒性的提升；对真正的故障检测、风险规避或开放世界安全，论文没有直接覆盖。

WA-SpecDec: World-Aware Speculative Decoding for Vision-Language-Action Models

作者: Zikang Wen (The University of Sydney; Sydney, Australia); Yuning Zhang (The University of Sydney; Sydney, Australia); Dong Yuan (The University of Sydney; Sydney, Australia)

方向: VLA | 标签: VLA

简述: 世界感知加速VLA解码

筛选理由: 兼顾提速与接触安全，结果较扎实

Deep Review

一句话判断

这篇论文最值得关注的点，是它没有改 relaxed speculative decoding 的验收规则，而是把“物理场景感知”前移到 VLA 的 prefill 表征中，从而在接近接触的操作阶段同时改善速度-成功率权衡；如果你关心 VLA 推理加速且不想明显牺牲操控可靠性，值得精读。

核心问题与动机

论文解决的是：VLA 策略按 token 自回归生成动作，闭环控制延迟受 target model 重复前向开销限制；speculative decoding 可用 draft model 批量提议 token，再由 target 并行验证来加速。但在机器人动作里，精确 token 匹配过严，因此已有工作采用 relaxed acceptance，只要 draft token 与 target token 的距离不超过阈值 `ρ` 就接受。

作者指出关键缺陷在于：这种 relaxed acceptance 是“场景无关”的。相同的 token 偏差在自由空间可能无害，但在接触前后可能导致碰撞、抓取失败或错误接触相位。于是现有方法只能把 `ρ` 设得保守，换取成功率，导致接受前缀长度和加速收益受限。论文的核心动机，是让 proposal 和 verification 共享更“物理知情”的场景表征，从源头提升 relaxed verification 的可靠性，而不是事后再修补 acceptance rule。

方法拆解

整体 pipeline 很直接：当前 observation 和语言指令先进入 target VLA 的 prefill；不同的是，作者额外用一个 World-Aware Bias, WAB 模块，从当前 RGB 图像提取一个与视觉 patch 对齐的 bias，并把它逐 patch 加到原始 visual embeddings 上，再送入 target 的 multimodal prefill。这样得到的 world-aware prefill hidden states 同时供 target 验证和 draft 提议使用，speculative decoding 循环本身不变。

WAB 的关键机制是“冻结 VAE 编码器 + 轻量可训练适配路径 + 训练期下一帧 latent 监督”。具体地，当前帧先映射到 VAE latent map，经 tokenization、spatial VideoEncoder、空间对齐和 MLP projector，得到与视觉 patch 同形状的 bias。训练损失由动作预测损失与 next-frame latent MSE 组成，辅助目标只在训练使用，推理时不预测未来帧，只基于当前观测计算一次 bias。作者的设计重点不在复杂解码器，而在把世界模型式的短期物理变化线索注入 prefill，使 target reference token 本身更适合 relaxed verification。

创新点含金量

第一，论文明确提出 relaxed VLA speculative decoding 的“scene-dependent reliability bottleneck”。这不是全新问题设定，但抓住了现有加速方法最影响机器人可用性的缺口，问题定义有价值，也比单纯追求 accepted length 更贴近 embodied control。

第二，WAB 以前注方式而非后验 acceptance 修正来引入 world awareness。它针对的是“固定距离阈值无法表达物理风险”的不足；从技术形态看更像是一个结构克制的表示层创新，而非全新解码算法。优点是可迁移性较强：只要方法依赖共享 prefill state 的 draft/target 验证框架，理论上都能接入。

第三，引入 NCF 作为 near-contact failure 指标，用来单独衡量接触敏感区域内的失败。这一指标不是方法创新核心，但它确实比总成功率更能支撑论文动机。可迁移性也较高，尤其适合评估 manipulation 中 relaxed decoding 的安全边界。

实验证据

实验覆盖较完整。主评测在 LIBERO 四个 suite 上，用 OpenVLA 作为主要 target，并在 `ρ`-based、KERV、HeiSD 三类 relaxed verifier 下，对比 Standard SpecDec 与 WA-SpecDec；此外还在更强的 ActionCodec target、以及 SIMPLER-Env 上的 OpenVLA/UniVLA 设定中验证泛化。核心结论基本一致：WA-SpecDec 在相同 verifier 和 decoding 配置下，通常同时提高成功率与 wall-clock speedup。论文还给出 matched-success speedup 为 1.5×，以及相对 speculative baseline 平均降低 18.6% 的 NCF。

证据最充分的有三点：一是主表格显示跨 verifier、跨 target policy 的一致改进；二是 accepted-length–success frontier 整体上移/右移，支持“不是单纯更激进地接受 token，而是更可靠地接受更长前缀”；三是 `ρ` 增大时，WA-SpecDec 成功率退化更平缓，说明收益确实来自更好的 shared conditioning，而非改规则。相对不足的是：实现细节被放到附录，正文未明确说明训练/推理额外开销占比、参数量变化和真实时延分解；代码也仅说 acceptance 后发布，复现实证仍待外部验证。

局限与风险

第一，方法本质依赖“当前帧可恢复足够物理线索”这一前提。若场景存在严重遮挡、透明/反光物体、细粒度接触几何难从 RGB 推断，WAB 能否稳定提供有用 bias，论文未明确说明。

第二，作者强调不改变 acceptance rule，但实际上改写了 target reference 分布；这意味着它并非对原始 VLA 分布保持等价，只对 world-aware target 自洽。对于“是否偏离原 target policy 意图”这一点，论文也明确承认不保证 vanilla VLA distribution preservation。

第三，评测均在模拟环境。虽然 LIBERO 和 SIMPLER-Env 覆盖多任务，但真实机器人中的感知噪声、时延抖动、控制误差会放大 near-contact 风险，sim-to-real 的可靠性收益是否成立，论文未明确说明。

第四，NCF 指标有解释力，但仍是失败后验统计，不直接约束安全。它说明“更少在近接触处失败”，但不能等价推出“执行更安全”或“碰撞代价更低”。

与我方向的关系

对 VLA 和 embodied AI，这篇论文的启发很直接：推理加速不应只在 token 层做 acceptance engineering，而应联动“控制相关表征”。它提供了一个很实用的思路，即在不改动作接口、不增 target 序列长度的前提下，把 world-model 式短期物理预测信号注入 prefill。对后续研究，可以进一步探索把接触风险、不确定性、或 affordance 先验写入 shared hidden state，而不是只调 verifier。

对多模态 safety/robustness，这篇工作也有参考价值。它没有显式做安全约束，但通过 near-contact 场景的可靠性提升，说明“场景依赖风险”可以通过表征层改善。一个自然延伸是把 NCF 这类接触敏感指标，与 uncertainty-aware decoding 或 risk-conditioned acceptance 结合。若你的重点是高层规划而非低层动作生成，这篇相关性会弱一些。
