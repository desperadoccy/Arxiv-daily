BridgeVLA++: A Data-Efficient, Generalizable, and Memory-Augmented Vision-Language-Action Framework for 3D Manipulation

作者: Peiyan Li (New Laboratory of Pattern Recognition (NLPR), Institute of Automation, Chinese Academy of Sciences, Beijing, China; School of Artificial Intelligence, University of Chinese Academy of Sciences, Beijing, China); Yuze Zhu (New Laboratory of Pattern Recognition (NLPR), Institute of Automation, Chinese Academy of Sciences, Beijing, China; School of Artificial Intelligence, University of Chinese Academy of Sciences, Beijing, China); FiveAges, Beijing, China); Hongtao Wu (ByteDance Seed); Xiao Ma (ByteDance Seed); Tao Kong (ByteDance Seed); Liang Wang (New Laboratory of Pattern Recognition (NLPR), Institute of Automation, Chinese Academy of Sciences, Beijing, China; 方向: VLA | 标签: VLA

简述: 面向3D操控的记忆增强VLA框架

筛选理由: 兼顾数据效率、泛化与记忆，适合相关方向

Deep Review

一句话判断

这篇论文最值得关注的是：把“3D VLA 的数据效率/泛化”与“显式时空记忆”统一到同一个 2D heatmap 接口里，且在多项仿真与真实机器人任务上给出了较强证据；值得精读，尤其适合关心 VLA 架构设计和记忆增强操控的读者。

核心问题与动机

论文要解决三个问题：3D VLA 往往吃数据、分布外泛化弱，而且多数方法没有显式记忆，因此在“需要回忆历史交互”或“目标几何被遮挡”的操控中表现差。作者强调，现有 3D VLA 常把动作当 token 序列预测，这会丢掉 3D 观察与动作之间的空间对应关系，也削弱了预训练 VLM 的迁移。

BridgeVLA 是其前作：把点云投影成多视角正交图，用 VLM 预测每个视角的 2D heatmap，再回投到 3D 动作；BridgeVLA++ 在此基础上补上记忆，但目标不是改成“更大模型”，而是在不破坏原有输入-输出对齐的前提下加记忆。

方法拆解

整体流程是：RGB-D → 点云 → 三视角正交投影 → VLM 输出多视角 heatmap → 聚合得到 3D 位置；同时用一个 MLP 预测旋转、夹爪、碰撞标志。推理采用coarse-to-fine：先在全局视图预测粗位点，再围绕该点裁剪、放大、重新渲染，做二次精定位。预训练阶段用 RoboPoint 的 12 万检测样本，把语言指定目标转成 2D heatmap，VLM 采用 PaliGemma（SigLIP + Gemma），用 heatmap 监督替代原本的 token 生成接口。

BridgeVLA++ 的核心是两个记忆：temporal memory 存初始锚帧、最近若干关键帧和自适应保留的子目标帧，用于 coarse stage 判断“下一步做什么”；spatial memory 把初始点云在当前 zoom/位姿下重新渲染，用于 fine stage 在遮挡情况下判断“具体在哪儿做”。两者都通过轻量 cross-attention 注入，不改 heatmap/action head 的主体结构；还扩展到双臂，只共享 backbone 和记忆，分离动作头。

创新点含金量

1）2D heatmap 作为 3D VLA 的统一接口。 这是对“动作 token 化”的直接替代，针对空间对应关系丢失的问题，属于实质性方法设计，不只是工程拼接；可迁移性较强，因为它依赖的是“可转成空间监督”的 VLM 预训练范式。

2）时空记忆的职责拆分：temporal 负责“做什么”，spatial 负责“在哪里做”。 这个划分很清晰，针对的是记忆依赖与遮挡两类失败场景，属于较有想法的结构化设计；但记忆注入本身是 attention 模块，机制上偏模块化，创新强度中等。

3）自适应子目标关键帧选择。 论文用可学习 retention 机制避免存所有历史帧，针对冗余与计算成本问题，属于实用型改进；可迁移到其他 episode-level memory policy。

4）双臂扩展。 共享场景级记忆、仅复制动作头，思路简洁，工程价值高，但更像对主框架的自然延伸，不算独立核心创新。

实验证据

仿真部分覆盖五个基准：RLBench、COLOSSEUM、GemBench、RMBench、MemoryBench。RLBench 上，BridgeVLA 平均成功率 90.5%，超过 SAM2Act 的 86.8%；BridgeVLA++ 达到 93.7%。消融很有说服力：去掉 heatmap decoding 后性能大幅崩塌（RLBench 平均 31.4%，另一组任务平均 5.3%），说明“heatmap 而非 token 动作”是关键；改成直接输入 3D position 也明显更差。去掉 spatial/temporal memory 都会掉点，但幅度不算巨大，说明基础框架已强，记忆主要补的是特定难点。

摘要还声称：BridgeVLA++ 在两个 memory-dependent benchmark 上取得 SOTA，且真实机器人上在 memory-dependent 任务中把平均成功率从 20.0% 提升到 93.3%；但在当前给出的正文片段里，RMBench/MemoryBench 的完整表格未展示，因此这些结论方向明确、细节证据不完整。总体上，“heatmap 接口有效”“记忆确实缓解遮挡/历史依赖”被充分支持。

局限与风险

首先，方法强依赖RGB-D、点云重建、正交投影和相机标定，一旦感知链路不稳，性能可能受影响。其次，spatial memory 依赖初始点云作为参考；如果初始观测本身就遮挡严重，记忆收益可能有限。第三，记忆模块与双臂扩展都建立在较大的 backbone 上，论文报告总参数约 2.92B，且仍有额外 269.77M 参数和更高延迟，部署成本不低。

另一个风险是：论文把记忆问题主要压缩成“coarse/fine 两阶段注意力注入”，对更长时域、多子任务、多失败恢复策略的覆盖是否充分，论文未明确说明；此外，训练和评估主要集中在 keyframe-based manipulation，连续控制场景的适用边界未展开。

与我方向的关系

对 VLA / embodied AI 很相关，尤其适合借鉴两点：一是把多模态预训练和下游操控统一到空间显式监督里，二是把记忆按“任务进度”和“局部遮挡”分解，而不是只堆一个通用 memory bank。对 multimodal safety/robustness 的启发在于：作者用 COLOSSEUM、GemBench、真实环境扰动去验证泛化，说明记忆增强不应只看平均成功率，也要看遮挡、分布外和新组合场景。

若你做后续研究，这篇最可借鉴的是：“保留 VLM 的 2D 先验 + 用结构化记忆补 3D 操作的时空缺口”。如果你关注长程规划、遮挡恢复、少样本真实机器人迁移，这篇很值得作为架构参考。

GUARD: Grounding Uncertainty and Ablation-Based Risk Detection for Diffusion-Based VLAs

作者: Suhas Hegde (Bosch Research India); Jitendra Yasaswi Bharadwaj Katta (Bosch Research India)

方向: VLA | 标签: VLA

简述: 面向扩散VLA的测试时风险检测

筛选理由: 聚焦VLA安全监测，方法新且泛化结果强

Deep Review

一句话判断

这篇论文最值得关注的是：它把 VLA 失败检测从“看分布外/看不确定性”推进到“直接测动作生成是否还依赖关键多模态证据”，方法在多政策、多任务、多 embodiment 上都有较稳的泛化；值得精读，尤其适合关心 VLA 运行时安全与鲁棒监测的人。

核心问题与动机

论文要解决的是：扩散式/flow 式 VLA 在陌生场景里可能生成“看起来合理但其实没被视觉和语言证据真正支撑”的动作，执行层面却没有明确告警。现有方法多依赖嵌入距离、动作不确定性、时间一致性或内部特征探针，能反映分布偏移或动作波动，但不能直接回答“这一步动作是否仍 grounded 在当前任务证据上”。

作者的动机很明确：对通用 VLA 来说，陌生观测不等于失败，因为模型也可能泛化成功；但如果动作头对关键 token 的依赖变弱，就可能是危险信号。论文因此把“grounding 衰减”当作失败检测的核心视角。

方法拆解

GUARD 是一个test-time 检测器，不改动预训练 VLA。流程是：先让冻结的 VLA 正常 rollout，取最终视觉语言模型的 KV cache；再对 cache 中按 token 对齐的位置做梯度 saliency，找出每个模态最重要的若干位置；随后把这些位置的 key/value 用该模态的均值表示做 counterfactual mean-ablation，并在同一个噪声输入上比较原始与 ablated cache 的一次 denoising 响应差异。

核心量有三类：敏感度 \(S_t\) 衡量原始与双模态 ablation 后响应变化大小；注意力熵 \(E_t\) 描述注意力是否集中；grounding efficiency \(G_t=S_t/(E_t+\epsilon)\) 把两者合在一起。再加上 modality bias、阈值 \(\theta_t\)、校准状态和 low-sensitivity indicator，组成 7 维诊断向量。最后用轻量时序分类器（GRU/LSTM/Transformer 均可，论文未明确固定一种）在滑窗上做在线失败预测，并用 functional conformal prediction 给出时间相关报警阈值。

创新点含金量

1）从“表示异常”转向“证据依赖性”：这是最实质的创新。它针对现有监测方法只看 embedding/uncertainty、却不看动作是否真正依赖任务证据的不足；不是简单工程拼装，概念上更接近“机制层失败检测”。可迁移性较强，理论上也适合其他带显式条件缓存的生成式控制器。

2）KV cache 上的 token 级反事实探测：作者利用 final KV cache 的 token 对齐性，做 saliency + mean-ablation，直接测动作头对视觉/语言 token 的依赖。这个设计比只看 attention weight 更可信，因为它结合了干预而非仅可视化；但它对架构有依赖，迁移到没有类似 cache 结构的模型会变弱。

3）把局部诊断做成在线风险信号：将单步 sensitivity、entropy 等转为时序窗口分类，再用 conformal 校准阈值，解决了机器人 rollout 中噪声大、单步不稳定的问题。这里属于“方法组合里有明确目标”的设计，工程性较强，但和运行时安全需求匹配度高，实用价值不错。

实验证据

实验覆盖四个基准/场景：LIBERO、SimplerEnv、MetaWorld、PhysicalAI-AV；模型包括 Pi0、SmolVLA、Alpamayo-1.5，共五个 policy-benchmark setting。基线包括 SAFE、欧氏/余弦/Mahalanobis/PCA-kMeans、LogpZO、FIPER、STAC/STAC-Single。主结果显示：GUARD 在 5 个设置里 4 个 unseen-task 最优、1 个第二，平均 unseen ROC-AUC 为 88.84%，比最强竞品 FIPER 高 5.73 个百分点，且 seen-task 平均只差最优 0.19。

消融也支持其关键设计：Top 10% salient cache ablation 最好，明显优于随机和最不显著选择；更大比例（30%、50%）总体变差，说明“精确删掉关键证据”比“粗暴扰动缓存”更有效。在线检测图里，GUARD 在 5 个设置中有 3 个 balanced accuracy 最优，并且部分设置报警更早。证据相对充分，但主要还停留在模拟/基准级评估，真实部署场景的证据论文未明确说明。

局限与风险

第一，只适用于 diffusion/flow-based action head，作者明确说不直接适用于 autoregressive VLA。第二，方法需要 saliency backward pass 并保留中间激活，峰值显存上升，虽然整体开销只有 1.14×/1.27×，但在更大模型或长上下文下可能更重。第三，论文依赖“mean ablation”作为反事实近似，这是一种保守替换，但未证明它一定对应真实因果删除；若 token 依赖高度非线性，诊断可能偏保守或误判。第四，实验虽跨任务/域，但未明确说明在更强分布外、动态遮挡、长时失败累积等场景下的稳健性边界。

与我方向的关系

对 VLA / embodied AI 很相关，尤其是运行时安全、失败预测、鲁棒监测方向。它的启发在于：不要只监测“模型像不像训练分布”，而要监测“动作还是否由任务证据支撑”。这对多模态 safety/robustness 很有价值，也能启发后续做证据一致性监控、反事实探测、token 级风险定位。如果你做的是带语言条件的机器人策略、或希望把监测信号从黑箱分数提升到可解释 grounding 指标，这篇值得借鉴。

CofactVLA: Deconfounding Vision-Language-Action Models via Counterfactual Intervention

作者: Yan Zhang (Department of Automation, Tsinghua University); Yinan Wu (Department of Automation, Tsinghua University); Haoran Duan (Department of Automation, Tsinghua University); Jungong Han (Department of Automation, Tsinghua University)

方向: VLA | 标签: VLA

简述: 用反事实去偏VLA

筛选理由: 方法新颖且有实证增益

Deep Review

一句话判断

这篇论文最值得关注的是：它把 VLA 的“视觉压语言”问题显式建模成因果混淆，并同时在特征层（CCR）+ 动作层（OPG）做反事实干预；如果你关心 VLA 的鲁棒性/OOD 泛化，值得精读。

核心问题与动机

论文解决的是 VLA 在机器人操控中常见的 vision-override：模型被显著视觉对象、熟悉布局等“视觉捷径”带偏，忽略语言指令。作者认为根因是机器人数据里视觉流远密于语言，导致内部表示发生 causal confusion。现有数据增强/改写方法难以跨开放世界扩展；而类似 classifier-free guidance 的推理期减法虽然能压视觉先验，但在连续动作空间里可能放大非对齐噪声，使轨迹偏离可行动作流并带来安全风险。

方法拆解

整体是一个双分支反事实框架 DDG：同一前向里构造事实分支（O,T）和反事实分支（仅 O，语言掩码），以隔离“无语言时模型会怎么做”的视觉偏置。然后在两个层面介入：
OPG 用于动作层：在 flow matching 中，把事实速度场 \(v_{cond}\) 沿反事实速度场 \(v_{uncond}\) 做正交投影，去掉共线的视觉偏置，再用指导系数 \(\gamma\) 强化剩余的正交部分，得到最终 causal velocity。
CCR 用于特征层：截取 transformer 后层的 Key/Value 特征，计算事实/反事实协方差差值 \(\Delta\Sigma\)，取其正特征子空间作为 bias basis \(U_{bias}\)，再将原特征沿该子空间做投影削减，强行去除视觉捷径。论文声称在 final layers 的 KV cache 上拦截实现；训练细节与是否端到端联合训练，论文未明确说明。

创新点含金量

1. 双路径反事实图 DDG：针对“视觉主导语言”的因果混淆做显式建模，属于问题形式化层面的实质创新，可迁移到其他多模态决策任务。
2. OPG（动作层正交投影）：相对直接减法，它只去掉与视觉偏置共线的部分，避免无脑放大噪声；这是对 CFG 类方法的结构化改造，创新偏方法性，迁移到连续生成/控制较有潜力。
3. CCR（特征层协方差去偏）：利用事实-反事实协方差差分提取 bias 子空间，属于较强的表示去混淆思路；若反事实分支可构造，方法可迁移，但依赖“正负特征空间可分”的假设。
4. 单次前向内构造反事实分支：工程上更易落地，但严格说更多是实现形态上的优势，不是核心理论创新。

实验证据

实验覆盖 LIBERO、LIBERO-Plus 和真实机器人。LIBERO 上基于 π0.5 架构，CofactVLA 平均成功率 98.5%，优于 π0.5 的 96.9% 和 X-VLA 的 98.1%。LIBERO-Plus（训练仅用标准 LIBERO，测试 OOD）总分 69.1%，优于 π0 的 53.6%，作者强调在 Robot、Layout 等扰动下更稳。真实机器人四个任务、每任务约 100 条 expert trajectories，标准环境平均 90.8%，OOD 场景平均 75.8%，相对 π0.5 的 23.5% 提升 52.3%。消融显示 CCR 和 OPG 各自有效，合并最好；OPG 优于 Add/Sub/CAG，说明正交化比简单引导更稳。
证据充分支持“方法能提升鲁棒性和 OOD 泛化”，但对“因果去混淆真的被充分验证”证据仍偏间接，缺少更细粒度的机制分析与失败案例量化。

局限与风险

一是方法依赖反事实分支与协方差差分，若语言掩码后的分支仍混入复杂语义，bias 子空间估计可能失真。二是论文明确承认受限于 base VLM 的 zero-shot grounding：没学过的概念，干预也无法凭空生成。三是对严重物理遮挡（如机械臂挡住相机）仍脆弱，说明它主要解决“视觉捷径”，不是完整感知问题。四是大量理论建立在可分解子空间、contrastive eigengap 等假设上，现实中是否普适，论文未明确说明充分性边界。

与我方向的关系

对 VLA / embodied AI 很相关，尤其适合关注“语言是否真的在驱动动作”的研究。对多模态 safety/robustness 的启发是：不要只做数据增强或后处理减法，而要把反事实分支、表示层去偏、动作层几何约束联动起来。若你做开放世界机器人、OOD 泛化或多模态安全，这篇可借鉴其“双层干预”范式；若你更关注高效训练或通用规划，它的直接贡献相对次要。

CofactVLA 将 VLA 的 vision-override 问题建模为因果混淆，并通过特征层 CCR 与动作层 OPG 的双路径反事实干预，显著提升了模拟与真实机器人中的鲁棒泛化。

Item Response Theory for AI Safety

作者: Joshua Fonseca Rivera (Independent); Neil Shah (Independent); David Demitri Africa (UK AI Security Institute); Konstantinos Voudouris (UK AI Security Institute)

方向: 其他 | 标签: LLM-SAFETY

简述: 用IRT重构AI安全评测

筛选理由: 评测降本增效，方法实用

Deep Review

一句话判断

这篇论文最值得关注的是：它把 IRT 从“压缩 benchmark”推进到“解释、降本、审计”三位一体的 AI 安全测量框架；如果你关心安全评测方法论，值得精读。

核心问题与动机

论文要解决的是：安全 benchmark 分数到底测到了什么、多个 benchmark 是否在重复测量、以及模型是否会在评测时“演戏”。作者指出，现有安全评测存在强相关、冗余、部分项目几乎对所有模型都没区分力，以及 API/评测过程可能被策略性操纵等问题，因此单一总分很难可信解释。

其核心动机不是再做一个新 benchmark，而是把安全评测当作心理测量问题：用 item-level 响应来反推模型潜在能力、挑出信息量高的题目、并识别异常响应模式。这个切入点对“分数是否可解释、是否可压缩、是否可审计”三个问题同时给出统一工具。

方法拆解

整体流程是：收集 8 个安全 benchmark 的 item-level 输出，用各 benchmark 自带的 judge 进行二值化评分；随后对每个 benchmark 拟合 2PL IRT，估计 item 难度 `bj`、区分度 `aj` 和模型能力 `θm`。作者使用正则化先验稳定估计，并比较了 1PL/3PL/4PL，最终采用 2PL。

在分析层面，论文做了三件事：一是把 8 个 benchmark 的能力矩阵做因子分析，找潜在维度；二是用 Fisher information 选静态短测和 CAT（computerized adaptive testing）做 benchmark 缩减；三是用 person-fit（lz）、历史能力变化和 response fingerprint 做黑盒审计。推理上仍是模型对 item 逐题作答，IRT 只是在事后估计与选题，并不改训练过程。

创新点含金量

1. 把安全 benchmark 解释成三种潜在能力：refusal strictness、truthfulness、contextual harm。它直接针对“单一 safety score 不可信”的不足，属于实质性测量解释而非简单工程拼接；可迁移到其他多维评测，前提是有足够 item-level 数据。

2. 用 IRT 做降本评测：三组各 25 题的静态测试、以及约 10 题的自适应测试就能恢复不少 benchmark 分数/排序，成本降 97–99%。这是对“全量评测太贵”的直接解决方案，属于方法+系统化应用，迁移性较强。

3. 用 person-fit/能力漂移/fingerprint 做审计：它不是只看总分，而是识别 selective sandbagging、uniform sandbagging 和 API 替换。这个点对“评测可信性”很重要，属于测量学方法的安全审计化，可迁移到任何能拿到 item 响应的黑盒评测。

实验证据

数据覆盖 8 个 benchmark、5,067 个保留 item、192 个模型；跨 benchmark 的潜变量分析使用 169 个模型，latent-structure 分析用 134 个模型。结果上，三因子模型最好，解释 77% 方差，且比一/二因子拟合更好；三个因子分别对应 refusal strictness、truthfulness、contextual harm。论文明确反驳“一个总安全能力”能概括全部 benchmark 的想法。

压缩实验中，75 个静态题（不到总题量 2%）在 held-out 模型上比随机子集有更低 RMSE，排名恢复也更高；CAT 在多个单项 benchmark 上用约 10 题就接近完整分数，且全套 composite 在所有预算下都优于随机。审计方面，person-fit 在 10% 假阳性率下可抓住 80–100% 的 selective sandbagging；能力漂移可补足 uniform sandbagging，使总检出率达 94–97%；fingerprint 在 16 个 endpoint 中识别 13/14 个模型身份。证据对“能压缩、能审计”支撑较强，但对“这些因子具有外部效度”支撑仍不足。

局限与风险

第一，latent 因子的命名来自 loading pattern 的经验解释，论文自己也承认未做充分的构念效度验证，所以这些维度更像“测量上可分离的方向”，不等于真实安全本体。第二，跨 benchmark 分析虽然已算大规模，但对传统 psychometrics 来说样本仍偏小，且只用了能拿到完整响应的模型子集，可能影响因子稳定性。

第三，审计实验主要是 prompted sandbagging 的 model organisms，不是经过专门对抗训练的真实规避模型；作者也明确说，方法未证明能抓住专门训练来逃避审计的模型。第四，fingerprint/能力漂移对 hosted API 有用，但其结论依赖重复采样与固定 item 集，遇到更强路由变化或响应随机性时可能变弱。

与我方向的关系

对 VLA、embodied AI、多模态 safety/robustness 的直接关联不强，因为论文对象是 LLM 安全 benchmark；但方法论很可借鉴：把任务级响应当 item，做潜变量建模、短测压缩与异常行为审计。推断如果未来机器人/VLA 评测也有大量可标注的离散任务项，这套 IRT + CAT + person-fit 框架可用于低成本评测策略鲁棒性、拒答/过拒答倾向、以及部署前后行为漂移。

对多模态 safety/robustness 的启发尤其大：不要只看平均分，而要先问“评测在测哪个维度”“哪些题真正有区分度”“模型是否在某些子集上异常作答”。这对后续做 robot policy audit 或多模态安全基准整合很有参考价值。

  • 三个关键词：IRT；安全评测降本；模型审计

该工作表明，AI 安全 benchmark 不应被视为单一分数，而应作为可测量、可压缩、可审计的多维心理计量对象。

Explicit Language Memory for Long-Horizon Planning in Vision-Language-Action Models

作者: Houze Xu (Fudan University); Jizhong Li (Fudan University); Ziyi Ye (Fudan University)

方向: VLA | 标签: VLA

简述: 显式语言记忆提升长程VLA规划

筛选理由: 长程任务痛点明确，含仿真与实机验证

Deep Review

一句话判断

这篇论文最值得关注的是：它把“长时序任务的历史”显式压缩成可读语言记忆，并与低层动作控制解耦，确实缓解了 VLA 的阶段混淆问题；值得精读，尤其适合关注长程规划、可解释性和分层 VLA 的读者。

核心问题与动机

论文要解决的是 VLA 在长时序任务中的两个核心痛点：一是单帧/短历史条件下容易忘记已完成阶段，导致跳步、重复或提前进入下一阶段；二是直接拼接全部历史帧代价高、难实时部署。作者还指出，端到端动作微调可能削弱 VLM 背骨的高层语义能力。这个动机是成立的，而且直指 embodied AI 中“看懂了但执行顺序错了”的典型失败模式。

与现有方法相比，论文认为仅在当前决策上做 reasoning trace（如 CoT）不够，因为那只是“当前一步的解释”，缺少跨决策持续状态；而纯历史感知策略又多依赖视觉记忆或检索，不够紧凑、不可读。这里的核心假设是：把历史显式写成自然语言 memory，可以作为阶段推进的语义锚点。

方法拆解

整体是一个两层递归框架：高层 VLM 输入全局指令、当前观测和上一轮 memory，输出更新后的 memory \(m_t\) 与子任务 \(s_t\)；低层 VLA 只接收当前观测和子任务，输出固定长度动作 chunk \(a_{t:t+H}\)，其中论文给出 \(H=30\)。推理时先高层更新语义状态，再由低层执行，执行后回到环境获得新观测，形成闭环。

训练上，高层用 PaliGemma 做自回归预测，目标同时包含 memory 和 subtask；低层沿用 π0.5 的 action expert，用 flow-matching/监督式动作目标训练。论文还构造了一个自动标注管线：从专家视频、技能标签和时间戳出发，用通用 VLM 生成“过去式 memory + 当前 subtask”的监督对。这个设计的关键不是单一公式，而是把长程历史压缩为可监督的语言状态变量；论文未明确说明两层是否联合端到端训练，文中写的是独立训练。

创新点含金量

1. 显式滚动语言记忆：针对长任务中的阶段混淆，属于实质性方法设计，不只是把提示词变长；可迁移到其他需要阶段管理的 VLA/agent 任务。
2. 高层语义、低层控制解耦：针对“语义规划”和“运动控制”优化目标冲突，属于较稳妥的系统性拆分，偏方法论创新，迁移性较强。
3. 自动化 memory 标注管线：解决 memory 监督难题，工程价值高，但创新性相对弱，更多是支撑主方法落地。
4. 可解释闭环日志：不是核心性能贡献，但对失败分析和调试很有用，适合后续 robustness/safety 研究借鉴。

实验证据

实验覆盖三个场景：BEHAVIOR-1K 的“turn on radio”，Genie Sim 3.0 的包裹分拣（单包与连续多包），以及真实 XLeRobot 双臂移动平台的抓放任务。baseline 是原生 π0.5，提出的方法是在其上加 explicit language memory。指标是 stage-wise success rate，而不是只看终局成功率，这一点比较适合长任务分析。

结果上，radio 任务平均从 30.0% 提升到 40.0%；Genie Sim 单包从 41.7% 到 63.9%，连续任务从 31.3% 到 46.9%；真实机器人从 62.5% 到 66.3%。定性分析显示，baseline 容易在“该按按钮时直接进入放置”“该扫描时跳到篮筐”等阶段上提前推进，而 memory 版本能把“已完成什么、下一步是什么”显式记录下来。证据较充分支持“memory 减少阶段混淆、提升阶段成功率”；但对“泛化能力提升多少”与“失败恢复到底有多稳定”证据仍偏有限。

局限与风险

一是增益主要体现在中长链路任务，短任务上的提升有限，论文也承认 real-robot 任务较短，memory 作用空间不大。二是高层 VLM 每步都要额外调用一次，带来延迟、算力和系统复杂度，论文未给出时延开销。三是论文只报 stage success，没有随机种子、方差或置信区间，统计稳定性不足。四是对接触丰富动作（如按按钮）帮助有限，说明语言记忆只能解决“做什么/何时做”，不能替代低层控制精度。

与我方向的关系

与 VLA 和 embodied AI 高度相关：它提供了一种把长时序规划外显为语言状态的做法，适合做分层规划、任务进度跟踪和可解释执行日志。对多模态 safety/robustness 也有启发：memory 可把“失败、未完成、下一步意图”显式暴露出来，便于做错误归因、恢复策略和安全监控。若后续结合视觉/触觉记忆，论文最后的展望也暗示了更强的鲁棒闭环。

Suppression Sticks, Locality Is Fragile: A Closed-Loop Target-and-Control Audit of Task-Vector Negation in VLA Policies

作者: Shaoguang Wang (The Hong Kong University of Science and Technology (Guangzhou)); Weiyu Guo (The Hong Kong University of Science and Technology (Guangzhou)); Rushi Dai (The Hong Kong University of Science and Technology (Guangzhou)); Yiren Zhao (The Hong Kong University of Science and Technology (Guangzhou)); Yandong Guo (AI2 Robotics); Hui Xiong (The Hong Kong University of Science and Technology (Guangzhou); The Hong Kong University of Science and Technology)

方向: VLA | 标签: VLA

简述: 审计VLA任务向量负编辑的脆弱局部性

筛选理由: 系统揭示负编辑常伤及他任务，评估框架有参考价值

Deep Review

一句话判断

这篇论文最值得关注的是：它把“任务向量取反/减法是否局部生效”从静态模型编辑问题，首次系统地搬到 闭环 VLA 行为审计 上，并证明其虽能快速压制部分目标技能，但局部性非常脆弱；值得精读，尤其适合做 VLA 编辑/遗忘/安全方向的负面结果与评测设计参考。

核心问题与动机

论文研究的是：对一个多任务 VLA policy，能否用 单技能 expert 与共享 base 的权重差分 构成 task vector，并通过一次减法在不重训、无需删除时数据和梯度的前提下，去掉某个特定技能，同时尽量不伤害其他技能。这个问题对 embodied safety 很关键，因为现实里需要删除危险、过时或用户要求移除的行为。

现有 task arithmetic/模型编辑工作大多只在分类或生成等“单次前向”场景讨论 locality；但机器人控制是闭环的，轻微权重改动会通过状态分布漂移累积成 rollout 失败。作者认为，真正相关的问题不是“静态 loss 看起来是否局部”，而是“删掉一个技能会不会悄悄破坏其他技能”。这正是现有工作缺失之处。

方法拆解

方法本身很直接：先有一个多任务目标模型 `θGoal`，再为每个技能训练一个从共享初始化出发的单技能 expert，定义该技能的 task vector 为 expert 与 base 的参数差分；编辑时对目标模型做 `θedit = θGoal - ατ_i`。编辑作用于 VLM backbone、action head、proprio projector 三部分，α 控制压制强度。多技能同时删除则减去多个向量之和，并用近似 `1/√|S|` 的缩放维持扰动范数。

论文真正的贡献不在新算法，而在 audit protocol：对每个被减掉的技能，不只测目标任务是否失效，还测所有其他控制任务的闭环成功率，并区分三类结果：目标-控制分离、目标抗删、以及全局坍塌。训练/删除时开销方面，task vector subtraction 在编辑时是 data-free、gradient-free 的，但前提是单技能 expert delta 需预先存在；这一点很重要，说明其“廉价”只发生在 edit-time，而非全流程。

创新点含金量

第一，闭环 target-and-control 审计框架。它针对以往只看目标遗忘、不看控制保留的不足，是实质性评测创新，且可直接迁移到 VLA unlearning、policy editing、safety red-teaming。

第二，三种行为区间的经验图谱：分离、抗删、全局坍塌。这个发现说明 task-vector negation 不是统一有效的“局部删除”工具，而是高度技能依赖。这个结论更偏实证发现，但对后续方法设计有高价值。

第三，局部性脆弱性的系统证据。作者不仅看 in-sample，还用 held-out 初始状态验证，显示目标压制可泛化，但控制保留明显不稳。这不是新机制，而是对“locality”概念在闭环控制中重新定标，具有较强可迁移性。

第四，与梯度法和多架构/多 suite 的对照。它更多是扎实工程验证而非方法创新，但帮助确认现象不是单一架构偶然产物。

实验证据

主实验基于 MergeVLA 的 LIBERO-Goal 10 个技能完整 10×10 矩阵。结果最核心：10 个技能里，5 个出现“目标被压下且控制部分保留”的分离区，3 个目标抗删，2 个则目标与控制一起崩。固定 α=1.0 时，5 个可压制技能的目标成功率降到 ≤15%，但 baseline-normalized 控制保留均值只有 57.8%；在 held-out 初始状态上，5 个目标都保持 0/20，但控制保留均值进一步只有 52%，且 5 行中有 4 行至少把一个无关控制技能打到 0%。这充分支持了“目标压制可以稳，局部性不稳”的主结论。

对照方面，作者比较了 NegGrad、NegGrad+、Gradient-Difference 和 leave-one-task-out retrain oracle。在匹配面板上，所有方法都能把目标 t0 压到 0/20；纯 NegGrad 会把 9 个控制全打崩，Gradient-Difference 的控制保留优于 task-vector subtraction，NegGrad+ 则不稳定。这个证据支持“闭式减法不是最优保留方案，但胜在无删除时数据/梯度”的定位。跨架构上，在连续回归、离散 token、flow-matching 三类 action head 都观察到目标压制复现；但在 Spatial 没有干净分离，在 Object 和 Long10 更接近控制坍塌，说明现象具有一定普适性，但边界也很明显。作者还发现均值 cosine 不能解释这种差异。
不足在于：baseline 对比只在一个 target、一个 seed、一个预算上做得较细；机制解释主要停留在相关性诊断，未被充分证明。

局限与风险

第一，论文最强结论主要成立于 MergeVLA-Goal + 预训练的单技能 expert bank。如果没有这些 expert delta，方法前提就不成立；作者也明确说直接对 off-the-shelf multitask vector 取反是破坏性的。

第二，seed 鲁棒性有限。完整 10×10 矩阵主要基于单个训练 seed，虽然有小规模三 seed probe，但不足以证明模式稳定到可泛化为普遍规律。

第三，真实机器人外推缺失。所有结果都在 LIBERO MuJoCo 模拟中，论文未明确说明真实机器人上的表现，因此对 sim2real、执行噪声、视觉偏移下的 locality 不能下结论。

第四，它更像“行为遮蔽”而非真正遗忘。relearning probe 显示，被压制技能重新学回比从 task-naive base 学起快得多，因此不能把此法视为 certified unlearning 或长期安全删除。

与我方向的关系

对 VLA / embodied AI 来说，这篇文章最大的启发不是“如何删技能”，而是“如何正确评估删技能”。以后做 policy editing、模块化能力开关、拒绝行为注入，不能只看目标任务下降，还必须看全控制矩阵、held-out 初始状态、worst-control retention，这对 embodied safety/robustness 很关键。

对 多模态 safety，它提示一个重要风险：权重层面的轻量编辑可能在 target-only 指标上看似成功，但在闭环中引入隐蔽副作用。对后续研究，可借鉴其 target-control 审计范式，进一步结合 OOD 场景、对抗指令、长期任务和真实机评估。若你做 VLA unlearning，这篇很适合作为“闭式方法的强基线 + 负面边界案例”；若做更强的 retain-aware 编辑，则可把它当作零删除时成本的参考下界。

Retrieve in Time, Correct in Frequency

作者: Yuze Fan (Everwise-Tech Co., Ltd.; Tongji University); Yue Cao (Research Institute of Tsinghua University in Shenzhen; Everwise-Tech Co., Ltd.; Fudan University); Pengjie Gao (Tsinghua Shenzhen International Graduate School, Tsinghua University); Haojia Gao (Research Institute of Tsinghua University in Shenzhen); Guangqiu Guo (Research Institute of Tsinghua University in Shenzhen; Everwise-Tech Co., Ltd.; Tsinghua Shenzhen International Graduate School, Tsinghua University); Ziyue Zhang (Research Institute of Tsinghua University in Shenzhen); Junbo Tan (Research Institute of Tsinghua University in Shenzhen); Bokui Chen (Tsinghua Shenzhen International Graduate School, Tsinghua University); Zhuo Zou (Fudan University); Xueqian Wang (Tsinghua Shenzhen International Graduate School, Tsinghua University)

方向: VLA | 标签: VLA

简述: 检索对齐记忆，频域校正VLA动作

筛选理由: 训练免费、提效明显，长程任务增益突出

Deep Review

一句话判断

这篇论文最值得关注的是：提出了一个完全不训练、只在测试时对冻结 VLA 做“按进度检索 + 频域纠偏”的轻量修正框架；如果你关心 VLA 的部署稳定性、长时序纠错和低开销在线适配，值得精读。

核心问题与动机

论文要解决的是冻结式 chunk-based VLA 在长时程操作中容易出现的两类问题：一是执行误差累积，二是相似视觉状态在不同任务阶段造成的检索歧义。作者认为，仅看当前帧做 retrieval 可能拿到“进度不匹配”的成功经验；而直接 replay 或时域融合又会覆盖掉原策略的反应性结构。论文动机很明确：既要用成功经验纠错，又不能破坏冻结策略本身的局部细节。

现有方法的关键不足在于，要么依赖训练额外模块/适配器，要么把 memory 直接注入 sampler 或时域动作，容易引入额外计算和行为覆盖。作者据此提出：先用执行历史确定“现在处在记忆轨迹的哪个阶段”，再只把该阶段动作的低频运动趋势作为修正项转移给原策略。

方法拆解

RTCF 分两步：Retrieve in Time 和 Correct in Frequency。输入是当前观测 \(o_t\) 和语言指令 \(\ell\)，冻结 VLA \(\pi\) 先输出一个 action chunk \(A^\pi_t\)；同时系统维护一个成功轨迹 memory bank，每条记忆包含视觉序列和动作序列。视觉侧用冻结 SigLIP 特征做 PCA 压缩并归一化，动作侧直接存 FAST 的 DCT/BPE token，目的是压缩存储、便于在线检索。

核心检索模块 PMA（Progressive Memory Alignment）本质上是一个因果版 subsequence DTW：它不只看当前图像，而是把“截至当前为止的执行历史”与每条成功轨迹做单调对齐，并维护一个 frontier，避免过早锁死在某个阶段。每来一个新观测，只更新一次 frontier，最后得到最佳 memory 和对齐位置。随后在频域中读取对应动作 chunk，将其 DCT 系数与冻结策略输出做差，只对运动通道的低频部分做 clipped residual transfer：高频成分和 gripper 决策保持原策略不变。推断上，这相当于用 memory 修正“全局运动趋势”，而不去替换细粒度控制。

创新点含金量

第一，PMA 的进度感知检索针对的是“同一视觉状态可能对应不同任务阶段”的歧义。它不是工程上简单地加历史窗口，而是显式维护单调对齐前沿；这属于实质性方法设计，且思路可迁移到其他需要阶段识别的 embodied retrieval 任务。

第二，频域而非时域的纠偏针对的是“记忆一旦直接 replay 就会覆盖原策略反应性”的问题。只传低频残差、保留高频细节，这个设计不是纯拼接式工程，而是利用了动作 chunk 的结构先验；可迁移性较强，尤其适合平滑连续控制。

第三，训练-free + 单次前向 + CPU 后处理是部署层面的重要贡献，解决的是在线适配成本高的问题。它更多是系统级创新，但和前两点结合后，形成了完整闭环，因此不是单纯工程堆叠。

实验证据

实验在 LIBERO-Long / Spatial / Object / Goal 四个 suite 上进行，每个 suite 10 个 task，共 2000 episodes/condition。基线是冻结的 PI-FAST。论文还做了两个消融：去掉历史感知对齐的 Frame-NN，以及去掉频率选择的 Time-Domain。

主结果是：总体成功率从 86.4% 提升到 88.4%；其中 LIBERO-Long 从 61.6% 提升到 68.6%，是最主要收益来源。Spatial 和 Object 也有小幅提升，Goal 基本不变。消融显示两部分都重要：去掉历史对齐后 Long 变为 63.6%；去掉频率选择后 Long 直接掉到 50.0%，说明“直接时域覆盖”会显著伤害成功率。证据充分支持的结论是：进度对齐与低频残差转移是互补的。证据不足之处在于：论文未明确说明在更多 VLA 基座、更多机器人任务或更大 memory bank 上是否仍稳定成立。

局限与风险

一是任务与平台范围偏窄，只在 LIBERO 和冻结 PI-FAST 上验证，外推到真实机器人、不同动作表征或更强 VLA 未明确说明。二是依赖成功记忆库，且检索是对完整 active-suite bank 的精确搜索；当记忆规模更大、经验更稀疏或分布漂移更强时，性能与延迟都可能受影响。三是收益主要集中在 Long，说明它更适合长时程、多阶段任务，对近乎满分的任务提升有限。四是作者明确说 paired transitions 只是描述性证据，不是严格反事实，因此“为什么某些回合被救回/被破坏”的因果解释还不够强。

与我方向的关系

这篇论文和 VLA / embodied AI 关系很直接：它提供了一种冻结策略上的 test-time robustness 修正范式，尤其适合多阶段操作中的进度歧义、误差累积和局部失败恢复。对多模态 safety/robustness 的启发在于：不要盲目覆盖模型输出，而是做有界、选择性的纠偏；这比简单 retrain 更适合部署场景。对后续研究可借鉴的点是：把“历史一致性”与“动作频谱结构”分开建模，做成可插拔后处理模块。

SAFECAST: Robust Failure Detection for VLA Policies with Contrast-Set Training and Calibration

作者: Harshitha Rajaprakash (University of Southern California, Thomas Lord Department of Computer Science); Aditeya Prajapati (University of Southern California, Thomas Lord Department of Computer Science); Rong Xue (University of Southern California, Thomas Lord Department of Computer Science); Abrar Anwar (University of Southern California, Thomas Lord Department of Computer Science); Jesse Thomason (University of Southern California, Thomas Lord Department of Computer Science)

方向: VLA | 标签: VLA

简述: 用对比集提升VLA失效检测

筛选理由: 解决部署偏移下失效检测，实验扎实

Deep Review

一句话判断

这篇论文最值得关注的是：它不是改 VLA 策略本身，而是针对 “部署分布偏移下失效检测校准失真” 这一实际痛点，用 contrast set 同时增强 probe 训练与 conformal calibration；如果你关心 VLA 安全监测、OOD 可靠性或 sim-to-real 风险控制，值得精读。

核心问题与动机

论文研究的是冻结的 VLA policy 在部署时遇到视觉、语言或多模态分布偏移后，如何更可靠地提前检测 rollout 失败。现有 SAFE 类方法的基本思路是：从策略隐藏状态中训练 failure probe，再用 functional conformal prediction 得到随时间变化的风险阈值。但它依赖一个关键前提：校准轨迹要和部署轨迹分布匹配。一旦部署时出现 clutter、distractor、光照变化、novel object、初始状态变化或指令改写，隐藏态风险轨迹会变，源分布上校准出的阈值就可能失配，导致漏报或晚报。

这个问题重要，因为 VLA 在实验室内表现好，不代表真实部署安全；而比起重训练主策略，一个轻量级、可插拔的 runtime failure detector 更现实。论文的核心动机因此很明确：不是提升任务成功率，而是提升失败预警在分布偏移下的稳健性。

方法拆解

SAFECAST 建立在 SAFE 之上。冻结 VLA policy \( \pi \) 后，在每个时刻提取 pre-final-layer hidden state \(h_t\)，用一个轻量 MLP probe 输出 failure score \(r_t=f_\phi(h_t)\)。再基于成功轨迹做 functional conformal calibration，得到时变阈值 \(\delta_t\)；部署时若 \(r_t>\delta_t\)，就判定 rollout 正走向失败。

SAFECAST 的关键干预点不是模型结构，而是 probe 训练集和 calibration 集的数据分布。作者从源分布 rollout 出发，施加视觉扰动、语言扰动或联合扰动，并在扰动条件下 重新执行冻结策略，得到新的 contrast-set rollouts，而不是把原轨迹简单重标注。这一点很关键：因为动作序列和隐藏状态都会变，作者明确不假设源轨迹和扰动轨迹可交换。之后，SAFECAST 用这些 contrast trajectories 扩充 probe 训练集、校准集，形成 TrainAug、CalAug 和两者同时增强的完整 SAFECAST。额外还有基于 DTW 的主动去重，避免训练集中出现大量近重复轨迹。训练细节、probe 架构超参等论文正文未明确说明。

创新点含金量

第一，把 contrast sets 从“评测脆弱性”转成“增强失效检测训练/校准”工具。针对的是 SAFE 在 deployment shift 下校准失配的问题。这属于有明确问题导向的实质性方法改造，不只是换数据增强名称；而且思路可迁移到其他 hidden-state monitor、甚至非 VLA 的 sequential policy 监测。

第二，同时增强 probe training 与 conformal calibration，而不是只做其中一步。这针对的是“表示可分性”和“阈值对齐”两个不同瓶颈。实验证明不同 backbone 受益点不同：π0 更吃训练增强，π0-FAST 更吃校准增强。这一点说明作者不是把 SAFECAST 当成单一技巧，而是揭示了训练与校准在鲁棒监测中的不同作用，具有方法论价值。

第三，联合视觉+语言 contrast set 优于单模态。这解决的是部署偏移往往是多模态组合而非独立单模态的问题。这个创新更偏经验性发现，但对 embodied AI 很实用：如果只对图像或指令单独增强，可能不足以覆盖真实部署风险空间。

第四，sim-train + real-calibration 优于只用小规模真实数据训练 probe。这不是全新的理论贡献，但对机器人很有吸引力，因为它直接回应真实 rollout 成本高的问题，可迁移性较强。

实验证据

实验覆盖真实机器人 DROID/Franka 和仿真 LIBERO。真实侧评测 π0 与 π0-FAST；仿真侧评测 π0 与 OpenVLA。指标用 F1 和 ROC-AUC，并对 \(\alpha\in\{0.1,\dots,0.9\}\) 做 sweep，避免只汇报单个 operating point，这点是加分项。

主要结果比较扎实。表 1 中，完整 SAFECAST 在四个设置上 ROC-AUC 都高于 SAFE：Sim-π0 从 0.3267 到 0.4469，Sim-OpenVLA 从 0.5937 到 0.8014，Real-π0 从 0.2626 到 0.3807，Real-π0-FAST 从 0.5501 到 0.6664。多数提升带统计显著性。F1 也整体提升，但并非所有配置都由完整 SAFECAST 最优，例如 Real-π0 上 TrainAug 的 F1 高于完整 SAFECAST，说明不同增强位置的收益确实有差异。消融方面，图 4 显示联合视觉+语言优于单模态；对 π0，平均 F1 从 visual-only 0.649 / language-only 0.664 提升到 visual+lang 0.753，证据较强。sim-to-real 方面，图 5 说明“仿真训练 probe + 真实 contrast-set 校准”优于“只用较小真实数据训练并校准”，但正文未给出该图的精确数值，因此这一结论方向明确、量化力度略弱。

总体看，“SAFECAST 在分布偏移下优于 SAFE”被充分支持；“联合多模态增强更好”也有明确支撑；但“为何不同 backbone 分别更依赖训练或校准增强”的机理解释仍偏现象描述，证据不足以支持更强因果结论。

局限与风险

第一，方法强依赖 contrast-set 是否覆盖未来部署偏移。作者也承认，若真实扰动超出 contrast-set 分布，检测性能仍可能下降；这意味着 SAFECAST 更像“面向预期 shift 的稳健化”，不是普适 OOD 保障。

第二，真实数据规模不大，尤其 DROID 训练/校准 rollout 数量有限，且成功/失败分布不平衡明显。虽然作者做了 controlled sampling，但这会让真实场景结论的外推范围受到限制。

第三，论文强调 conformal calibration，但也明确 没有恢复任意 shift 下的 exchangeability 保证。因此它本质上是经验上改善 calibration alignment，而不是提供分布偏移下严格统计保证。

第四，扰动空间仍较有限，主要是 distractor/clutter、背景变化、指令改写/否定等；更复杂的任务级变化、动力学变化、传感器异常是否有效，论文未明确说明。

与我方向的关系

对 VLA 和 embodied AI 很相关。它给出的启发是：安全性不一定先靠更强 policy，也可以靠更强的 hidden-state runtime monitor；而 monitor 的成败很大程度取决于训练/校准数据是否覆盖部署偏移。对多模态 safety/robustness 来说，这篇文章尤其提醒：视觉和语言偏移不能分开想，联合 contrast augmentation 对 failure detection 更有效。

如果你做 VLA 安全，可直接借鉴三点：一是把 contrast-set 作为风险监测器的数据构造工具；二是把“表示学习增强”和“阈值校准增强”分开分析；三是在 sim-to-real 中优先考虑“仿真大规模 probe 训练 + 小规模真实校准”的低成本方案。若你主要关注 policy learning 本身，这篇文章相关但属于后验安全监测层，而不是策略优化层。
