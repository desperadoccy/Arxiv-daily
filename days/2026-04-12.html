Act Wisely: Cultivating Meta-Cognitive Tool Use in Agentic Multimodal Models

方向: MM | 标签: MM

简述: 解耦奖励抑制盲目工具调用

筛选理由: 问题重要，方法新颖，但增量偏训练技巧

Deep Review

创新: 论文直击 agentic 多模态模型中的一个关键但常被忽视的问题：模型不会判断“该不该用工具”，而是倾向于盲目调用工具。作者提出 HDPO（Hierarchical Decoupled Policy Optimization），把“答对题”和“少用工具”从传统的单一标量奖励中解耦成两个独立优化通道，并通过只在正确轨迹内部比较工具使用效率的 conditional advantage，避免奖励耦合导致的信用分配混乱。更重要的是，这种设计自然形成了“先学会做对，再学会少用工具”的隐式课程学习机制。

方法: 方法上，作者首先分析了现有 GRPO/类似 RL 方案中 accuracy reward 与 tool penalty 混合后，在 advantage normalization 下会被准确率方差淹没的问题，因此单纯加 tool penalty 很难真正抑制工具滥用。HDPO 为每条 rollout 分别计算 accuracy reward 与 tool reward：前者在所有轨迹上做标准组内相对优势估计，后者则仅在回答正确的轨迹集合中比较谁更省工具。最终训练目标是两个 PPO/GRPO 风格损失的加权和，从而让正确性与效率分别获得干净、正交的梯度信号。除此之外，作者还构建了较严格的数据清洗流程，过滤掉伪造工具反馈、过时的工具依赖样本以及低质量推理链，以保证 RL 环境和 SFT 先验的可靠性。

实验: 实验最突出的结果是：Metis 在多个视觉感知、文档理解和数学推理基准上同时实现了更高精度和极低工具调用率，明显打破了“多用工具才更强”的直觉。例如图 1 中，Metis 在 HRBench/V*Bench 上把工具使用率从常见的 80%–98% 降到约 2%，同时准确率反而提升。消融实验也显示，相比仅优化准确率的标准 GRPO，加入 HDPO 后在 V*Bench、HRBench-8K、CharXiv(RQ) 等任务上持续增益，说明工具节制本身能够改善推理质量，而不只是节省开销。

Deep理由: 这篇工作对多模态 agent 训练中的一个核心瓶颈——工具滥用与奖励耦合——给出了非常清晰的理论诊断和实证解决方案。若你关注 multimodal agent、tool use、RLHF/RLAIF 式优化或高效推理，这篇论文的思想非常值得借鉴。

SIM1: Physics-Aligned Simulator as Zero-Shot Data Scaler in Deformable Worlds

方向: 其他 | 标签: VLA

简述: 物理对齐仿真扩展柔性操作数据

筛选理由: 面向柔性操作痛点，零样本扩数结果亮眼

Deep Review

创新: 论文的核心创新在于提出了面向可变形物体操作的 real-to-sim-to-real（R2S2R）数据引擎 SIM1，把“先做物理对齐，再做数据扩增”作为第一原则，而不是依赖传统刚体仿真的后验适配。其关键贡献是同时在几何、动力学和运动三个层面对齐现实：用高精度扫描构建米制一致的场景孪生、用变形稳定求解器校准布料物理、再用扩散式轨迹生成与筛选机制扩展高质量操作数据。更重要的是，它证明了纯合成数据在可变形操作上可以接近真实数据训练效果，并具备零样本真实部署能力。

方法: SIM1包含三个阶段。首先在 SIM1-Scene 中，作者通过高精度 3D 扫描、重建和后处理，获得带纹理、尺寸准确的服装 mesh，并结合机器人 URDF 与环境资产，构建与真实场景严格对应的数字孪生。其次在 SIM1-Sim 中，作者基于 Newton-VBD 扩展出 deformation-stable AVBD 求解器，通过自适应应变约束抑制布料过度拉伸，并借助真实机器人与仿真同步执行进行人工物理参数校准。最后在 SIM1-DataGen 中，作者把示教轨迹拆分为“交互段”和“移动段”，保留真实有效的抓取/接触配置，用条件扩散模型生成两段之间的人类式过渡运动，再通过状态规则和视频判别器过滤无效样本，并配合视觉随机化生成大规模训练集。

实验: 实验表明，在代表性的 T-shirt folding 任务上，纯仿真生成数据训练的策略可实现 90% 零样本真实成功率；在 π0.5 和 π0 上，合成数据训练不仅接近甚至在泛化设置下超过真实数据基线。作者还给出很有说服力的数据缩放结论：在 in-domain 场景下，约 15 条 synthetic 样本相当于 1 条 real demonstration 的训练价值，而在某些泛化设置下这一比值可提升到约 5:1。更关键的是，从零训练时真实小数据完全学不起来，而合成数据管线仍能达到 76% 成功率，说明增益确实来自高质量仿真监督而非预训练先验。

Deep理由: 这是少见在可变形操作上把几何重建、软体物理和 VLA 数据扩增完整打通的工作，而且实验结果对“仿真能否替代真实数据”给出了非常强的实证支持。对于关注 VLA、sim2real、服装操作或数据引擎的研究者，这篇论文具有很高参考价值。

Seeing but Not Thinking: Routing Distraction in Multimodal Mixture-of-Experts

方向: MM | 标签: MM

简述: 揭示多模态MoE推理受路由分心

筛选理由: 问题新颖，机制分析扎实，但增益较有限

Deep Review

创新: 本文首次系统提出并实证分析多模态 MoE 中的“Seeing but Not Thinking”现象：模型能看懂图像内容，却在后续推理阶段失效，而同一问题转成纯文本又能答对。作者进一步提出“Routing Distraction”假设，指出问题不主要在跨模态语义对齐失败，而在于视觉输入干扰了中间层对任务相关推理专家的路由激活。基于这一机制解释，论文给出一种无需训练、可在推理时直接施加的 routing-guided intervention，并在多模型多基准上稳定提升表现。

方法: 方法分三步。第一，作者设计跨模态 concept intervention，直接在隐藏状态层面做“图像概念→文本概念”的替换，证明 MoE 架构中间层确实存在跨模态语义共享，因此“看懂了但不会想”不能简单归因于表示空间未对齐。第二，他们用 expert activation frequency difference 识别 domain experts 与 visual experts，发现视觉专家主要集中在早层和末层，而领域推理专家集中在中间层，呈现明显的层级分离。第三，作者通过比较同一问题的图像版与文本版在各层的 routing divergence（JSD），发现视觉输入会在中间层显著扰动路由；随后在推理时对识别出的领域专家增加路由权重（soft/hard guidance），以恢复正确的推理专家激活。

实验: 实验覆盖 Qwen3-VL、Kimi-VL、Llama4-Scout 三个多模态 MoE 模型，以及 6 个 benchmark，包括语义等价设置（文本渲染成图像）和真实视觉数学场景。结果显示 soft routing guidance 在大多数设置下稳定优于 baseline，复杂视觉推理任务上最高提升达到 3.17%。更有价值的是，作者通过错误分析证明失败样本中 68.2%–73.1% 来自推理错误而非感知错误，并验证了“中间层路由偏移越大，推理准确率越差”的关键相关性。

Deep理由: 这篇工作的问题定义非常精准，分析链条也较完整：从现象识别、机制验证到干预修复形成闭环，对理解多模态 MoE 为什么‘看得见却想不对’很有启发。对于做多模态大模型、MoE 路由机制、视觉推理鲁棒性的研究者而言，具有很高的参考价值。

AVGen-Bench: A Task-Driven Benchmark for Multi-Granular Evaluation of Text-to-Audio-Video Generation

方向: MM | 标签: MM

简述: 面向文生音视频的细粒度评测基准

筛选理由: 评测框架系统，揭示现有T2AV模型关键短板

Deep Review

创新: 本文的核心创新在于提出了首个真正面向 Text-to-Audio-Video（T2AV）生成的任务驱动、多粒度评测基准 AVGen-Bench，不再把音频和视频割裂评估，也不满足于粗粒度 embedding 相似度打分。它进一步构建了一个“专用轻量模型 + 多模态大模型（MLLM）”的混合评测框架，能够从基础感知质量、跨模态同步到细粒度语义可控性进行系统诊断，并揭示当前模型在语义可靠性上远落后于视听美学质量。

方法: AVGen-Bench 先从真实用户场景出发，构建了覆盖 3 大领域、11 个子类别的 235 条高质量复杂提示词，强调任务驱动而非指标驱动，平均 prompt 长度和复杂度显著高于现有 benchmark。评测框架分为三层：基础单模态质量（视觉美学、音频制作质量）、基础跨模态对齐（AV Sync、Lip Sync），以及六个细粒度模块（文本渲染、人脸一致性、音高准确率、语音可懂度与连贯性、物理合理性、整体语义对齐）。其中每个细粒度模块都采用 specialist model 先做结构化提取，再由 Gemini 等 MLLM 进行规则验证或语义审计，从而兼顾信号级精度与高层语义推理能力。

实验: 实验覆盖了 Veo 3.1、Sora 2、Kling 2.6、Wan 2.6、Seedance、LTX、Ovi 等当前主流闭源/开源/级联系统，结果显示：主流模型在视觉质量上已非常强，但在文本生成、物理因果、复杂语义遵循和音乐音高控制上普遍薄弱，尤其音高控制几乎全线失效。作者还通过 10 位专家对 85 个任务进行人工标注，证明除 Pitch 任务外，大部分自动指标与人工判断具有较强相关性，同时重复运行和子集采样实验表明评测框架具备较好的稳定性。

Deep理由: 这篇工作对 T2AV 评测范式的推动非常关键：它不仅补上了联合视听生成缺少高质量 benchmark 的空白，还清晰揭示了当前大模型“好看但不可靠”的核心短板。对于做多模态生成、世界模型、AIGC 评测或音视频对齐研究的人来说，这篇论文具有很强的参考价值。

OpenVLThinkerV2: A Generalist Multimodal Reasoning Model for Multi-domain Visual Tasks

方向: MM | 标签: MM

简述: 多模态RL新目标提升通用推理

筛选理由: 提出新RL目标，通用性强，需看实验扎实度

Deep Review

创新: 论文的核心创新有两点：第一，提出 G2RPO（Gaussian GRPO），用基于一维最优传输的非线性分布匹配替代 GRPO/EMA-GRPO 的线性标准化，把不同任务的 advantage 强制映射到标准高斯分布，从而缓解多任务视觉奖励拓扑差异、重尾异常值和梯度失衡问题。第二，作者进一步提出 task-level 的 response length shaping 与 entropy shaping，把“感知型任务需要短而准输出”和“推理型任务需要长链条思考”显式纳入 RL 训练目标，使模型在 perception 与 reasoning 间获得更稳定的折中。

方法: 整体方法是在 Qwen3-VL-Instruct-8B 上做多任务 RL 后训练，训练数据来自过滤后的 OneThinker-600k。其核心是对每个任务内的 reward 做排序，再通过经验 CDF 到标准正态分布逆 CDF 的映射，得到高斯化 advantage，用于替代原始 GRPO 的均值方差标准化；这样不同任务的 advantage 分布都被统一到 N(0,1)。在此基础上，作者增加两类任务级 shaping：一类用梯形长度奖励约束回答长度，让推理题更愿意展开链式思考、视觉题更倾向简洁直接；另一类用熵区间正则把探索强度限制在合理范围，避免 entropy collapse 或 entropy explosion。最终形成通用多模态模型 OpenVLThinkerV2。

实验: 实验覆盖 18 个 benchmark、6 大任务类型，包括通用 VQA、数学、图表、文档理解、空间推理和 grounding，整体提升比较全面。相对基线 Qwen3-VL-Instruct-8B，论文报告在 MMMU、MathVista、ChartQA、OCRBench、RefCOCO 系列等任务上都有明显增益，并在多个文档理解与空间推理任务上超过 GPT-5、Gemini 2.5 Pro 等专有模型。消融实验也表明，性能提升主要来自 G2RPO，而长度 shaping 与熵 shaping 进一步提供互补增益。

Deep理由: 这篇论文在“多任务多模态 RL 如何稳定训练”上提出了一个很有启发性的统一视角，G2RPO 也具有较强的方法新颖性和实用潜力。虽然结果很亮眼，但论文目前仍是 preprint，且若干关键结论更多依赖经验验证，理论与泛化性还需要后续社区复现和更大规模实证支持。

ActiveGlasses: Learning Manipulation with Active Vision from Ego-centric Human Demonstration

方向: VLA | 标签: VLA

简述: 第一视角主动视觉模仿操控

筛选理由: 主动视觉零样本迁移新颖，实用性强但偏系统集成

Deep Review

创新: 论文提出了 ActiveGlasses：用头戴智能眼镜上的双目相机作为唯一视觉源，在人类演示阶段记录第一视角图像与 6DoF 头部运动，在机器人部署阶段再把同一相机装到 6DoF 感知臂上复现“主动视觉”。更关键的是，它没有做人手到机械臂的直接动作重定向，而是转向对象中心表示，学习物体 6DoF 轨迹与头部运动的联合预测，从而实现裸手演示到机器人操作的零样本迁移。该工作把“人类主动看”的行为从噪声变成了可学习信号，这是本文最有价值的视角转变。

方法: 系统层面，作者使用 XREAL Air 2 Ultra 记录头部位姿，用 ZED Mini 采集双目视频，并通过手势+音频 UI 实现轻量化裸手数据采集。数据处理上，利用 FoundationStereo 估深、Grounded-SAM/SAM2 做手和目标分割、FoundationPose 估计被操作物体 6DoF 位姿，再借助桌面三个球完成坐标系标定，把观测统一到世界坐标下的点云表示。策略层面，基于 3D point cloud 的 object-centric policy 采用两个 diffusion heads，分别预测绝对物体轨迹和相对头部运动；机器人执行时由主操作臂跟踪物体目标轨迹、辅助感知臂复现头部运动，从而在遮挡和远距离精细任务中动态调整视角。

实验: 作者在 Book Placement、Bread Insertion、Occluded Distant Water Pouring 三个高遮挡/高精度真实任务上验证了系统，且部署时只使用单个主动视觉相机输入。相较于去掉主动视觉的版本和 π0.5 基线，ActiveGlasses 在最终成功率上分别提升约 35%、25%、30%，显示主动视觉和 3D 对象中心表示的组合确实有效。另一个亮点是跨平台零样本迁移：同一策略可直接迁移到 Flexiv 与 UR5，两者前两阶段表现接近，说明方法具备较好的跨 embodiment 泛化能力。

Deep理由: 这篇工作在“主动视觉 + 第一视角人类演示 + 对象中心零样本迁移”三者结合上很新颖，系统设计也完整，实验任务选取得当，适合做 VLA/模仿学习/人机迁移方向的研究者重点关注。缺点是实验规模仍偏小、任务类型有限，且系统依赖多阶段感知模块串联，距离大规模通用范式还有一定距离，因此我给出‘推荐’而非‘必读’。

UniversalVTG: A Universal and Lightweight Foundation Model for Video Temporal Grounding

方向: MM | 标签: MM

简述: 轻量统一视频时序定位基础模型

筛选理由: 跨数据集统一训练，轻量且SOTA，实用价值高

Deep Review

创新: 论文的核心创新在于提出了一个真正“通用”的轻量级视频时序定位模型 UniversalVTG：通过离线 Query Unifier 将不同数据集里风格迥异的文本查询统一到一个标准化陈述语义空间，从根源上缓解跨数据集联合训练时的负迁移。另一方面，作者证明了对 VTG 而言，与其依赖参数巨大的 MLLM，不如通过“统一监督 + 大规模跨数据集预训练 + 高效时序解码器”来获得更强的跨域泛化和长视频处理能力。

方法: 方法上，UniversalVTG 采用共享视觉编码器 + 查询规范化 + 轻量级时序定位头的三段式框架。首先使用 PerceptionEncoder 作为统一且高效的视觉 backbone，在不同数据集间建立共享视频表征；其次通过离线 LLM-based Query Unifier，把疑问句、短语、命令式、叙述式等异构查询改写为统一的过去时陈述句，减少语言风格差异带来的优化冲突；最后基于 HieraMamba 进行长时序建模与边界回归，并通过 Stage-I 的 100 万级 query-segment 对预训练、Stage-II 的五大 benchmark 联合微调，得到单一共享权重模型。

实验: 实验上，单个 UniversalVTG checkpoint 在 GoalStep、Ego4D-NLQ、TACoS、Charades-STA 和 ActivityNet-Captions 五个数据集上整体达到或逼近各自专用 SOTA，显著优于此前统一模型 UniVTG。更值得注意的是，它只有约 6000 万参数，却能在多个基准上匹敌甚至超过 2B/7B 级 MLLM 方法，同时在长视频 grounding 的计算量和推理时延上低两个数量级以上。消融实验也清晰表明：性能提升并不是因为“测试时把 query 改写得更好”，而是因为统一语义空间确实缓解了联合训练中的负迁移，并进一步释放了大规模预训练的价值。

Deep理由: 这是 VTG 领域里一篇非常有代表性的“反大模型堆参数”工作：它清晰展示了统一数据接口和监督标准化如何替代部分模型规模，具有很强的方法论价值。对于关注视频理解、机器人感知检索、跨域多模态学习的人来说，这篇论文不仅结果强，而且提供了可复用的统一训练范式。

MolmoWeb: Open Visual Web Agent and Open Data for the Open Web

方向: MM | 标签: MM

简述: 开源视觉网页代理与数据集

实验: 在 Bench2Drive 闭环基准上，Orion-Lite 取得 80.6 Driving Score，超过 ORION teacher 的 77.7，并刷新当时 SOTA；同时 Success Rate 也略有提升，多能力平均分提升 5.8。效率上更突出：reasoning 模块延迟从 524.6ms 降到 3.5ms，约快 150×，整系统推理速度提升约 3×，显存占用从 31GB 降到 8GB。消融实验还表明，单独蒸馏或单独 GT 监督都不如二者联合，且较浅 decoder 反而优于更深模型，说明该任务所需的 latent planning capacity 可能没有想象中那么大。

Deep理由: 这篇工作对“LLM 是否真的必须在线参与自动驾驶推理”提出了非常有分量的反证，结论对 VLA、端到端驾驶和模型部署三条线都很重要。若你关注高效驾驶模型、VLA 压缩或闭环评测，它是非常值得精读的一篇。

HiRO-Nav: Hybrid ReasOning Enables Efficient Embodied Navigation

方向: MM | 标签: MM

简述: 按动作熵自适应触发导航推理

筛选理由: 问题真实，方法实用，兼顾性能与推理成本

Deep Review

创新: 论文的核心创新在于提出了 HiRO-Nav，一种能够基于自身动作熵（action entropy）自适应决定“是否需要思考”的具身导航智能体，而不是像现有方法那样每步都推理或固定频率推理。作者进一步通过实证分析证明：高熵动作只占少数，但往往对应关键决策点（如转向、进入新区域、接近目标物体），且仅在这些高熵步骤激活显式推理，能够带来更高的任务收益与更好的 token 效率。另一个重要创新是配套提出了“混合监督微调 + 两阶段在线强化学习”的训练范式，专门解决 hybrid reasoning 能力训练中的模式塌缩问题。

方法: HiRO-Nav 的核心机制是先让 VLM 在 no-thinking 模式下输出动作，并用该动作首 token 的熵来估计当前决策不确定性；当熵超过阈值 τ 时，再切换到 thinking 模式生成 CoT 推理与最终动作，否则直接执行动作。为训练这种能力，作者先构建 hybrid reasoning dataset：从专家轨迹中筛出高熵样本，用 Gemini 生成推理链，和普通无推理样本一起进行混合监督微调。随后使用两阶段 PPO 在线强化学习：第一阶段只训练 no-thinking 能力，第二阶段在 hybrid reasoning 策略下只优化 thinking 分支，并通过 KL 正则保持第一阶段学到的无推理能力不退化。另为避免连续高熵导致反复思考，作者引入 No-Thinking Window 限制模型不能过于频繁地触发推理。

实验: 在 CHORES-S ObjectNav 基准上，HiRO-Nav 达到了 81.0% SR 和 57.2% SEL，在成功率上优于 no-thinking、dense-thinking 和 thinking-every-K-steps 等策略，同时 token 开销远低于 dense-thinking。实验清晰验证了“过度思考”问题：dense-thinking 在该任务上反而显著劣化，而仅对高熵动作思考取得了最佳性能-效率折中。消融实验还表明，两阶段 RL 和 KL 约束对防止 no-thinking 能力塌缩非常关键；此外即便将长期记忆从 GT semantic map 替换为深度模型估计的噪声 map，方法仍保持较强鲁棒性，并在 Pass@k 上展现出很高的性能上界。

Deep理由: 这篇工作抓住了当前 LRM/具身智能中非常关键但常被忽视的问题——推理并非越多越好，而应在真正不确定、真正关键的决策点使用。论文不仅提出了直观且有效的熵驱动 hybrid reasoning 框架，还通过较完整的分析、训练设计和实验结果证明了其在性能与效率之间的实际价值，对后续高效 embodied agent 设计很有启发。

方法: ViVa 以 Wan2.2 预训练视频扩散 Transformer 为基础，通过 latent injection 将多视角图像、当前 proprioception、未来 proprioception 以及 scalar value 都编码成统一的“latent frame”序列。训练时，当前观测作为干净条件前缀，未来 proprioception 和 value 作为带噪目标帧，模型用 flow matching 进行去噪学习，从而联合恢复未来机器人状态和价值。其 value supervision 不是简单成功/失败分类，而是基于 episode 进度构造 normalized return，并对失败轨迹整体上移一个常数间隔，以显式拉开“失败但走到后期”和“成功早期阶段”的歧义。推理时只需当前观测，模型经过极少步扩散采样即可输出未来 proprioception 和当前 value，用于 RECAP 中的 advantage estimation。

实验: 实验上，ViVa 在真实世界 box assembly 上将 RECAP 的成功率从 VLM-value 的 58% 提升到 73%，throughput 从 11 提升到 14，说明它不仅提高成功率，也改善了执行效率。定性结果显示，ViVa 能在 box assembly、shirt folding、toilet paper organization 三类任务中更稳定地跟踪任务进展，并在错位、滑落、受力不均、提前释放等细粒度操作错误发生时出现明显价值下降。进一步地，在未见过的 pants folding 上，ViVa 仍能准确对应关键阶段给出单调上升的价值轨迹，展示出比 VLM-based value 更强的跨物体泛化能力。

Deep理由: 这篇工作抓住了机器人 value modeling 的关键痛点：静态 VLM 不擅长建模操作过程，而视频生成模型天然适合作为 progress/value estimator。对于做 VLA、机器人 RL、world model 或 value function 研究的人，这篇论文提供了一个非常值得重视的新方向：用视频生成先验统一建模 task progress、physical dynamics 与 policy improvement。

创新: 论文的核心创新在于重新定义了 world model 在导航中的角色：不是在测试时直接拿生成的未来视角做决策证据，而是把这些生成结果转化为可持久利用的语义-空间结构，并进一步生成规划伪标签来监督学生模型。作者提出了一个 teacher-student 框架，teacher 通过未来视频生成、语义目标/障碍物 grounding、BEV 代价图与 FMM 规划，产出高质量轨迹监督；student 则学习从单帧第一视角图像和语言指令直接预测轨迹。这个思路本质上把“生成式世界模型”从 action-time reasoner 变成了 training-time supervision engine，这是本文最有价值的概念贡献。
