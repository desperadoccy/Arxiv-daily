Fringe Projection Based Vision Pipeline for Autonomous Hard Drive Disassembly

方向: 其他 | 标签: VLA

简述: 面向硬盘拆解的高精度3D视觉

筛选理由: 工程价值高，但偏任务视觉，非VLA核心

Deep Review

创新: 论文提出了一条面向硬盘自动拆解的完整视觉管线：用 Fringe Projection Profilometry（FPP）做高速高精度3D重建，在检测到盘片侧时再按需触发深度补全网络 MMDC-Net，从而兼顾效率与反光场景鲁棒性。另一个关键创新是 2D 实例分割与 3D 深度都来自同一套相机-投影仪系统，天然像素级对齐，避免了工业 RGB-D 系统常见的跨传感器配准误差。作者还结合 sim-to-real 训练策略和公开合成数据集，降低了真实标注成本。

方法: 方法上，作者首先用 YOLOv11n-seg 对 HDD 的 11 类关键部件与螺丝进行实例分割，并基于是否检测到 platter 进行逻辑驱动的状态识别，将样本分为 Platter Facing 和 PCB Facing。对于 PCB Facing，直接使用标准 FPP 进行三维重建；对于 Platter Facing，由于镜面盘片会导致 FPP 深度缺失和相位失效，系统会选择性调用 MMDC-Net，将稀疏 FPP 深度、投影照明灰度图和 Depth Anything V2 相对深度先验融合，生成完整深度图。训练上，实例分割网络先在 Blender 数字孪生生成的 3685 张合成图像上预训练，再用少量真实 HDD 图像微调，实现 sim-to-real 迁移。

实验: 实例分割方面，系统取得了 box mAP@50 = 0.960、mask mAP@50 = 0.957，其中螺丝检测 box AP@50 = 0.929、mask AP@50 = 0.910，说明其对拆解关键紧固件也有较高可靠性。深度补全方面，作者比较了多种 Depth Anything V2 骨干，在 Base 版本下实现 RMSE 2.317 mm、MAE 1.836 mm，并在部署优化后让盘片侧整套学习推理栈达到 12.86 ms 延迟、77.7 FPS 吞吐。状态识别中，platter presence 的精度和召回均达到 100%，保证了自适应深度补全触发逻辑的稳定性。

Deep理由: 这篇工作在工程系统整合和工业拆解场景适配上做得很扎实，特别适合关注机器人拆解、工业视觉和具身操作感知的研究者。若你关心 VLA/端到端决策本身，它更偏“高质量感知前端”而非动作学习核心，但作为真实拆解任务的视觉基础设施很有参考价值。

EmbodiedHead: Real-Time Listening and Speaking Avatar for Conversational Agents

方向: 其他 | 标签: VLA

简述: 实时可听说一体对话头像

筛选理由: 工程完整，实时交互强，但偏头像生成非VLA核心

Deep Review

创新: 论文的核心创新有三点：第一，提出了面向实时对话头像生成的首个 Rectified-Flow DiT + 可微渲染器端到端框架，在仅 4 步采样下实现高保真、实时生成。第二，针对现有 listening-speaking 工作依赖双音频流、无法满足因果式用户-LLM交互的问题，作者设计了单流音频接口、显式逐帧 listening-speaking state 条件和 Streaming Audio Scheduler，实现真正可部署的实时听说一体化行为建模。第三，通过“系数空间预训练 + 图像域联合细化”的两阶段训练，显著缩小了 3D 参数监督与最终 2D 渲染质量之间的鸿沟。

方法: 方法上，模型以 FLAME 参数作为3D运动表示，使用 Rectified Flow 训练 DiT 预测目标窗口内的人脸运动速度场，并结合历史动作、参考身份/姿态、音频特征、运动幅度控制和听说状态等多重条件。听说状态一方面被拼接进每帧运动 token，另一方面通过 FiLM 调制进入音频 cross-attention，从而在 listening 阶段抑制错误张嘴、在 speaking 阶段增强唇动一致性。推理时，Streaming Audio Scheduler 将麦克风流与 LLM 语音流因果地拼接成统一窗口并同步输出状态标签，实现快速轮换对话。训练分两阶段进行：先在 FLAME 系数空间做 flow matching 预训练，再联合 GAGAvatar 渲染器进行图像域微调，以提升最终视觉质量。

实验: 实验上，EmbodiedHead 在作者自建 speaking/listening 测试集和公开 DualTalk 基准上都取得了很强结果：在唇动同步、上半脸动态、运动多样性及渲染质量上整体优于 DiffPoseTalk、ARTalk 和 DualTalk。尤其在 2D 渲染质量上，Stage II 联合图像监督显著提升了 PSNR/SSIM/LPIPS，证明端到端优化是有效的。效率方面，完整系统在单张 RTX 3090 上达到 59 FPS，运动系数生成超过 900 FPS，满足实时交互要求。

Deep理由: 如果你关注 VLA、数字人、对话式智能体或语音驱动头像，这篇论文非常值得读，因为它同时解决了“实时性、听说一体化、最终可视质量”这三个实际落地中的核心矛盾。相比很多只在离线指标或3D参数上做优化的工作，它更接近真实 LLM Avatar 系统部署形态。

Robust Resource Allocation in RIS-Assisted Wireless Networks Integrating NOMA and Over-the-Air Federated Learning

方向: FL | 标签: FL

简述: RIS-NOMA空口联邦学习资源优化

筛选理由: 偏通信优化，方法常规，但场景较新且鲁棒性有参考价值

Deep Review

创新: 论文提出了一个同时融合 RIS、NOMA 与 over-the-air federated learning（AirFL）的统一上行混合网络框架，使通信用户与学习用户能够在同一时频资源上并发传输。其核心新意在于：在存在不完美 CSI 与不完美 SIC 的现实条件下，作者从 AirFL 收敛角度显式推导了 optimality gap，并将“最小化学习最优性缺口”作为资源分配目标，而不是只优化速率、MSE 或能效。进一步地，论文使用具备时序记忆能力的 LSTM-DDPG 来联合优化用户功率、RIS 相位与去噪因子，从而提升鲁棒性与在线自适应能力。

方法: 作者首先建立了多 RIS 辅助的上行混合系统模型：NOMA 用户上传通信信号，AirFL 用户上传局部梯度，并通过空口叠加完成模型聚合。随后在不完美 CSI 和残余 SIC 干扰下，推导了 AirFL 聚合 MSE、梯度偏差/方差以及全局训练 optimality gap 的上界，进而把联合优化问题表述为一个带 QoS、MSE、功率和 RIS 相位约束的非凸问题。考虑到离线全局优化难以处理高维、动态、随机环境，作者将问题进一步改写为逐时隙的 MDP，并采用 LSTM-DDPG 学习在线资源分配策略。LSTM 用于捕获信道和系统状态的时间相关性，DDPG 负责在连续动作空间中输出功率控制、RIS 配置和去噪参数。

实验: 仿真结果表明，所提 LSTM-DDPG 在收敛速度、训练稳定性和最终性能上均优于 DDPG、SAC 与 A2C 等基线 DRL 方法，尤其在信道不确定性较强时表现出更低方差和更强鲁棒性。论文还显示，引入 RIS 后，系统能够更好地平衡 NOMA 通信 QoS 与 AirFL 聚合精度，从而有效缩小 optimality gap。整体上，该方法在混合业务场景下比仅面向通信或仅面向学习的设计更具综合收益。

Deep理由: 这篇论文的价值在于把无线资源分配与联邦学习收敛分析紧密结合，问题设定贴近实际，且 DRL 方案有一定新意。如果你关注 RIS+NOMA+AirFL 的交叉方向，这篇很值得看；但从当前内容看，理论与实验仍偏仿真驱动，工程可落地性和方法细节完整度还需要进一步验证。

EvoComp: Learning Visual Token Compression for Multimodal Large Language Models via Semantic-Guided Evolutionary Labeling

方向: 未知 | 标签: MM

筛选理由: AI 解析失败

Deep Review

创新: 论文提出 EvoComp，将视觉 token 压缩从基于注意力/相似度的启发式筛选，转化为“直接面向 MLLM 输出损失”的监督学习问题。其最核心的设计是语义引导的进化式标注：用进化搜索寻找在给定文本条件下最能保持任务性能的 token 子集，并结合基于词表锚点的语义分组来抑制冗余。另一个亮点是为压缩器训练专门设计了 GHM + 余弦相似度正则的损失，以处理正负样本极不平衡和保留/丢弃 token 语义边界模糊的问题。

方法: EvoComp在视觉编码器/对齐模块之后、LLM之前插入一个轻量级 encoder-only Transformer 压缩器，输入同时包含视觉 token 与文本 token，输出每个视觉 token 的保留概率。训练时，作者先对每个样本用进化算法搜索最优二值 mask，使保留后的视觉 token 在原始 MLLM 上获得尽可能低的任务损失；同时通过“最近词表 embedding”把语义相近的视觉 token 分组，并约束每组最多保留一个 token。随后用这些搜索得到的标签监督训练压缩器，并使用 GHM loss 解决类别/难度不均衡，再用 cosine similarity loss 拉开保留与丢弃 token 的表示。推理时只需一次前向即可完成 token 筛选，且无需改动原始 MLLM。

实验: 在 LLaVA-1.5-7B 上，EvoComp 在 3x 压缩下可保持 99.3% 原始精度，在 9x 压缩下仍保持 94.9%，整体优于 FastV、VisionZip、DART、SparseVLM 等方法。在高分辨率的 LLaVA-NeXT-7B 上，即使从 2880 个 token 压到 160 个（18x 压缩），仍能保持 92.1% 基线性能。效率方面，A100 上 LLaVA-NeXT-7B 的 prefill 最多加速 4.1x、总时延加速 2.6x；手机端总时延最高可达 2.0x 加速，说明其具备较强部署价值。

Deep理由: 这篇工作在视觉 token 压缩方向上提出了较完整且工程可落地的新范式，实验也覆盖了精度、速度、迁移性与消融，质量较高。若你关注 MLLM 推理加速、边端部署或 token pruning，这篇很值得读；但其核心仍偏工程优化而非基础范式颠覆，因此我给“推荐”而非“必读”。

CogGen: A Cognitively Inspired Recursive Framework for Deep Research Report Generation

方向: 未知 | 标签: MM

筛选理由: AI 解析失败

Deep Review

创新: 本文的核心创新有两个：一是提出了受认知写作理论启发的分层递归生成框架 CogGen，用宏观-微观双层循环替代传统线性流水线，使系统能够在写作过程中根据新证据进行“全局回改”和结构重组。二是提出 Abstract Visual Representation（AVR），把图表生成从像素/代码级实现中抽象出来，让模型先表达“视觉意图”再交给渲染器执行，从而实现文本与视觉内容的同步协同规划。另一个重要贡献是提出 CLEF 评测框架，从认知负荷和多模态协同角度评估深度研究报告质量，而不只看表面文本质量。

方法: CogGen 由 Planner、Writer、Reviewer 三类智能体组成：Planner 负责检索与全局大纲规划，Writer 按章节并行生成文本和 AVR，Reviewer 负责过程监控与全局评审。整体上采用 Macro-Cognitive Loop，在每一轮先规划、再写作、再评审，并把评审反馈用于下一轮全局重构，从而避免一次性定稿的线性锁死。局部章节层面采用 Micro-Cognitive Cycle，各章节线程执行 Search–Replan–Write 的递归流程，但跨章节冲突不在局部解决，而是延迟到全局评审阶段统一处理。最终，Render Agent 将 AVR 转换为可执行图表代码并完成可视化渲染，同时配合后验校验降低图表数据幻觉。

实验: 实验在自建的 OWID 多模态深研究报告数据集和 WildSeek 上进行，结果显示 CogGen 在开源方法中达到 SOTA，并在 OWID 上整体质量接近人工专家报告，在 WildSeek 上整体超过 Gemini Deep Research。消融实验表明，递归评审机制主要提升组织性、深度和整体协同性，而 AVR 驱动的原生多模态协同显著提升 Alignment 与 Synergy。作者还显示 AVR + verification 能将图表数据幻觉率从约 60%+ 降到 28%，这是很有说服力的工程价值点。

Deep理由: 这篇工作在“深研究代理 + 多模态报告生成”方向上提出了较完整的系统方案，尤其是递归重构和 AVR 的设计很有启发性，实验也较充分。缺点是方法仍然高度依赖强闭源模型与 judge-based 评测，理论收敛性和真实用户效用验证还不够扎实，因此我给出高质量推荐但未到必读级。

IMA-MoE: An Interpretable Modality-Aware Mixture-of-Experts Framework for Characterizing the Neurobiological Signatures of Binge Eating Disorder

方向: MM | 标签: MM

简述: 可解释多模态MoE识别BED生物标志

筛选理由: 多模态医学建模有新意，但任务较垂直

Deep Review

创新: 论文提出 IMA-MoE，一个面向 BED 判别的可解释模态感知混合专家框架，把 sMRI、DTI、tfMRI、行为、激素和人口学等异构指标统一编码为 measure-level token，从而同时保留模态特异性与跨模态交互能力。其第二个关键创新是将 Transformer 的跨模态建模、MoE 的自适应专家路由，以及 token-importance 的可解释加权融合结合起来，不仅提升分类性能，还能直接量化每个测量对预测的贡献。论文还进一步揭示了明显的性别差异模式：女性预测更依赖激素特征，男性更依赖 tfMRI/任务表现特征。

方法: 方法上，作者先将每个高维向量型测量（如皮层厚度、白质纤维指标、tfMRI 图指标）通过专门的 vector encoder 编码，并将标量变量（如年龄、性别、收入、BMI、IQ）通过 scalar encoder 投影到统一隐空间。随后把所有测量表示成独立 token，输入 Transformer encoder 建模跨模态依赖关系。接着利用 token-wise MoE 对不同 token 进行动态专家路由，以适配不同模态的非线性模式。最后通过 token-importance 模块为各 token 分配个体化权重，做加权池化并完成 BED/健康对照分类，同时输出可解释的模态贡献度。

实验: 在 ABCD 数据集构建的 99 个 BED 与 123 个健康对照样本上，IMA-MoE 获得了 82.61% 的准确率和 0.8571 的 F1，优于线性/RBF-SVM、Random Forest 和 5 层 MLP 等基线。分性别分析中，女性子集准确率达到 91.67%，明显高于男性的 72.73%，并且 token importance 显示女性更依赖激素特征、男性更依赖 N-back/SST/MID 等功能任务特征。消融实验还表明 Transformer 与 MoE 都是性能提升的关键，而解释性模块几乎不损伤分类表现。

Deep理由: 这篇论文的方法设计清晰，兼顾多模态融合、专家路由与可解释性，在 BED 这样机制尚不清晰的精神疾病研究中很有启发性。不过其样本规模仍偏小、测试集较有限，且缺少更严格的外部验证与统计显著性分析，因此更适合作为值得关注的新方法论文，而非现阶段的“必读标杆”。

Mini-BEHAVIOR-Gran: Revealing U-Shaped Effects of Instruction Granularity on Language-Guided Embodied Agents

方向: VLA | 标签: VLA

简述: 指令粒度影响具身智能呈U型

筛选理由: 基准设计新颖，发现有启发，但偏分析型

Deep Review

创新: 论文的核心创新有两点：第一，提出了 MINI-BEHAVIOR-Gran，这是一个能够在“同一任务、不同指令粒度”下进行受控研究的 embodied benchmark，弥补了现有数据集通常只提供单一静态指令的缺陷。第二，作者系统比较了多种粒度度量方式，发现源自规划理论的 width 比 token/entity/action-verb 等表层统计量更稳定地刻画指令粒度及其对智能体性能的影响。更重要的是，论文进一步揭示了一个此前未被明确报告的结论：指令粒度与性能之间并非单调关系，而是呈现 U 型曲线，且粗粒度端的回升与“浅层 grounding、视觉主导策略”有关。

方法: 方法上，作者在 MINI-BEHAVIOR 基础上构建了多粒度指令版本：先借助共享符号特征空间表示环境状态，再把任务写成 if-then 规则集合，从最细粒度的原子规则开始，逐步合并为更粗的宏规则，并通过模板生成自然语言指令。实验中，系统用动态 instructor 在执行过程中根据当前状态实时选择可用规则并生成对应指令，因此 agent 接收到的是随任务进展变化的动态语言输入，而不是静态 instruction。随后论文比较四种粒度指标——token count、entity count、action-verb count 和 width——并用 width 将训练/测试样本划分为 Fine / Medium / Coarse，分析不同粒度分布下的学习与泛化行为。最后，作者通过指令可预测性 P(l|v)、去语言/弱语言测试以及注意力分析，解释 U 型现象背后的机制。

实验: 实验最有价值的发现是：width 是唯一在不同 instruction horizon 和不同 VLA action decoder（AR / diffusion / parallel）上都与 success rate 持续显著负相关的指标，说明它比表层语言统计量更能反映真实 grounding 难度。进一步地，训练和测试按粒度分组后，三类 VLA 都表现出一致的 U 型规律：细粒度表现最好，中粒度最差，粗粒度出现反弹。作者还发现粗粒度训练虽然能带来性能回升，但其策略更依赖视觉、对语言依赖显著减弱；而 fine-weighted mixed training 在性能与语言 grounding 之间取得了更好的折中。

Deep理由: 这篇论文对于 VLA/embodied AI 很值得读，因为它不仅提出了一个高质量 benchmark，更给出了一个非常强的经验性结论：更详细的指令并不总是更好，粒度与性能存在 U 型关系。这个发现对数据构造、训练配比、鲁棒性评测乃至未来人机交互式机器人指令设计都有直接启发。
